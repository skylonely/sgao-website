# 沈阳 + 丹东 + 大连 6日5晚旅行攻略（最终版）

![沈阳、丹东、大连旅行路线](https://img.sgao.cc/travel/travel_shenyang.png)

## 时间

**8月25日 ～ 8月30日**

路线：

常州 ✈ 沈阳 → 丹东 → 大连 ✈ 常州

旅行主题：

-   沈阳：历史文化
-   丹东：边境风光
-   大连：海滨城市

------------------------------------------------------------------------

# Day 1｜8月25日（周一）

## 常州 → 沈阳

### 航班

-   23:00 左右
-   常州奔牛机场 → 沈阳桃仙机场
-   飞行约2小时

预计： - 8月26日凌晨1点左右抵达沈阳

### 住宿建议

区域： - 沈阳中街 / 故宫附近

优势： - 第二天景点集中 - 吃饭方便 - 去高铁站方便

------------------------------------------------------------------------

# Day 2｜8月26日（周二）

# 沈阳一日游

## 上午：清朝 + 民国历史路线

### 09:00 沈阳故宫 ⭐⭐⭐⭐⭐

游玩： 约2小时

重点： - 大政殿 - 十王亭 - 凤凰楼 - 清宁宫

------------------------------------------------------------------------

### 11:30 张氏帅府 ⭐⭐⭐⭐⭐

游玩： 1～1.5小时

看点： - 张作霖官邸 - 张学良故居 - 民国建筑

------------------------------------------------------------------------

## 午餐 13:00

推荐： - 老边饺子 - 李连贵熏肉大饼

------------------------------------------------------------------------

## 下午

二选一：

### 方案A：辽宁省博物馆

适合喜欢历史文化。

### 方案B：北陵公园

适合散步、拍照。

------------------------------------------------------------------------

## 傍晚

### 17:30 西塔韩国风情街

推荐： - 朝鲜冷面 - 烤肉 - 打糕

------------------------------------------------------------------------

## 晚上

### 19:30 中街夜景

体验： - 老字号 - 小吃 - 夜景

------------------------------------------------------------------------

# 大连滨海经典一日游

东港 → 棒棰岛 → 老虎滩 → 北大桥 → 燕窝岭 → 星海广场 → 东港

------------------------------------------------------------------------

可选择： - 海洋公园游玩 - 周边看海

------------------------------------------------------------------------

## 午餐

推荐： - 虾爬子 - 海螺 - 扇贝 - 海胆

------------------------------------------------------------------------

## 下午

### 北大桥

### 燕窝岭
