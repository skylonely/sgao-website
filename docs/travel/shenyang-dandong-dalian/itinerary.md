# 沈阳 + 丹东 + 大连 6日5晚旅行攻略（最终修正版）

![沈阳、丹东、大连旅行路线](https://img.sgao.cc/travel/travel_shenyang.png)

## 时间

8月25日（周二）～8月30日（周日）

路线： 常州 → 沈阳 → 丹东 → 大连 → 常州

------------------------------------------------------------------------

# Day 1｜8月25日（周二）

## 常州 → 沈阳

-   23:00左右 常州奔牛机场出发
-   飞行约2小时
-   8月26日凌晨1点左右抵达沈阳

住宿： 沈阳青年南大街奥体中心附近

优势： - 靠近机场方向 - 去辽宁省博物馆方便 - 环境较新

------------------------------------------------------------------------

# Day 2｜8月26日（周三）

# 沈阳历史文化一日游

路线： 酒店 → 九一八历史博物馆 → 沈阳故宫 → 张氏帅府 → 西塔 → 中街

## 09:00 九一八历史博物馆

游玩约1～1.5小时。

## 10:30 沈阳故宫

游玩约2小时。

重点： - 大政殿 - 十王亭 - 凤凰楼

## 12:30 午餐

推荐： - 老边饺子 - 李连贵熏肉大饼

## 14:00 张氏帅府

游玩约1～1.5小时。

## 16:00 西塔韩国风情街

推荐： - 朝鲜冷面 - 烤肉

## 18:30 中街夜景

结束后返回青年南大街奥体中心酒店。

------------------------------------------------------------------------

# Day 3｜8月27日（周四）

# 沈阳 → 丹东

## 上午

09:00 辽宁省博物馆

酒店前往约15～20分钟。

游玩： 1.5～2小时。

## 中午

返回酒店取行李。

12:00左右高铁： 沈阳 → 丹东

约1.5小时。

## 下午丹东

15:30 鸭绿江断桥

16:40 鸭绿江公园

17:30 鸭绿江游船

晚上： 安东老街

美食： - 黄蚬子 - 虾爬子 - 海鲜烧烤

住宿： 鸭绿江断桥附近。

------------------------------------------------------------------------

# Day 4｜8月28日（周五）

# 丹东 → 大连

## 上午

09:00 抗美援朝纪念馆

11:00 虎山长城

## 下午

丹东 → 大连

高铁约2小时。

住宿： 大连东港音乐喷泉广场附近。

晚上：

-   东方水城
-   东港音乐喷泉
-   海边夜景

------------------------------------------------------------------------

-   北大桥

# Day 6｜8月30日（周日）

# 大连 → 常州

根据航班安排。

上午可选：

A： 中山广场 + 俄罗斯风情街

B： 海之韵公园

随后前往机场。
