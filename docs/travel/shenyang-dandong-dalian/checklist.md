# 十一、行程小建议

1.  沈阳景点集中，尽量步行游玩。

2.  丹东以边境体验为主，不建议安排过多景点。

3.  大连东港酒店位置很好，晚上优先安排东港夜景。

4.  海边城市早晚温差较明显，建议随身带薄外套。

5.  出行以网约车 + 高铁为主，减少换乘。

------------------------------------------------------------------------

# 最终出行目标

轻松旅行：

历史文化 → 边境风光 → 海滨城市

不赶路、不打卡式旅游，重点体验东北特色。
