# 1. 嵌入式系统案例概述

嵌入式系统案例主要考查：

-   系统实时性；
-   系统可靠性；
-   资源约束；
-   硬件软件协同设计。

案例通常描述：

-   工业控制系统；
-   交通控制系统；
-   航空航天系统；
-   智能设备。

需要分析：

-   系统架构；
-   实时策略；
-   可靠性措施。

------------------------------------------------------------------------

# 2. 嵌入式系统特点（★★★★★）

嵌入式系统通常具有：

## 资源受限

包括：

-   CPU资源有限；
-   存储空间有限；
-   功耗要求严格。

------------------------------------------------------------------------

## 实时性

要求：

系统必须在规定时间内完成任务。

------------------------------------------------------------------------

## 可靠性

要求：

长期稳定运行。

------------------------------------------------------------------------

## 专用性

通常针对特定任务设计。

------------------------------------------------------------------------

# 4. 嵌入式实时系统案例（★★★★★）

实时系统关注：

-   时间约束；
-   响应速度；
-   任务调度。

------------------------------------------------------------------------

## 硬实时系统

特点：

必须满足截止时间。

例如：

-   飞控系统；
-   工业控制系统。

------------------------------------------------------------------------

## 软实时系统

特点：

允许偶尔超时。

例如：

-   多媒体系统。

------------------------------------------------------------------------

常见策略：

## 冗余设计

通过增加备用资源避免单点故障。

------------------------------------------------------------------------

## 故障检测

及时发现异常。

------------------------------------------------------------------------

## 故障隔离

限制错误影响范围。

------------------------------------------------------------------------

## 故障恢复

恢复系统正常运行。

# 9. N版本程序设计案例（★★★★★）

N版本程序设计思想：

通过多个独立开发的软件版本提高可靠性。

结构：

``` text
输入

↓

程序A

程序B

程序C

↓

表决器

↓

输出
```

------------------------------------------------------------------------

## 优点

-   提高可靠性；
-   降低单版本错误影响。

------------------------------------------------------------------------

## 缺点

-   开发成本增加；
-   维护复杂度提高。

------------------------------------------------------------------------

# 10. 恢复块设计案例（★★★★★）

恢复块思想：

采用主程序和备用程序结合方式。

流程：

``` text
主程序运行

↓

结果验证

↓

是否正确？

↓

备用程序恢复
```

------------------------------------------------------------------------

特点：

-   提高系统可靠性；
-   适用于高可靠系统。

# 12. 案例分析答题模板

## 高可靠场景

答案：

> 采用冗余设计和容错机制，通过故障检测、故障隔离以及恢复策略，提高系统可靠性。

------------------------------------------------------------------------

## 严格实时场景

答案：

> 采用实时操作系统，通过任务调度、优先级管理和中断机制保证任务在规定时间内完成。

------------------------------------------------------------------------

## 防止单程序故障

答案：

> 采用N版本程序设计，通过多个独立实现和表决机制提高系统容错能力。

------------------------------------------------------------------------

# 14. 易错点

  易错知识                     正确理解
  ---------------------------- ----------------------------
  实时系统一定要求速度最快     关键是满足时间约束
  冗余只提高性能               冗余主要提高可靠性
  N版本程序只有一个程序        N版本包含多个独立版本
  恢复块依靠多个同时运行版本   恢复块主要采用备用恢复机制
