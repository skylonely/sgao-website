``` text
↓

```

# 2. 项目进度管理案例（★★★★★）

项目进度管理关注：

-   项目什么时候完成；
-   哪些任务影响工期；
-   如何控制延期。

主要方法：

-   甘特图；
-   PERT；
-   CPM。

------------------------------------------------------------------------

# 3. 甘特图案例（★★★★★）

甘特图通过时间轴展示任务计划。

示例：

``` text
任务A  █████

任务B      ██████

任务C            ████
```

优点：

-   直观展示项目进度；
-   方便跟踪任务完成情况。

缺点：

-   对复杂依赖关系表达不足。

------------------------------------------------------------------------

# 4. PERT网络计划案例（★★★★★）

PERT：

Program Evaluation and Review Technique。

用于：

-   项目进度分析；
-   活动时间估算。

------------------------------------------------------------------------

## 三种时间估计

  类型           含义
  -------------- --------------
  乐观时间 a     最短完成时间
  最可能时间 m   正常完成时间
  悲观时间 b     最长完成时间

------------------------------------------------------------------------

## 期望时间公式

``` text
Te = (a + 4m + b) / 6
```

# 5. 关键路径法（CPM）案例（★★★★★）

关键路径：

> 项目网络中持续时间最长的路径。

特点：

-   决定项目最短完成时间；
-   关键任务延期会导致项目延期。

分析过程：

``` text
任务网络

↓

计算各路径时间

↓

找出最长路径

↓

确定关键路径
```

------------------------------------------------------------------------

# 6. ES / EF / LS / LF计算案例（★★★★★）

## 正向计算

计算：

-   ES：最早开始时间；
-   EF：最早结束时间。

公式：

``` text
EF = ES + 工期
```

------------------------------------------------------------------------

## 反向计算

计算：

-   LS：最迟开始时间；
-   LF：最迟结束时间。

公式：

``` text
LS = LF - 工期
```

------------------------------------------------------------------------

# 7. 总时差计算案例（★★★★★）

公式：

``` text
总时差 = LS - ES

或

总时差 = LF - EF
```

判断：

  总时差   含义
  -------- ----------
  0        关键任务
  \>0      可以延期

## 风险应对策略

  策略       含义
  ---------- --------------
  风险规避   消除风险来源
  风险转移   转给其他主体
  风险降低   减少影响概率
  风险接受   主动承担风险

# 11. 案例分析答题模板

## 场景：项目延期

答案：

> 通过PERT和关键路径分析识别影响项目工期的关键任务，对关键活动进行重点控制，降低项目延期风险。

------------------------------------------------------------------------

## 场景：任务依赖复杂

答案：

> 建立项目网络计划图，分析任务之间的依赖关系，确定关键路径和任务时差。

------------------------------------------------------------------------

## 场景：需求频繁变化

答案：

> 采用配置管理和变更控制流程，对需求、代码和文档进行统一管理。

------------------------------------------------------------------------

# 13. 易错点

  易错知识                     正确理解
  ---------------------------- -------------------------
  关键路径最短                 关键路径是最长路径
  总时差越小越不重要           总时差为0通常是关键任务
  甘特图可以完整表示复杂依赖   网络图更适合复杂依赖
  配置管理只是代码管理         包含文档、需求等配置项

# 15. 本节小结

项目管理案例核心：

> 通过计划、分析和控制手段，保证项目按时间、质量和成本目标完成。

案例回答重点：

-   根据任务关系建立计划；
-   使用PERT和关键路径分析工期；
-   根据风险选择应对措施；
-   使用配置管理控制项目变化。
