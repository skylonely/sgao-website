# 3. B/S架构案例（★★★★★）

B/S：

Browser / Server。

结构：

``` text
浏览器

↓

服务器

↓

数据库
```

------------------------------------------------------------------------

## 优点

-   客户端无需复杂安装；
-   易维护；
-   易升级；
-   支持跨平台访问。

------------------------------------------------------------------------

## 缺点

-   对网络依赖较高。

# 4. MVC / MVP / MVVM案例（★★★★★）

## MVC

MVC：

``` text
Model

View

Controller
```

------------------------------------------------------------------------

### Model

负责：

-   数据管理；
-   业务逻辑。

------------------------------------------------------------------------

### View

负责：

-   页面展示；
-   用户交互显示。

------------------------------------------------------------------------

### Controller

负责：

-   接收请求；
-   调用业务；
-   返回结果。

------------------------------------------------------------------------

## MVP

组成：

-   Model；
-   View；
-   Presenter。

特点：

Presenter负责控制业务流程，使View更加被动。

------------------------------------------------------------------------

## MVVM

组成：

-   Model；
-   View；
-   ViewModel。

特点：

通过ViewModel实现数据和界面的绑定。

------------------------------------------------------------------------

------------------------------------------------------------------------

# 12. 案例分析答题模板

## 场景：访问量快速增长

答案：

> 采用负载均衡和服务器集群，将请求分散到多个节点，同时结合缓存机制降低服务器压力，提高系统性能和可扩展性。

------------------------------------------------------------------------

## 场景：静态资源访问慢

答案：

> 使用CDN缓存静态资源，将内容分发到边缘节点，减少用户访问距离，提高访问速度。

------------------------------------------------------------------------

## 场景：系统需要快速开发维护

答案：

> 采用前后端分离架构，通过接口进行通信，降低系统耦合，提高开发效率和可维护性。

# 14. 易错点

  ---------------------- ----------------------
  CDN提升数据库性能      CDN主要加速静态资源
  MVC是数据库架构        MVC是应用架构模式
  REST只能用于Web页面    REST主要用于服务接口
