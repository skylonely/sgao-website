# 一、案例分析考试特点

案例分析主要考查：

-   阅读系统背景描述；
-   分析架构设计问题；
-   根据场景选择技术方案；
-   使用专业术语进行回答。

与选择题不同，案例分析更加关注：

-   理论知识应用；
-   架构设计能力；
-   问题分析能力。

------------------------------------------------------------------------

# 九、案例分析答题方法

## 第一步：识别考点

阅读题目：

判断属于：

-   架构设计；
-   数据库；
-   Web；
-   安全；
-   项目管理。

------------------------------------------------------------------------

## 第二步：提取关键词

例如：

高并发：

→ 缓存、负载均衡、集群。

高可靠：

→ 冗余、备份、容错。

高安全：

→ 加密、认证、授权。

------------------------------------------------------------------------

## 第三步：使用标准术语回答

案例答案应避免：

-   口语化描述；
-   模糊表达。

建议使用：

-   架构模式；
-   技术方案；
-   设计原则。
