# 2. 信息安全基本目标（★★★★★）

信息安全主要目标：

## 保密性（Confidentiality）

保证：

未经授权的用户无法获取信息。

措施：

-   加密；
-   权限控制。

------------------------------------------------------------------------

## 完整性（Integrity）

保证：

数据没有被非法修改。

措施：

-   数字签名；
-   校验机制。

------------------------------------------------------------------------

## 可用性（Availability）

保证：

系统能够持续提供服务。

措施：

-   备份；
-   容灾；
-   冗余。

------------------------------------------------------------------------

# 3. 身份认证案例（★★★★★）

身份认证用于：

确认用户身份是否合法。

常见方式：

## 用户名密码

特点：

简单，但安全性依赖密码管理。

------------------------------------------------------------------------

## 多因素认证

结合：

-   密码；
-   短信验证码；
-   生物特征。

提高安全性。

------------------------------------------------------------------------

## 数字证书认证

利用：

-   公钥；
-   私钥；
-   证书机构。

确认身份。

------------------------------------------------------------------------

# 4. 访问控制案例（★★★★★）

访问控制目标：

限制用户访问资源范围。

主要包括：

## 自主访问控制 DAC

特点：

资源拥有者决定访问权限。

------------------------------------------------------------------------

## 强制访问控制 MAC

特点：

由系统安全策略统一控制。

------------------------------------------------------------------------

## 基于角色访问控制 RBAC

特点：

根据用户角色分配权限。

例如：

``` text
用户

↓

角色

↓

权限
```

------------------------------------------------------------------------

# 5. 密码技术案例（★★★★★）

密码技术包括：

## 对称加密

特点：

加密和解密使用同一个密钥。

优点：

-   速度快。

缺点：

-   密钥管理困难。

------------------------------------------------------------------------

## 非对称加密

特点：

使用公钥和私钥。

优点：

-   密钥管理方便。

应用：

-   数字签名；
-   身份认证。

------------------------------------------------------------------------

## 哈希算法

特点：

单向不可逆。

应用：

-   数据完整性校验；
-   密码保存。

------------------------------------------------------------------------

# 7. 入侵检测与防御案例

## IDS

Intrusion Detection System。

作用：

检测异常行为。

特点：

-   发现攻击；
-   产生报警。

------------------------------------------------------------------------

## IPS

Intrusion Prevention System。

作用：

主动阻止攻击。

区别：

  IDS        IPS
  ---------- ----------
  检测       防御
  被动报警   主动阻断

# 11. 案例分析答题模板

## 场景：防止非法访问

答案：

> 采用身份认证和访问控制机制，对用户身份进行验证，并根据权限限制资源访问，提高系统安全性。

------------------------------------------------------------------------

## 场景：保护敏感数据

答案：

> 采用加密技术保护数据传输和存储安全，同时结合权限控制和审计机制防止数据泄露。

------------------------------------------------------------------------

## 场景：防御网络攻击

答案：

> 部署防火墙和入侵检测/防御系统，对网络流量进行监控和异常行为阻断。

# 13. 易错点

  易错知识                 正确理解
  ------------------------ ------------------------
  加密保证所有安全         加密主要保护机密性
  IDS可以自动阻止攻击      IDS主要检测报警
  防火墙解决所有安全问题   防火墙只是安全措施之一
  权限控制等于身份认证     两者作用不同

# 15. 本节小结

信息安全案例核心：

> 根据安全需求识别风险，选择合适的安全技术和管理措施。

案例回答重点：

-   明确安全目标；
-   选择认证、授权、加密等措施；
-   结合网络防护和数据保护方案；
-   使用标准安全术语回答。
