# 1. AI原生应用案例概述

AI原生应用：

> 以人工智能能力作为核心设计理念，从架构、交互、流程和数据体系重新构建的新一代智能应用。

传统应用：

``` text
用户

↓

业务逻辑

↓

数据库

↓

返回结果
```

AI原生应用：

``` text
用户

↓

AI理解层

↓

Agent智能层

↓

业务执行层

↓

数据与知识层

↓

持续优化
```

# 2. AI Native基本概念

核心特点：

-   AI作为核心能力；
-   自然语言交互；
-   Agent自主执行；
-   数据持续学习；
-   动态优化。

区别：

  传统应用   AI原生应用
  ---------- --------------
  固定流程   智能流程
  菜单交互   自然语言交互
  人工操作   Agent执行
  静态规则   动态优化

> 通过AI工作流和Agent自动化，实现业务流程智能化。

## 企业知识无法有效利用

> 引入RAG知识增强架构，实现企业知识智能检索和应用。

## 企业数字化升级

> 构建AI原生应用平台，实现模型、Agent、知识和业务能力融合。

-   理解 AI Native Application 架构；
-   掌握Agent原生设计方法；

-   掌握企业AI原生应用建设路径。
