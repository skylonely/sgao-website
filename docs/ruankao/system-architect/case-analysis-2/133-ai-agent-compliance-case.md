  易错知识             正确理解
  -------------------- --------------------------------
  合规只是法律检查     合规还包括制度、流程和业务执行
  AI可以替代审计人员   AI主要辅助分析和检查
  规则固定不变         法规变化需要持续更新
  发现问题即可结束     需要整改和验证闭环
