# 易错点

|易错知识|正确理解|
|-|-|
|Agent只管理代码|还需要管理Prompt、模型和知识|
|上线后无需迭代|Agent需要持续优化|
|测试只验证功能|还需要效果、安全和性能测试|
|DevOps只适用于传统软件|AI应用同样需要工程化交付|
