  易错知识                正确理解
  ----------------------- --------------------------------------
  销售Agent只是聊天工具   需要覆盖获客、分析、成交和运营全过程
  只需要客户数据          还需要销售知识和业务流程
  销售预测只依靠模型      需要结合业务规则和人工判断
  AI完全替代销售          实际采用人机协同模式
