## 代码维护困难

> 建设自动重构建议Agent，提高代码可维护性。

## 推进软件质量治理

> 构建AI代码质量治理平台，实现检测、分析、优化、验证全过程智能化。

# 易错点

|易错知识|正确理解|
|-|-|
|代码质量只是格式检查|还包括缺陷、复杂度、安全和可维护性|
|AI可以完全替代Review|AI主要辅助开发人员提升效率|
|只分析代码即可|需要结合规范、历史缺陷和工程数据|
|质量治理只在开发阶段|需要持续集成全过程治理|
