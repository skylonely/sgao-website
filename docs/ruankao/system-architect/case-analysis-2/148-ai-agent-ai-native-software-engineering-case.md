# 1. AI原生软件工程案例概述

AI原生软件工程：

> 以人工智能作为软件研发核心能力，通过智能体参与需求、设计、开发、测试、部署和维护全过程的新型软件工程模式。

传统软件工程：

``` text
需求分析

↓

系统设计

↓

编码开发

↓

测试部署

↓

维护
```

AI原生软件工程：

``` text
需求理解Agent

↓

架构设计Agent

↓

编码Agent

↓

测试Agent

↓

DevOps Agent

↓

持续优化
```

> 引入AI编码Agent，实现代码生成、补全和自动优化，提高研发效率。

> 建设AI测试和代码审查Agent，实现自动测试和质量保障。

## 研发流程割裂

> 构建AI DevOps体系，实现开发、测试、部署和运维一体化。

## 企业研发智能化升级

> 建设AI原生软件工程平台，实现需求、设计、开发、测试和运维全过程智能化。

# 易错点

  易错知识                     正确理解
  ---------------------------- ------------------------------------
  AI原生软件工程只是代码生成   还包括需求、设计、测试和运维全过程
  AI替代所有开发人员           AI主要增强研发能力
  只关注编码效率               还需要关注质量、安全和维护
  AI开发无需工程流程           仍需要DevOps和治理体系
