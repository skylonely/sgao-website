# 易错点

  易错知识                    正确理解
  --------------------------- ------------------------------------
  法律Agent只是法律问答工具   需要覆盖检索、分析、审核和管理流程
  只需要大模型                还需要法律知识库和业务数据
  AI生成法律意见无需审核      必须保留专业人员复核
  法律数据可以直接开放        需要严格权限和安全控制
