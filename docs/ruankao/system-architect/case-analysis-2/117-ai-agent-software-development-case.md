# 易错点

  易错知识                        正确理解
  ------------------------------- --------------------------------
  软件开发Agent只是代码生成工具   需要覆盖研发全生命周期
  只需要大模型                    还需要代码库、知识库和工程流程
  AI生成代码无需审核              必须进行人工审查和质量控制
  AI替代开发人员                  实际采用人机协同模式
