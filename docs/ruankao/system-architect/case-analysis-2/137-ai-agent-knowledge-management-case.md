# 易错点

|易错知识|正确理解|
|-|-|
|知识管理只是文档存储|还包括知识组织、应用和运营|
|搜索系统等于知识智能体|AI智能体具备理解和推理能力|
|知识库建立后无需维护|知识需要持续更新|
|所有知识都可以公开访问|需要权限和安全控制|
