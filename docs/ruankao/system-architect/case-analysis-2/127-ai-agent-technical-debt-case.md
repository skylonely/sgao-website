# 易错点

|易错知识|正确理解|
|-|-|
|技术债只是代码问题|技术债还包括架构、设计和技术选型问题|
|发现问题即可完成治理|需要评估、规划、实施和验证闭环|
|AI可以自动重构所有系统|复杂系统仍需要人工决策|
|技术债只关注开发阶段|技术债需要持续治理|
