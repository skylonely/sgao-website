# 1. 高并发系统案例概述

高并发系统主要解决：

-   用户访问量快速增长；
-   突发流量冲击；
-   系统响应时间增加；
-   服务稳定性下降。

典型架构：

``` text
用户请求

↓

CDN

↓

负载均衡

↓

应用服务器集群

↓

缓存

↓

数据库
```

# 4. 负载均衡案例（★★★★★）

负载均衡：

> 将用户请求分发到多个服务器，提高系统处理能力。

架构：

``` text
用户

↓

负载均衡器

↓

服务器1
服务器2
服务器3
```

常见策略：

-   轮询；
-   加权轮询；
-   最小连接数。

------------------------------------------------------------------------

# 5. CDN与静态资源优化案例（★★★★★）

CDN：

> 将静态资源缓存到距离用户更近的位置。

适用：

-   图片；
-   视频；
-   CSS；
-   JavaScript。

优势：

-   降低源站压力；
-   提升访问速度。

------------------------------------------------------------------------

# 6. 动静分离案例（★★★★★）

动静分离：

将：

-   静态资源；
-   动态业务。

分别处理。

结构：

``` text
用户

↓

静态资源 → CDN

↓

动态请求 → 应用服务器
```

优势：

-   提升系统吞吐；
-   降低应用服务器压力。

------------------------------------------------------------------------

# 7. 限流设计案例（★★★★★）

限流：

> 控制进入系统的请求数量，保护系统稳定。

常见算法：

-   令牌桶；
-   漏桶；
-   计数器。

应用：

-   API访问控制；
-   秒杀保护。

------------------------------------------------------------------------

# 8. 服务降级案例（★★★★★）

服务降级：

> 在系统压力过大时关闭非核心功能，保证核心业务运行。

例如：

关闭：

-   推荐服务；
-   数据统计。

保留：

-   下单；
-   支付。

# 16. 案例分析答题模板（★★★★★）

## 系统访问压力大

> 采用负载均衡和服务器集群，将请求分散到多个节点，提高系统并发处理能力。

------------------------------------------------------------------------

## 突发流量

> 采用限流、缓存和消息队列削峰，降低瞬时压力，保护后端服务稳定运行。

------------------------------------------------------------------------

## 响应速度慢

> 采用CDN、缓存和动静分离技术，减少后端压力，提高系统响应速度。

------------------------------------------------------------------------

## 系统可靠性要求高

> 采用集群部署、故障转移和监控机制，提高系统可用性。

# 20. 本节小结

高并发系统案例核心：

> 通过分层架构、负载均衡、缓存、消息队列以及流量治理技术，提高系统吞吐能力和稳定性。

案例分析重点：

-   根据压力来源选择优化方案；
-   综合使用缓存、MQ、限流等技术；
-   平衡性能、成本和复杂度；
-   保证系统高可用。
