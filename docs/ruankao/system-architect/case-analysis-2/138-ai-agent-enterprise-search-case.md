# 易错点

|易错知识|正确理解|
|-|-|
|企业搜索只是关键词匹配|AI搜索需要语义理解和上下文分析|
|搜索结果越多越好|需要智能排序和精准推荐|
|RAG只负责生成答案|RAG包含知识检索和增强生成过程|
|搜索系统无需权限控制|企业搜索必须考虑数据安全|
