# 易错点

  易错知识                 正确理解
  ------------------------ --------------------------------
  数据质量只是检查错误     还包括分析、修复和持续优化
  发现异常即可结束         需要形成质量治理闭环
  规则完全固定             规则需要根据业务持续优化
  质量问题只来自数据本身   需要结合业务流程和数据血缘分析
