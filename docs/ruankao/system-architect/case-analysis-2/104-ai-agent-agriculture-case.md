# 易错点

  易错知识                    正确理解
  --------------------------- ----------------------------------
  农业Agent只是农业问答工具   需要参与生产分析和优化决策
  只需要AI模型                还需要农业数据和知识体系
  农业自动化等于智能农业      智能农业需要感知、分析和决策能力
  农业数据无需治理            需要数据安全和权限管理
