# 易错点

  易错知识                  正确理解
  ------------------------- -----------------------------
  AI安全只关注模型          还包括数据、Agent和应用安全
  Prompt攻击只是输入问题    需要输入检测和行为防护
  Agent拥有全部权限更方便   企业环境必须最小权限控制
  安全检测后无需响应        需要自动化处置和持续优化
