# 易错点

|易错知识|正确理解|
|-|-|
|金融Agent只是客服机器人|金融Agent需要参与分析、决策和业务执行|
|金融AI只需要模型|还需要知识、数据和规则体系|
|AI决策可以完全自动化|金融高风险场景需要人工审核|
|上线后无需管理|需要持续治理和监管|
