# 1. 云计算案例概述

云计算主要解决：

-   IT资源利用率低；
-   系统扩展困难；
-   运维成本高；
-   业务快速变化。

核心思想：

> 通过虚拟化和资源池化技术，将计算、存储、网络等资源按需提供。

典型架构：

``` text
用户

↓

云服务平台

↓

计算资源池

存储资源池

网络资源池
```

------------------------------------------------------------------------

# 2. 云计算基本概念（★★★★★）

云计算特点：

## 按需服务

根据业务需求动态申请资源。

------------------------------------------------------------------------

## 弹性伸缩

根据负载自动增加或释放资源。

------------------------------------------------------------------------

## 资源池化

统一管理：

-   CPU；
-   内存；
-   存储；
-   网络。

------------------------------------------------------------------------

## 快速部署

实现：

-   自动化创建；
-   自动化配置。

------------------------------------------------------------------------

# 3. 云计算服务模式案例（★★★★★）

## IaaS

Infrastructure as a Service。

提供：

-   虚拟机；
-   存储；
-   网络。

用户负责：

-   操作系统；
-   应用程序。

------------------------------------------------------------------------

## PaaS

Platform as a Service。

提供：

-   开发平台；
-   运行环境；
-   中间件。

用户关注：

-   应用开发。

------------------------------------------------------------------------

## SaaS

Software as a Service。

提供：

-   软件服务。

用户直接使用应用。

------------------------------------------------------------------------

三者关系：

``` text
SaaS

↓

PaaS

↓

IaaS

↓

硬件资源
```

------------------------------------------------------------------------

# 4. 云计算部署模式案例（★★★★★）

## 公有云

资源由云服务商提供。

特点：

-   成本低；
-   弹性强。

------------------------------------------------------------------------

## 私有云

企业自建云平台。

特点：

-   安全性高；
-   可控性强。

------------------------------------------------------------------------

## 混合云

结合：

-   公有云；
-   私有云。

优势：

-   灵活；
-   安全。

------------------------------------------------------------------------

## 存储虚拟化

# 16. 案例分析答题模板（★★★★★）

## 资源不足

> 采用云计算资源池和弹性伸缩机制，根据业务负载动态调整计算资源，提高资源利用率。

------------------------------------------------------------------------

## 系统快速上线

> 采用云平台自动化部署能力，通过虚拟化和平台服务快速创建运行环境。

------------------------------------------------------------------------

## 高可靠要求

> 采用多区域部署、数据复制和故障转移机制，提高云系统可用性。

------------------------------------------------------------------------

## 企业上云

> 根据业务特点采用混合云架构，将核心业务部署在私有云，弹性业务部署在公有云。

# 18. 易错点

  易错知识               正确理解
  ---------------------- --------------------------------
  云计算就是购买服务器   云计算核心是资源池化和按需服务
  SaaS用户管理底层资源   SaaS用户只使用应用服务
  虚拟化等于云计算       虚拟化是云计算的重要技术基础
  上云后不需要安全设计   云环境仍需要安全控制

# 20. 本节小结

云计算案例核心：

> 通过虚拟化、资源池化和自动化管理，实现计算、存储和网络资源的按需提供，提高系统弹性、可靠性和资源利用率。

案例分析重点：

-   根据业务需求选择云服务模式；
-   根据安全和成本选择部署模式；
-   结合容器、微服务和自动化能力设计云架构；
-   保证云环境的安全性和高可用性。
