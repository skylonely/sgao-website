# 1. 零售智能体案例概述

零售智能体：

> 面向商品销售、客户服务和供应链运营场景，结合商品知识、用户数据和业务流程，实现智能营销、智能推荐和经营优化的AI
> Agent系统。

传统零售系统：

``` text

↓

↓
```


# 易错点

  易错知识                  正确理解
  ------------------------- ----------------------------
  零售Agent只是客服机器人   需要覆盖营销、运营和供应链
  只需要推荐模型            还需要知识库和业务数据
  用户数据可以直接使用      需要隐私保护和权限管理
  AI可以完全替代运营人员    复杂业务仍需要人工决策
