# 1. 大数据案例概述

大数据主要解决：

-   海量数据存储；
-   大规模数据计算；
-   实时数据分析；
-   数据价值挖掘。

核心思想：

> 利用分布式存储和分布式计算技术，对海量、多类型、高增长速度的数据进行处理和分析。

典型架构：

``` text
数据源

↓

数据采集

↓

数据存储

↓

数据计算

↓

数据分析

↓

业务应用
```

# 2. 大数据基本概念（★★★★★）

大数据特点：

## Volume（大量）

数据规模巨大。

例如：

-   日志；
-   图片；
-   视频。

------------------------------------------------------------------------

## Velocity（高速）

数据快速产生。

例如：

-   实时交易；
-   传感器数据。

------------------------------------------------------------------------

## Variety（多样）

数据类型丰富：

-   结构化数据；
-   半结构化数据；
-   非结构化数据。

------------------------------------------------------------------------

## Value（价值）

通过分析产生业务价值。

------------------------------------------------------------------------

## Veracity（真实性）

保证数据质量。

------------------------------------------------------------------------

# 17. 案例分析答题模板（★★★★★）

# 19. 易错点

  易错知识                   正确理解
  -------------------------- ----------------------------
  大数据就是存储大量数据     大数据还包括计算和分析
  Hadoop只能做离线计算       Hadoop生态包含多种组件
  数据湖等于数据库           数据湖支持多类型原始数据
  实时计算只能使用一种技术   可根据场景选择不同计算框架

# 21. 本节小结

大数据案例核心：

> 通过分布式存储、分布式计算和数据分析技术，实现海量数据的高效处理和业务价值挖掘。

案例分析重点：

-   根据数据规模选择存储方案；
-   根据实时性要求选择计算模型；
-   结合数据湖、数据仓库构建数据平台；
-   通过大数据分析支撑业务智能化。
