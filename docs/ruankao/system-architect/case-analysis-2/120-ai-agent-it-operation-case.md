# 案例分析答题模板

## 告警数量过多

> 建设智能监控Agent，通过AI分析实现告警聚合和智能研判。

## 故障定位困难

> 引入根因分析Agent，通过多源数据关联实现快速定位。

## 运维效率低

> 建设自动修复Agent，实现常见故障自动化处理。

## 推进智能运维建设

> 构建AIOps智能运维平台，实现监控、分析、处置全过程智能化。

# 易错点

  易错知识                正确理解
  ----------------------- ----------------------------------
  运维Agent只是监控工具   需要覆盖监控、分析、处置全过程
  只需要AI模型            还需要运维知识、数据和自动化能力
  自动修复无需控制        高风险操作必须审批和审计
  AI完全替代运维人员      实际采用人机协同模式
