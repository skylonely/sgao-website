# 易错点

  易错知识                正确理解
  ----------------------- ----------------------------------
  安全Agent只是告警工具   需要覆盖检测、分析、响应全过程
  只需要安全模型          还需要安全知识和业务上下文
  自动响应无需控制        高风险操作必须进行权限和审批控制
  AI完全替代安全人员      实际采用人机协同模式
