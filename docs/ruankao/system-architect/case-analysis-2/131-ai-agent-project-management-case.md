# 易错点

  易错知识               正确理解
  ---------------------- ------------------------------
  项目管理只是进度管理   还包括成本、资源、风险和质量
  AI可以替代项目经理     AI主要辅助计划和决策
  项目风险只能人工发现   AI可以基于历史数据预测风险
  项目结束即完成管理     项目过程需要持续监控
