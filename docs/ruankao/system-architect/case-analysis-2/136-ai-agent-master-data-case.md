# 1. 主数据管理智能体案例概述

主数据管理智能体：

> 面向企业核心业务数据管理，通过AI技术结合主数据模型、数据标准和业务规则，实现企业核心数据统一管理、质量控制和共享服务的AI
> Agent系统。

典型主数据：

-   客户；
-   产品；
-   供应商；
-   组织机构；
-   员工；
-   地理位置。
