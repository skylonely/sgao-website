# 易错点

  易错知识                    正确理解
  --------------------------- --------------------------------------
  营销Agent只是自动发送广告   需要覆盖分析、策略、执行和优化全过程
  只需要用户数据              还需要知识库和业务规则
  营销效果只看点击率          需要综合评估转化和业务价值
  AI可以完全替代营销人员      实际采用人机协同模式
