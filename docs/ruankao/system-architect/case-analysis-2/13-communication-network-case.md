# 2. 通信网络架构基础（★★★★★）

通信网络通常包括：

``` text
终端设备

↓

接入网络

↓

核心网络

↓

业务系统
```

------------------------------------------------------------------------

## 接入网络

作用：

连接用户终端。

特点：

-   用户数量多；
-   接入方式丰富。

------------------------------------------------------------------------

## 核心网络

作用：

完成：

-   数据转发；
-   用户管理；
-   业务控制。

# 3. 传统网络架构案例

传统网络特点：

-   网络设备功能集中；
-   硬件专用化；
-   扩展能力有限。

问题：

-   部署周期长；
-   资源利用率低；
-   灵活性不足。

------------------------------------------------------------------------

优化方向：

-   网络虚拟化；
-   软件定义网络；
-   自动化管理。

------------------------------------------------------------------------

# 4. 5G网络架构案例（★★★★★）

5G网络特点：

-   高速率；
-   低时延；
-   大连接。

典型应用：

-   智慧城市；
-   工业互联网；
-   自动驾驶。

------------------------------------------------------------------------

## 5G核心网特点

采用：

-   服务化架构；
-   网络切片；
-   云化部署。

------------------------------------------------------------------------

## 网络切片

作用：

在同一物理网络上创建多个逻辑网络。

优势：

-   满足不同业务需求；
-   提高资源利用率。

------------------------------------------------------------------------

# 5. MEC边缘计算案例（★★★★★）

MEC：

Multi-access Edge Computing。

核心思想：

> 将计算能力部署到靠近用户的位置。

------------------------------------------------------------------------

传统模式：

``` text
用户

↓

远程云中心
```

------------------------------------------------------------------------

边缘计算：

``` text
用户

↓

边缘节点

↓

云中心
```

------------------------------------------------------------------------

优势：

-   降低网络时延；
-   减少核心网络压力；
-   提升实时处理能力。

------------------------------------------------------------------------

应用：

-   自动驾驶；
-   工业控制；
-   视频分析。

------------------------------------------------------------------------

# 6. SDN软件定义网络案例（★★★★★）

SDN：

Software Defined Network。

核心思想：

> 将网络控制功能与数据转发功能分离。

------------------------------------------------------------------------

传统网络：

``` text
网络设备

↓

控制 + 转发
```

------------------------------------------------------------------------

SDN：

``` text
应用层

↓

控制层

↓

数据转发层
```

------------------------------------------------------------------------

## SDN三层架构

### 应用层

提供网络业务。

------------------------------------------------------------------------

### 控制层

负责：

-   网络控制；
-   路由计算。

------------------------------------------------------------------------

### 数据层

负责：

-   数据转发。

------------------------------------------------------------------------

## SDN优势

-   网络集中控制；
-   自动化管理；
-   灵活配置。

------------------------------------------------------------------------

# 7. 网络功能虚拟化NFV案例（★★★★★）

NFV：

Network Functions Virtualization。

核心：

将传统网络设备功能软件化。

例如：

-   防火墙；
-   路由器；
-   负载均衡。

------------------------------------------------------------------------

优势：

-   降低硬件成本；
-   快速部署网络服务；
-   提高资源利用率。

# 10. 通信网络案例分析

## 案例一：低时延业务需求

问题：

传统云中心距离用户较远。

方案：

> 采用MEC边缘计算，将计算资源部署到靠近用户的位置，降低访问时延，提高实时处理能力。

------------------------------------------------------------------------

## 案例二：网络资源动态调整

问题：

传统网络配置复杂。

方案：

> 采用SDN架构，实现控制平面和数据平面分离，通过集中控制提高网络管理灵活性。

------------------------------------------------------------------------

## 案例三：快速部署网络服务

问题：

专用硬件部署周期长。

方案：

> 采用NFV技术，将网络功能软件化，实现快速部署和弹性扩展。

------------------------------------------------------------------------

# 11. 案例分析答题模板

## 网络低时延

> 采用MEC边缘计算，将计算资源下沉到用户附近，减少数据传输距离，提高业务响应速度。

------------------------------------------------------------------------

## 网络灵活管理

> 采用SDN架构，通过控制层集中管理网络资源，实现网络自动化配置和动态调整。

------------------------------------------------------------------------

## 网络快速扩展

> 采用NFV技术，将网络功能虚拟化，提高资源利用率和业务部署效率。

# 13. 易错点

  易错知识            正确理解
  ------------------- --------------------------
  MEC就是普通云计算   MEC强调靠近用户部署
  SDN只是交换机技术   SDN是一种网络架构思想
  NFV等于虚拟机       NFV是网络功能虚拟化
  网络可靠只靠备份    需要综合冗余、切换和监控
