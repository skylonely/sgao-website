# 易错点

  易错知识               正确理解
  ---------------------- --------------------------------
  产品管理只是需求管理   产品管理还包括市场、规划和运营
  AI可以替代产品经理     AI主要辅助分析和决策
  只关注用户需求         需要结合商业价值和技术成本
  产品上线即结束         产品需要持续运营和优化
