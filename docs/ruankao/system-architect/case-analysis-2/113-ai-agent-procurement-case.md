# 案例分析答题模板

## 采购效率低

> 建设采购智能体，通过自动分析采购需求和供应商信息提升采购效率。

## 供应商选择困难

> 引入供应商推荐Agent，通过数据分析实现供应商智能匹配。

## 采购成本高

> 建设智能比价Agent，通过价格分析优化采购成本。

## 供应链风险高

> 引入风险分析Agent，实现供应商风险预测和预警。

# 易错点

  易错知识                    正确理解
  --------------------------- --------------------------------------
  采购Agent只是自动询价工具   需要覆盖需求、寻源、分析和决策全过程
  只需要供应商数据            还需要采购知识和业务流程
  价格最低就是最佳采购        需要综合考虑质量、风险和交付能力
  AI可以完全替代采购人员      实际采用人机协同模式
