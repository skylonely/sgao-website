# 易错点

  易错知识                    正确理解
  --------------------------- ------------------------------------
  测试Agent只是自动执行工具   需要覆盖测试设计、执行、分析全过程
  只需要测试模型              还需要测试知识、数据和工程流程
  AI生成用例无需验证          仍需要测试人员审核
  AI可以完全替代测试人员      实际采用人机协同模式
