## 一、单项选择题

### 1. 数据库三级模式结构中，用于描述数据库整体逻辑结构的是（）。

A. 外模式\
B. 模式\
C. 内模式\
D. 存储模式

**答案：** B

------------------------------------------------------------------------

### 2. 下列属于关系代数基本运算的是（）。

A. 自然连接\
B. 并\
C. 外连接\
D. 排序

**答案：** B

------------------------------------------------------------------------

### 3. 若组合键的一部分即可决定某非主属性，则属于（）。

A. 完全函数依赖\
B. 部分函数依赖\
C. 传递函数依赖\
D. 多值依赖

**答案：** B

------------------------------------------------------------------------

### 4. 第二范式（2NF）的核心目标是（）。

A. 保证属性原子性\
B. 消除部分函数依赖\
C. 消除传递函数依赖\
D. 消除多值依赖

**答案：** B

------------------------------------------------------------------------

### 5. 能够防止读脏数据的是（）。

A. 一级封锁协议\
B. 二级封锁协议\
C. 一级封锁协议和二级封锁协议\
D. 一级封锁协议和三级封锁协议

**答案：** B

------------------------------------------------------------------------

### 6. SQL 中用于分组后的条件过滤的是（）。

A. WHERE\
B. ORDER BY\
C. GROUP BY\
D. HAVING

**答案：** D

------------------------------------------------------------------------

### 7. 下列数据库中，更适合表示复杂关系网络的是（）。

A. 键值数据库\
B. 文档数据库\
C. 图数据库\
D. 列族数据库

**答案：** C

## 三、综合分析题

### 题目

已知关系：

```text
Student(
  Sno,
  Name,
  ClassName,
  ClassTeacher
)
```

函数依赖：

```text
Sno → Name
Sno → ClassName
ClassName → ClassTeacher
```

请回答：

1.  是否存在传递函数依赖？
2.  当前关系最高属于哪一级范式？
3.  如何进行规范化？

### 参考思路

-   存在 `Sno → ClassName → ClassTeacher` 的传递函数依赖。
-   应将班级信息拆分为独立关系，以消除传递函数依赖。
