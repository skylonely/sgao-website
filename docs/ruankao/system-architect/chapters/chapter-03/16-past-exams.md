# 第十五节 历年真题（Past Exams）

## 高频真题考点

### 数据库基础

**考查重点：**

-   DB、DBMS、DBS 区别
-   三级模式与两级映像
-   数据独立性

**常见问法：**

-   哪种映像保证逻辑独立性？
-   哪种映像保证物理独立性？

------------------------------------------------------------------------

### E-R 模型与数据库设计

重点：

-   实体
-   属性
-   联系
-   E-R 转关系模型
-   数据库设计六阶段

------------------------------------------------------------------------

### 关系代数

重点运算：

-   选择
-   投影
-   并
-   差
-   笛卡尔积
-   自然连接

常见题型：

-   判断关系代数表达式含义
-   根据查询要求写出关系代数表达式

------------------------------------------------------------------------

### 函数依赖与范式

重点：

-   函数依赖
-   部分函数依赖
-   传递函数依赖
-   Armstrong 公理
-   1NF
-   2NF
-   3NF
-   BCNF

典型题型：

-   判断所属范式
-   判断是否存在部分依赖、传递依赖
-   根据函数依赖进行规范化。

------------------------------------------------------------------------

### 模式分解

重点：

-   无损连接
-   保持函数依赖
-   属性闭包

常见题型：

-   判断分解是否无损
-   判断是否保持函数依赖

------------------------------------------------------------------------

### 并发控制

重点：

-   ACID
-   丢失修改
-   读脏数据
-   不可重复读
-   一级、二级、三级封锁协议

------------------------------------------------------------------------

### SQL

重点：

-   DDL
-   DML
-   DCL
-   SELECT
-   GROUP BY
-   HAVING
-   JOIN

------------------------------------------------------------------------

### 新型数据库

重点：

-   NoSQL
-   键值数据库
-   文档数据库
-   列族数据库
-   图数据库

------------------------------------------------------------------------

## 综合分析题答题模板

1.  明确题目涉及知识点；
2.  写出关键定义；
3.  根据函数依赖、事务或 SQL 等进行分析；
4.  给出最终结论并说明理由。
