# 二、可靠性指标总结

## MTTF

平均无故障时间。

## MTTR

平均修复时间。

## MTBF

平均故障间隔时间。

公式：

``` text
MTBF = MTTF + MTTR
```

## 可用性

公式：

``` text
可用性 = MTTF / (MTTF + MTTR) × 100%
```

提高可用性：

-   增大 MTTF；
-   减少 MTTR。

-   分析故障规律；

-   评价可靠性水平。

组成：

-   模型假设；
-   性能度量；
-   参数估计；
-   数据要求。

分类：

  类型       作用
  ---------- ----------------
  预测模型   预测未来可靠性
  估计模型   评价当前可靠性

## 冗余设计

  类型       说明
  ---------- --------------



# 九、易错点总结

  易错点                   正确理解
  ------------------------ ------------------------
  软件会自然老化           软件主要因设计缺陷失效
  MTTR是无故障时间         MTTR是修复时间
  MTBF等于MTTF             MTBF=MTTF+MTTR
  N版本属于动态冗余        N版本属于静态冗余
  恢复块同时运行多个版本   恢复块采用主备切换
  热备两台同时工作         热备是一主一备
