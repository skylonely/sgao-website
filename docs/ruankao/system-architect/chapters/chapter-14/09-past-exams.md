# 2. 基本概念真题

## 题目1

软件可靠性是指：

A. 软件运行速度\
B. 软件在规定条件和时间内完成规定功能的能力\
C. 软件代码数量\
D. 软件界面效果

答案：

``` text
B
```

------------------------------------------------------------------------

## 题目2

软件故障主要来源：

A. 硬件磨损\
B. 软件设计和实现缺陷\
C. 电源故障\
D. 机械损坏

答案：

``` text
B
```

------------------------------------------------------------------------

# 3. 可靠性指标真题

## 题目3

MTBF表示：

答案：

``` text
平均故障间隔时间
```

公式：

``` text
MTBF = MTTF + MTTR
```

------------------------------------------------------------------------

## 题目4

已知：

``` text
MTTF = 900小时
MTTR = 100小时
```

系统可用性：

公式：

``` text
A = MTTF / (MTTF + MTTR)
```

结果：

``` text
90%
```

# 8. 易错点总结

  知识点      正确理解
  ----------- --------------------
  MTTF        平均无故障时间
  MTTR        平均修复时间
  MTBF        MTTF+MTTR
  N版本程序   静态冗余
  恢复块      动态冗余
  热备        主机运行，备用等待
