# 三、计算题

## 可用性计算

公式：

``` text
可用性 = MTTF / (MTTF + MTTR)
```

示例：

``` text
MTTF=900小时
MTTR=100小时

可用性=900/(900+100)=90%
```

------------------------------------------------------------------------

## 串联系统可靠性

公式：

``` text
R = R1 × R2 × ... × Rn
```

------------------------------------------------------------------------

## 并联系统可靠性

公式：

``` text
R = 1-(1-R1)(1-R2)...(1-Rn)
```
