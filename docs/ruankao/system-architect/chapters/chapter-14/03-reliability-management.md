# 1. 软件可靠性管理概述

软件可靠性管理是指在软件生命周期过程中，通过计划、组织、控制和评价等活动，保证软件达到规定可靠性要求的管理过程。

软件可靠性管理不是某一个开发阶段的工作，而是贯穿：

-   需求分析；
-   软件设计；
-   编码实现；
-   软件测试；
-   软件运行维护。

------------------------------------------------------------------------

# 2. 软件可靠性管理目标

软件可靠性管理的主要目标：

-   确定可靠性要求；
-   制定可靠性目标；
-   保证软件达到可靠性指标；
-   降低软件故障风险。

可靠性管理需要同时关注：

-   软件质量；
-   开发过程；
-   测试过程；
-   运行维护。

------------------------------------------------------------------------

# 3. 软件可靠性计划

可靠性计划是在软件开发开始阶段制定的可靠性管理方案。

主要内容包括：

## 3.1 确定可靠性目标

根据系统需求确定：

-   可用性要求；
-   故障率要求；
-   可靠性指标。

------------------------------------------------------------------------

## 3.2 制定可靠性活动

包括：

-   可靠性分析；
-   可靠性设计；
-   可靠性测试；
-   可靠性评价。

------------------------------------------------------------------------

## 3.3 确定评价方法

明确：

-   测试方法；
-   数据收集方法；
-   评价模型。

------------------------------------------------------------------------

# 4. 生命周期可靠性活动

软件可靠性管理贯穿软件生命周期。

------------------------------------------------------------------------

## 4.1 需求阶段

主要活动：

-   分析可靠性需求；
-   确定可靠性指标。

------------------------------------------------------------------------

## 4.2 设计阶段

主要活动：

-   选择可靠性设计方法；
-   进行容错设计；
-   进行冗余设计。

------------------------------------------------------------------------

## 4.3 编码阶段

主要活动：

-   遵循编码规范；
-   减少程序错误。

------------------------------------------------------------------------

## 4.4 测试阶段

主要活动：

-   可靠性测试；
-   故障分析；
-   可靠性评价。

------------------------------------------------------------------------

## 4.5 运行维护阶段

主要活动：

-   收集运行数据；
-   分析故障原因；
-   改进软件可靠性。

------------------------------------------------------------------------

# 5. 软件可靠性保障

软件可靠性保障主要通过技术和管理措施保证软件质量。

主要措施：

## 5.1 过程控制

通过规范开发过程减少错误。

包括：

-   需求评审；
-   设计评审；
-   代码检查。

------------------------------------------------------------------------

## 5.2 测试保障

通过测试发现和修复缺陷。

包括：

-   功能测试；
-   可靠性测试；
-   压力测试。

------------------------------------------------------------------------

## 5.3 数据分析

通过收集：

-   故障数据；
-   运行数据；

评价软件可靠性。

------------------------------------------------------------------------

# 6. 可靠性管理过程

典型过程：

``` text
制定可靠性计划

↓

↓

收集可靠性数据

↓

评价可靠性水平

↓

持续改进
```

# 8. 易错点

  易错知识                 正确理解
  ------------------------ ----------------------------
  可靠性只属于测试阶段     贯穿整个生命周期
  可靠性管理只关注代码     包含需求、设计、测试和维护
  测试可以完全保证可靠性   测试只能发现部分问题
  可靠性计划等于测试计划   可靠性计划范围更广
