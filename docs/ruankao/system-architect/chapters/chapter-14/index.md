# 二、本章重点知识

## 1. 软件可靠性基本概念

软件可靠性：

> 软件产品在规定条件下和规定时间内完成规定功能的能力。

重点指标：

  指标   含义
  ------ ------------------
  MTTF   平均无故障时间
  MTTR   平均修复时间
  MTBF   平均故障间隔时间

公式：

``` text
MTBF = MTTF + MTTR
```

系统可用性：

``` text
可用性 = MTTF / (MTTF + MTTR) × 100%
```

# 三、软件可靠性设计重点

软件可靠性设计主要包括：

-   容错设计
-   检错设计
-   冗余设计
-   N版本程序设计
-   恢复块设计
-   防式程序设计

其中：

## N版本程序设计

通过多个独立版本程序同时执行，由表决机制选择正确结果。

## 恢复块设计

通过主模块和备用模块切换，提高系统可靠性。
