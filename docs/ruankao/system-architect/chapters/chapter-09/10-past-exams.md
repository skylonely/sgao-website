# 3. 典型真题（依据课程资料）

## 真题一

**下列属于对称加密算法的是（ ）**

A. RSA

B. AES

C. ECC

D. Diffie-Hellman

**答案：B** 

---

## 真题二

**数字签名主要用于实现（ ）**

A. 数据压缩

B. 身份认证和不可否认性

C. 数据备份

D. 数据复制

**答案：B** 

---

## 真题三

**HTTPS 是由哪两部分组成？**

A. HTTP + SSH

B. HTTP + SSL/TLS

C. HTTP + IPSec

D. HTTP + PGP

**答案：B**
