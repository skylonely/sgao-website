# 第九章章节练习

> 本练习覆盖信息安全基础、密码技术、访问控制、网络攻击与防护、安全体系、网络安全技术及网络安全协议。

---

# 一、单项选择题

## 1. 信息安全五大属性中，用于保证数据未经授权不能修改的是（ ）

A. 保密性  
B. 完整性  
C. 可用性  
D. 可控性

**答案：B**

**解析：**完整性强调数据保持正确、完整，不被非法篡改。

---

## 2. 下列属于对称加密算法的是（ ）

A. RSA  
B. ECC  
C. AES  
D. Diffie-Hellman

**答案：C**

---

## 3. 数字签名主要用于实现（ ）

A. 数据压缩  
B. 身份认证和不可否认性  
C. 数据备份  
D. 网络隔离

**答案：B**

---

## 4. 下列属于 TCP 拒绝服务攻击的是（ ）

A. DNS 欺骗  
B. SYN Flood  
C. ARP 欺骗  
D. ICMP Redirect

**答案：B**

---

## 5. IDS 与 IPS 的主要区别是（ ）

A. IDS 能主动阻断攻击  
B. IPS 只能记录日志  
C. IPS 能检测并主动阻断攻击  
D. 两者没有区别

**答案：C**

---

## 6. HTTPS 的本质是（ ）

A. HTTP + IPSec  
B. HTTP + SSL/TLS  
C. HTTP + SSH  
D. HTTP + PGP

**答案：B**

---

# 二、判断题

1. 保密性表示数据不能被非法泄露。（√）

2. RSA 属于对称加密算法。（×）

3. ACL 用于描述主体对客体的访问权限。（√）

4. SSH 主要用于安全远程登录。（√）

5. Kerberos 基于票据（Ticket）进行身份认证。（√）
