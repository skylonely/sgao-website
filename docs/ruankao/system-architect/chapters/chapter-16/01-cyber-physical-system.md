# 1. CPS 概述

信息物理系统（Cyber Physical System，CPS）是未来信息技术的重要发展方向。

CPS 通过：

-   感知技术；
-   计算技术；
-   通信技术；
-   控制技术；

实现物理世界与信息空间之间的深度融合。

CPS 将计算、网络和物理过程结合起来，使系统能够：

-   感知环境；
-   分析数据；
-   做出决策；
-   自动控制。

------------------------------------------------------------------------

# 2. CPS 定义

CPS 是控制系统、嵌入式系统的扩展与延伸。

其核心思想：

> 通过信息空间与物理空间的融合，实现对物理对象的实时感知、动态控制和智能服务。

CPS 包含：

-   物理实体；
-   传感设备；
-   计算资源；
-   通信网络；
-   控制系统。

------------------------------------------------------------------------

# 3. CPS 产生背景

随着信息技术发展，传统系统面临：

## 3.1 物理系统智能化需求

传统设备需要具备：

-   感知能力；
-   计算能力；
-   通信能力；
-   自动控制能力。

------------------------------------------------------------------------

## 3.2 信息技术融合需求

需要将：

-   计算机技术；
-   网络技术；
-   自动控制技术；

融合到物理系统中。

------------------------------------------------------------------------

## 3.3 智能应用发展需求

应用领域需要：

-   实时数据采集；
-   智能分析；
-   自动决策。

------------------------------------------------------------------------

# 4. CPS 基本特征

CPS 主要特点：

## 4.1 物理空间与信息空间融合

CPS 将真实物理对象映射到数字空间。

------------------------------------------------------------------------

## 4.2 实时感知

通过传感设备获取物理环境状态。

------------------------------------------------------------------------

## 4.3 实时计算

利用计算资源分析采集的数据。

------------------------------------------------------------------------

## 4.4 实时控制

根据分析结果对物理对象进行控制。

------------------------------------------------------------------------

## 4.5 网络连接

通过通信网络实现设备之间的信息交互。

------------------------------------------------------------------------

# 5. CPS 体系结构

CPS 体系结构通常分为三个层级：

``` text
单元级 CPS

↓

系统级 CPS

↓

SoS级 CPS
```

------------------------------------------------------------------------

# 5.1 单元级 CPS

单元级 CPS 是最基本的 CPS 单元。

特点：

具备：

-   感知能力；
-   计算能力；
-   通信能力；
-   控制能力。

例如：

-   智能设备；
-   智能机器人。

------------------------------------------------------------------------

# 5.2 系统级 CPS

系统级 CPS 由多个单元级 CPS 通过网络连接形成。

特点：

-   多设备协同；
-   数据共享；
-   状态监控；
-   协同控制。

例如：

-   智能生产系统。

------------------------------------------------------------------------

# 5.3 SoS级 CPS

SoS（System of Systems）表示系统之系统。

多个系统级 CPS 进一步组合形成更大规模系统。

特点：

-   系统规模更大；
-   多系统协同；
-   跨领域融合。

例如：

-   智慧城市；
-   智能交通系统。

------------------------------------------------------------------------
