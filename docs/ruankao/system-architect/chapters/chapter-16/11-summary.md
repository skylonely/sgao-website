# 二、信息物理系统 CPS 总结

CPS（Cyber Physical System）通过：

-   感知技术；
-   计算技术；
-   通信技术；
-   控制技术；

实现物理空间和信息空间融合。

## CPS三级结构

``` text
单元级CPS

↓

系统级CPS

↓

SoS级CPS
```

重点：

-   单元级：基础功能单元；
-   系统级：多个单元协同；
-   SoS级：多个系统组合。

## 四种学习方式

  类型         特点
  ------------ ---------------------
  监督学习     使用标签数据
  无监督学习   自动发现规律
  半监督学习   少量标签+大量无标签

# 六、边缘计算总结

边缘计算核心思想：

> 将计算能力部署到靠近数据产生源的位置。

体系结构：

``` text
云计算中心

↓

边缘节点

↓

终端设备
```

特点：

1.  联接性；
2.  数据第一入口；
3.  约束性；
4.  分布性。

# 十、技术之间关系总结

未来信息技术不是独立存在，而是相互融合。

``` text
          AI
           |
           |
大数据 —— 智能系统 —— 数字孪生
           |
           |
        CPS
           |
       边缘计算
           |
        云计算
           |
        机器人
```

关系：

-   大数据提供数据基础；
-   AI提供智能分析能力；
-   云计算提供资源能力；
-   边缘计算提供实时能力；
-   CPS连接物理世界；
-   数字孪生实现虚实映射；
-   机器人完成智能执行。

# 十二、易错点总结

  易错点                 正确理解
  ---------------------- ----------------------------------
  CPS就是物联网          CPS进一步包含计算和控制
  AI等于机器学习         机器学习只是AI的重要技术
  边缘计算替代云计算     二者是协同关系
  数字孪生只是三维模型   包含模型、数据和分析能力
  SaaS提供基础设施       SaaS提供软件服务
  大数据只是数据量大     还包括速度、多样性、真实性和价值

# 十四、本章总结

第十六章主要考查未来信息技术的基本概念和技术关系。

复习重点：

-   掌握各技术定义；
-   理解各技术解决的问题；
-   掌握技术之间融合关系；
-   能结合实际场景进行架构分析。

核心思想：

> 未来智能信息系统将通过 CPS 连接物理世界，通过 AI
> 实现智能，通过云边协同提供计算能力，通过大数据实现价值挖掘。
