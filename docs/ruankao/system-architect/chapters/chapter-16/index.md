# 一、信息物理系统（CPS）

## 1. CPS概念

信息物理系统（Cyber Physical
System，CPS）是控制系统、嵌入式系统的扩展与延伸。

通过：

-   感知技术；
-   计算技术；
-   通信技术；
-   控制技术；

实现物理空间与信息空间的融合。

------------------------------------------------------------------------

## 2. CPS体系结构

包括：

### 单元级CPS

最小功能单元，具有：

-   感知能力；
-   计算能力；
-   通信能力；
-   控制能力。

------------------------------------------------------------------------

### 系统级CPS

多个单元级CPS通过工业网络连接，实现：

-   数据共享；
-   协同控制；
-   状态监控。

------------------------------------------------------------------------

### SoS级CPS

多个系统级CPS组成更大规模系统。

例如：

-   智能工厂；
-   智慧城市。

------------------------------------------------------------------------

# 二、人工智能（AI）

人工智能利用计算机模拟、延伸和扩展人的智能。

主要目标：

-   感知环境；
-   获取知识；
-   推理决策；
-   完成智能任务。

------------------------------------------------------------------------

# 三、机器人技术

机器人技术进入4.0时代。

主要特点：

-   云端智能；
-   边缘计算；
-   自主学习；
-   自适应能力。

核心技术：

-   云边端协同计算；
-   持续学习；
-   知识图谱；
-   场景自适应；
-   数据安全。

------------------------------------------------------------------------

# 四、边缘计算

边缘计算将计算能力从云中心下沉到网络边缘。

特点：

-   靠近数据源；
-   降低网络延迟；
-   提升实时处理能力。

主要协同：

-   资源协同；
-   数据协同；
-   智能协同；
-   应用管理协同；
-   业务管理协同；
-   服务协同。

------------------------------------------------------------------------

# 五、数字孪生体

数字孪生体通过数字化方式建立物理对象模型，实现物理世界和数字世界交互。

核心技术：

-   建模；
-   仿真；
-   VR/AR；
-   物联网；
-   AI；
-   大数据；
-   边缘计算。

应用：

-   制造业；
-   城市管理；
-   工业系统。

------------------------------------------------------------------------

# 七、大数据

大数据是无法通过传统工具在合理时间内完成处理的数据集合。

特点：

-   大规模；
-   高速度；
-   多样化；
-   可变性；
-   复杂性。
