# 1. 人工智能概述

人工智能（Artificial Intelligence，AI）是未来信息技术的重要组成部分。

人工智能通过计算机技术模拟、延伸和扩展人的智能，使计算机能够完成：

-   感知；
-   学习；
-   推理；
-   决策；
-   执行。

AI 是实现智能化信息系统的重要基础。

------------------------------------------------------------------------

# 2. 人工智能定义

人工智能是利用计算机模拟、延伸和扩展人的智能的一门技术。

其目标是使机器具备类似人的智能能力，包括：

-   感知能力；
-   认知能力；
-   学习能力；
-   推理能力；
-   决策能力。

------------------------------------------------------------------------

# 3. 人工智能发展目标

人工智能主要目标：

## 3.1 感知环境

通过：

-   图像；
-   声音；
-   文本；
-   传感数据；

获取外部信息。

------------------------------------------------------------------------

## 3.2 获取知识

通过数据和算法：

-   学习规律；
-   建立知识模型。

------------------------------------------------------------------------

## 3.3 智能推理

根据已有知识：

-   分析问题；
-   推导结果。

------------------------------------------------------------------------

## 3.4 智能决策

根据环境变化：

-   选择行动方案；
-   完成目标任务。

------------------------------------------------------------------------

# 4. 人工智能关键技术

人工智能主要技术包括：

-   自然语言处理（NLP）；
-   计算机视觉；
-   知识图谱；
-   人机交互（HCI）；
-   虚拟现实与增强现实；
-   机器学习。

------------------------------------------------------------------------

# 5. 自然语言处理 NLP

自然语言处理（Natural Language
Processing，NLP）研究计算机理解、处理和生成自然语言。

目标：

使计算机能够：

-   理解人类语言；
-   分析语言信息；
-   生成人类可理解内容。

------------------------------------------------------------------------

## NLP 应用

包括：

-   机器翻译；
-   智能客服；
-   语音助手；
-   文本分析；
-   智能问答。

------------------------------------------------------------------------

# 6. 计算机视觉

计算机视觉研究如何让计算机理解图像和视频信息。

主要能力：

-   图像获取；
-   图像识别；
-   图像分析；
-   视觉理解。

------------------------------------------------------------------------

## 应用场景

包括：

-   人脸识别；
-   图像分类；
-   智能监控；
-   自动驾驶。

------------------------------------------------------------------------

# 7. 知识图谱

知识图谱通过建立实体之间的关系，形成结构化知识网络。

基本组成：

-   实体；
-   属性；
-   关系。

表示形式：

``` text
实体

↓

关系

↓

实体
```

------------------------------------------------------------------------

## 知识图谱作用

包括：

-   知识表示；
-   知识查询；
-   智能推理；
-   辅助决策。

------------------------------------------------------------------------

# 8. 人机交互 HCI

人机交互（Human Computer
Interaction，HCI）研究人与计算机之间的信息交换方式。

目标：

提高：

-   交互效率；
-   用户体验；
-   系统易用性。

------------------------------------------------------------------------

## 典型交互方式

包括：

-   图形界面；
-   语音交互；
-   手势交互；
-   虚拟交互。

------------------------------------------------------------------------

# 9. 虚拟现实 VR 与增强现实 AR

## 9.1 虚拟现实 VR

VR（Virtual Reality）通过计算机创建虚拟环境。

特点：

-   沉浸式体验；
-   三维交互。

------------------------------------------------------------------------

## 9.2 增强现实 AR

AR（Augmented Reality）将虚拟信息叠加到真实环境。

特点：

-   虚实结合；
-   实时增强。

------------------------------------------------------------------------

# 12. 易错点

  易错知识               正确理解
  ---------------------- --------------------------------
  AI只是机器学习         机器学习只是AI的重要技术之一
  NLP只负责语音识别      NLP包括语言理解、处理和生成
  VR和AR完全相同         VR创建虚拟环境，AR增强真实环境
  知识图谱只有数据存储   知识图谱还包含关系和推理
