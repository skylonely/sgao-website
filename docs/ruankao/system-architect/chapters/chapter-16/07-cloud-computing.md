# 1. 云计算概述

云计算（Cloud Computing）是未来信息技术的重要基础。

云计算通过网络将计算、存储、软件等资源以服务形式提供给用户。

用户无需购买和维护大量基础设施，即可按需使用计算资源。

------------------------------------------------------------------------

# 2. 云计算定义

云计算是一种通过网络提供计算资源的服务模式。

主要资源包括：

-   计算资源；
-   存储资源；
-   网络资源；
-   软件服务。

核心思想：

> 将计算能力作为一种公共服务提供。

------------------------------------------------------------------------

# 3. 云计算特点

## 3.1 按需服务

用户根据需求：

-   获取资源；
-   使用服务。

------------------------------------------------------------------------

## 3.2 资源池化

将计算、存储等资源集中管理。

特点：

-   统一调度；
-   动态分配。

------------------------------------------------------------------------

## 3.3 弹性扩展

根据业务变化：

-   增加资源；
-   减少资源。

------------------------------------------------------------------------

## 3.4 快速部署

云资源可以快速创建和释放。

------------------------------------------------------------------------

## 3.5 泛在访问

用户可以通过网络访问云服务。

------------------------------------------------------------------------

典型结构：

``` text

```

包括：

-   服务层；

------------------------------------------------------------------------

# 5. 云计算服务模式

云计算主要服务模式：

``` text
SaaS

↓

PaaS

↓

IaaS
```

从上到下：

-   用户控制能力逐渐降低；
-   云服务商提供能力逐渐增强。

------------------------------------------------------------------------

# 6. SaaS（Software as a Service）

软件即服务。

特点：

云服务商提供完整软件。

用户：

-   直接使用软件；
-   不需要管理底层资源。

例如：

-   在线办公软件；
-   在线业务系统。

------------------------------------------------------------------------

# 7. PaaS（Platform as a Service）

平台即服务。

特点：

提供应用开发和运行平台。

包括：

-   开发环境；
-   数据库服务；
-   中间件平台。

用户关注：

-   应用开发；
-   业务逻辑。

------------------------------------------------------------------------

# 8. IaaS（Infrastructure as a Service）

基础设施即服务。

提供：

-   虚拟机；
-   存储；
-   网络资源。

用户可以管理：

-   操作系统；
-   应用程序。

------------------------------------------------------------------------

# 9. 三种服务模式对比

  模式   提供内容   用户关注
  ------ ---------- ----------
  SaaS   软件服务   使用软件
  PaaS   开发平台   开发应用
  IaaS   基础设施   管理系统

------------------------------------------------------------------------

# 10. 云计算部署模式

## 10.1 公有云

资源由云服务商提供。

特点：

-   面向公众；
-   资源共享。

------------------------------------------------------------------------

## 10.2 私有云

云环境专属于某个组织。

特点：

-   安全性高；
-   可控性强。

------------------------------------------------------------------------

## 10.3 社区云

多个具有共同需求的组织共同使用。

------------------------------------------------------------------------

## 10.4 混合云

结合：

-   公有云；
-   私有云。

特点：

兼顾灵活性和安全性。

------------------------------------------------------------------------

# 11. 云计算与边缘计算关系

云计算：

-   强计算能力；
-   大规模存储；
-   全局分析。

边缘计算：

-   靠近数据源；
-   低延迟处理；
-   实时响应。

两者关系：

``` text
终端

↓

边缘计算

↓

云计算
```

形成云边端协同体系。
