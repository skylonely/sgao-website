# 1. 边缘计算概述

随着物联网、人工智能和智能设备的发展，大量数据在网络边缘产生。

传统云计算模式：

``` text
终端设备

↓

网络

↓

云计算中心

↓

数据处理
```

存在：

-   网络延迟较高；
-   数据传输压力大；
-   实时响应能力不足。

边缘计算通过将计算能力下沉到靠近数据源的位置，提高系统实时处理能力。

------------------------------------------------------------------------

# 2. 边缘计算定义

边缘计算（Edge Computing）是指：

> 将计算、存储和智能服务能力部署在靠近数据产生源的网络边缘，为用户提供低延迟、高可靠的服务。

核心思想：

将部分云端计算任务迁移到边缘节点。

------------------------------------------------------------------------

# 3. 边缘计算产生背景

主要原因：

## 3.1 数据规模快速增长

物联网设备产生大量数据：

-   传感数据；
-   视频数据；
-   工业数据。

------------------------------------------------------------------------

## 3.2 实时业务需求提高

部分应用要求：

-   快速响应；
-   低延迟处理。

例如：

-   自动驾驶；
-   工业控制。

------------------------------------------------------------------------

## 3.3 云计算压力增加

大量数据上传云端会造成：

-   网络压力；
-   计算压力；
-   存储压力。

------------------------------------------------------------------------

典型结构：

``` text
云计算中心

↓

↓

终端设备
```

------------------------------------------------------------------------

## 4.1 云端

主要负责：

-   大规模数据处理；

-   全局资源管理。

------------------------------------------------------------------------

## 4.2 边缘节点

主要负责：

-   数据预处理；
-   实时计算；
-   智能分析。

------------------------------------------------------------------------

## 4.3 终端设备

负责：

-   数据采集；
-   信息感知；
-   执行控制。

------------------------------------------------------------------------

# 5. 边缘计算特点

## 5.1 联接性

支持大量设备连接。

特点：

-   设备数量多；
-   网络连接复杂。

------------------------------------------------------------------------

## 5.2 数据第一入口

边缘节点靠近数据产生位置。

优势：

-   减少数据传输；
-   提高处理效率。

------------------------------------------------------------------------

## 5.3 约束性

边缘设备通常具有资源限制。

需要考虑：

-   计算能力；
-   存储能力；
-   能耗。

------------------------------------------------------------------------

## 5.4 分布性

边缘计算资源分布在多个位置。

特点：

-   分布式部署；
-   多节点协同。

------------------------------------------------------------------------

# 6. 边缘计算与云计算关系

云计算和边缘计算不是替代关系，而是协同关系。

## 云计算优势

-   强大计算能力；
-   海量存储；
-   全局分析。

------------------------------------------------------------------------

## 边缘计算优势

-   低延迟；
-   实时处理；
-   减少网络压力。

------------------------------------------------------------------------

典型模式：

``` text
终端

↓

边缘计算

↓

云计算
```

------------------------------------------------------------------------

# 7. 云边协同

云边协同是边缘计算的重要模式。

通过云端和边缘节点合作：

-   云端负责复杂计算；
-   边缘负责实时处理；
-   终端负责数据采集。

实现：

-   资源优化；
-   快速响应；
-   智能服务。

------------------------------------------------------------------------

# 11. 易错点

  易错知识               正确理解
  ---------------------- --------------------------
  边缘计算替代云计算     两者是协同关系
  边缘计算就是本地计算   边缘计算包含网络边缘节点
  数据全部上传云端处理   边缘计算强调就近处理
  边缘节点只负责存储     边缘节点也负责计算和分析
