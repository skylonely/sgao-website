# 一、信息物理系统 CPS 真题

## 1. 信息物理系统（CPS）的核心思想是：

A. 提高计算机硬件性能\
B. 实现物理空间与信息空间融合\
C. 只进行数据存储\
D. 替代互联网

答案：

``` text
B
```

解析：

CPS通过感知、计算、通信和控制，实现物理世界与信息世界融合。

------------------------------------------------------------------------

## 2. CPS体系结构中，多个系统级CPS进一步组合形成：

A. 单元级CPS\
B. 系统级CPS\
C. SoS级CPS\
D. 终端级CPS

``` text

```

-   理解技术概念；

-   能结合实际场景进行技术选型分析。
