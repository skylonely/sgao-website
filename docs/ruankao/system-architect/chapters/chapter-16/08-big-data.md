# 1. 大数据概述

大数据（Big Data）是未来信息技术的重要组成部分。

随着：

-   互联网发展；
-   物联网普及；
-   智能设备增加；

数据规模快速增长，传统数据处理技术难以满足海量数据处理需求。

大数据技术通过：

-   数据采集；
-   数据存储；
-   数据处理；
-   数据分析；

从大量数据中发现价值。

------------------------------------------------------------------------

# 2. 大数据定义

大数据是指：

> 无法通过传统数据处理工具在合理时间内完成采集、存储、管理和分析的数据集合。

大数据不仅关注数据规模，更关注：

-   数据处理能力；
-   数据价值发现；
-   智能分析能力。

------------------------------------------------------------------------

# 3. 大数据产生背景

## 3.1 数据规模快速增长

数据来源包括：

-   互联网数据；
-   企业业务数据；
-   传感器数据；
-   视频数据。

------------------------------------------------------------------------

## 3.2 数据类型不断丰富

包括：

-   结构化数据；
-   半结构化数据；
-   非结构化数据。

------------------------------------------------------------------------

## 3.3 数据价值需求提高

企业和组织希望通过数据：

-   发现规律；
-   辅助决策；
-   优化业务。

------------------------------------------------------------------------

# 4. 大数据特点

大数据通常具有 5V 特征：

------------------------------------------------------------------------

## 4.1 Volume（大量）

数据规模巨大。

包括：

-   海量文件；
-   海量记录；
-   海量设备数据。

------------------------------------------------------------------------

## 4.2 Velocity（高速）

数据产生和处理速度快。

例如：

-   实时交易；
-   实时监控。

------------------------------------------------------------------------

## 4.3 Variety（多样）

数据类型丰富。

包括：

-   文本；
-   图片；
-   视频；
-   音频；
-   传感数据。

------------------------------------------------------------------------

## 4.4 Veracity（真实性）

关注数据质量。

包括：

-   准确性；
-   完整性；
-   可靠性。

------------------------------------------------------------------------

## 4.5 Value（价值）

从大量数据中发现有价值的信息。

------------------------------------------------------------------------

# 5. 大数据技术体系

大数据技术主要包括：

-   数据采集技术；
-   数据存储技术；
-   数据处理技术；
-   数据分析技术；
-   数据可视化技术。

------------------------------------------------------------------------

# 6. 大数据处理流程

典型流程：

``` text
数据获取

↓

信息抽取

↓

数据清洗/注记

↓

数据集成

↓

数据聚集

↓

数据分析

↓

建模和结果解释
```

------------------------------------------------------------------------

# 7. 数据采集

数据采集是大数据处理的第一步。

数据来源：

-   业务系统；
-   网络日志；
-   传感器；
-   用户行为数据。

目标：

获取原始数据。

------------------------------------------------------------------------

# 8. 数据预处理

数据预处理包括：

-   数据清洗；
-   数据转换；
-   数据筛选。

作用：

提高数据质量，为后续分析提供可靠基础。

------------------------------------------------------------------------

# 9. 数据集成

数据集成是将多个来源的数据进行统一处理。

解决：

-   数据格式不同；
-   数据来源不同；
-   数据结构不同。

------------------------------------------------------------------------

# 10. 数据分析

数据分析通过算法发现数据中的规律。

包括：

-   统计分析；
-   预测分析；
-   机器学习分析。

目标：

实现：

-   辅助决策；
-   业务优化；
-   价值发现。

------------------------------------------------------------------------

------------------------------------------------------------------------

------------------------------------------------------------------------

## 工业领域

应用：

-   预测维护；
-   智能制造。

------------------------------------------------------------------------

# 12. 大数据与人工智能关系

大数据为人工智能提供：

-   训练数据；
-   分析基础。

人工智能帮助大数据：

-   智能分析；
-   自动发现规律。

二者相互促进。
