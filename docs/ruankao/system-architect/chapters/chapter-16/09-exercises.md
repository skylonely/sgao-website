# 一、信息物理系统 CPS 练习

## 1. 信息物理系统 CPS 的核心目标是什么？

A. 只提高计算机性能\
B. 实现物理空间与信息空间融合\
C. 替代所有人工操作\
D. 只实现数据存储

答案：

``` text
B
```

解析：

CPS 通过感知、计算、通信和控制技术，实现物理世界与信息世界融合。

## 3. CPS 体系结构中规模最大的是：

A. 单元级 CPS\
B. 系统级 CPS\
C. SoS级 CPS\
D. 设备级 CPS
