# 1. 机器学习概述

机器学习（Machine Learning，ML）是人工智能的重要技术之一。

机器学习通过：

-   数据；
-   算法；
-   模型；

使计算机能够从数据中自动学习规律，并根据学习结果完成预测、分类和决策。

机器学习是实现人工智能的重要基础。

------------------------------------------------------------------------

# 2. 机器学习定义

机器学习是研究如何让计算机通过数据和经验自动改进性能的方法。

与传统程序不同：

传统程序：

``` text
规则 + 数据

↓

程序结果
```

机器学习：

``` text
数据 + 结果样本

↓

学习模型

↓

预测结果
```

------------------------------------------------------------------------

# 3. 机器学习基本流程

典型流程：

``` text
数据采集

↓

数据预处理

↓

特征提取

↓

模型训练

↓

模型评估

↓

模型应用
```

------------------------------------------------------------------------

## 3.1 数据采集

获取用于训练的数据。

来源：

-   业务数据；
-   传感数据；
-   图像数据；
-   文本数据。

------------------------------------------------------------------------

## 3.2 数据预处理

包括：

-   数据清洗；
-   数据转换；
-   数据筛选。

目的：

提高数据质量。

------------------------------------------------------------------------

## 3.3 模型训练

利用算法从数据中学习规律。

------------------------------------------------------------------------

## 3.4 模型评估

评价模型：

-   准确性；
-   泛化能力；
-   稳定性。

------------------------------------------------------------------------

# 4. 机器学习分类

按照学习方式，机器学习主要分为：

``` text
机器学习

├── 监督学习
├── 无监督学习
├── 半监督学习
└── 强化学习
```

------------------------------------------------------------------------

# 5. 监督学习

监督学习（Supervised Learning）是利用带标签的数据进行学习。

特点：

-   数据包含输入和输出；
-   学习输入与输出之间的关系。

------------------------------------------------------------------------

## 5.1 主要任务

包括：

### 分类

预测数据所属类别。

例如：

-   垃圾邮件识别；
-   图像分类。

------------------------------------------------------------------------

### 回归

预测连续数值。

例如：

-   房价预测；
-   销量预测。

------------------------------------------------------------------------

# 6. 无监督学习

无监督学习（Unsupervised Learning）使用没有标签的数据进行学习。

特点：

-   不提供明确答案；
-   自动发现数据规律。

------------------------------------------------------------------------

## 6.1 常见任务

### 聚类

将相似数据划分为不同类别。

例如：

-   用户分类；
-   市场分析。

------------------------------------------------------------------------

### 关联分析

发现数据之间的关联关系。

------------------------------------------------------------------------

# 7. 半监督学习

半监督学习结合：

-   少量有标签数据；
-   大量无标签数据。

特点：

降低人工标注成本。

适用于：

-   数据量大；
-   标注困难的场景。

------------------------------------------------------------------------

# 8. 强化学习

强化学习（Reinforcement Learning）通过环境反馈进行学习。

基本过程：

``` text
智能体

↓

执行动作

↓

环境反馈

↓

获得奖励

↓

优化策略
```

------------------------------------------------------------------------

## 强化学习特点

-   通过试错学习；
-   根据奖励调整行为；
-   目标是获得最大收益。

应用：

-   自动驾驶；
-   游戏AI；
-   机器人控制。

------------------------------------------------------------------------

# 9. 深度学习

深度学习（Deep Learning）是机器学习的重要方向。

特点：

利用深层神经网络自动学习特征。

------------------------------------------------------------------------

## 深度学习优势

-   自动特征提取；
-   处理复杂数据；
-   支持大规模数据训练。

------------------------------------------------------------------------

## 应用领域

包括：

-   图像识别；
-   语音识别；
-   自然语言处理。

------------------------------------------------------------------------

------------------------------------------------------------------------

## 自动驾驶

------------------------------------------------------------------------

# 11. 监督学习、无监督学习、强化学习对比

  类型         数据                  特点
  ------------ --------------------- ------------------
  监督学习     有标签数据            学习输入输出关系
  无监督学习   无标签数据            自动发现规律
  半监督学习   少量标签+大量无标签   降低标注成本
  强化学习     环境反馈              通过奖励优化策略
