# 第五章 计算机网络

> **说明：** 本章依据《第五章
> 计算机网络》教材整理，重点介绍网络功能与分类、OSI 七层模型、TCP/IP
> 协议、IP 地址、IPv6、网络规划、网络存储等内容。

## 本章概述

计算机网络是系统架构设计师考试的重要章节，通常每年占 **3～5
分**。本章围绕网络体系结构、协议、通信方式、IP
地址与网络规划等内容展开，是考试中的高频章节。

## 学习目标

完成本章后，应能够：

-   理解计算机网络的基本功能与分类
-   掌握 OSI 七层模型与 TCP/IP 协议体系
-   熟悉常见网络协议及应用场景
-   掌握 IPv4 地址、子网划分与 IPv6
-   理解网络规划、网络存储及相关考点
