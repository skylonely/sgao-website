## 高频考点

-   网络功能与分类
-   OSI 七层模型
-   TCP/IP 协议族
-   网络设备（Hub、交换机、路由器、网关）
-   IPv4 地址、子网掩码、CIDR、子网划分
-   IPv6
-   路由技术（MTU、IGP、EGP）
-   网络规划与网络存储（NAS、SAN）

## 易错点

| 知识点 | 易错内容 |
| --- | --- |
| OSI 七层 | 协议、设备对应层次混淆 |
| TCP / UDP | 是否面向连接、是否可靠 |
| ARP / RARP | 地址解析方向容易混淆 |
| Hub / Switch / Router | 工作层次与转发依据混淆 |
| IPv4 / IPv6 | 地址长度与表示方式混淆 |
| NAS / SAN | 文件级与存储网络概念混淆 |
