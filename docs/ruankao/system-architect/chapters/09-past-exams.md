# 第一章历年真题整理

> **重要说明**
> 本文根据你提供的《计算机硬件》资料整理，仅收录资料中的历年真题及其知识点，不新增模拟题。

## CPU

### 真题1

**题目**

CPU 执行算术运算或逻辑运算时，常将源操作数和结果存放在（）。

A. 程序计数器（PC）

B. 累加器（AC）

C. 指令寄存器（IR）

D. 地址寄存器（AR）

**答案：B**

**考点**

-   AC（累加器）的作用
-   CPU 寄存器功能

------------------------------------------------------------------------

### 真题2

**题目**

执行 CPU 指令时，一个指令周期开始首先需要将（
）内容送到地址总线，以便从内存读取下一条指令。

A. IR

B. GR

C. PC

D. PSW

**答案：C**

**考点**

-   PC 保存下一条指令地址
-   指令周期

------------------------------------------------------------------------

## CRC

### 真题3

**题目**

已知数据位为 1100，生成多项式为 X³+X+1（1011），求 CRC 编码。

**答案：1100010**

**考点**

-   CRC 编码流程
-   模2除法
-   生成多项式

------------------------------------------------------------------------

## 流水线

### 真题4

资料包含两类流水线计算题：

-   吞吐率计算
-   加速比计算

**核心公式**

```text
流水线执行时间：
(k+n-1) × t

吞吐率：
指令数 / 执行时间

加速比：
非流水执行时间 / 流水执行时间
```

### 真题7

资料包含 DMA 与 CPU、中断方式区别的选择题。
