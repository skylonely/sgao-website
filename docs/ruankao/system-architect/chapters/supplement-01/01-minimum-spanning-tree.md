# 1. 最小生成树概述

最小生成树（Minimum Spanning Tree，MST）是图论中的经典优化问题。

主要用于解决：

> 在保证所有节点连通的情况下，使连接成本最小的问题。

典型应用：

-   网络线路建设；
-   通信系统规划；
-   城市基础设施建设；
-   资源连接优化。

------------------------------------------------------------------------

# 2. 图的基本概念

最小生成树建立在连通图基础上。

一个图通常表示为：

``` text
G = (V, E)
```

其中：

-   V：顶点集合；
-   E：边集合。

如果每条边具有权值，则表示：

-   距离；
-   成本；
-   时间；
-   费用。

------------------------------------------------------------------------

# 3. 最小生成树定义

对于一个连通无向加权图：

最小生成树是：

> 包含图中全部顶点的一棵生成树，并且所有边的权值之和最小。

------------------------------------------------------------------------

# 4. 最小生成树特点

## 4.1 包含所有顶点

生成树必须连接：

-   图中的全部节点。

------------------------------------------------------------------------

## 4.2 边数固定

如果图有 n 个顶点：

最小生成树包含：

``` text
n - 1 条边
```

------------------------------------------------------------------------

## 4.3 不存在环

最小生成树是一棵树：

-   任意两个节点之间只有一条路径；
-   不存在回路。

------------------------------------------------------------------------

## 4.4 总权值最小

所有可能生成树中：

选择：

> 边权值总和最小的一棵。

------------------------------------------------------------------------

# 5. Prim算法

Prim算法是一种基于顶点扩展的最小生成树算法。

## 5.1 基本思想

从任意一个顶点开始：

1.  将一个节点加入生成树；
2.  选择连接已选节点和未选节点的最小权值边；
3.  加入新的节点；
4.  重复上述过程。

------------------------------------------------------------------------

## 5.2 算法过程

``` text
选择起始节点

↓

寻找最小边

↓

加入新节点

↓

更新候选边

↓

重复直到所有节点加入
```

------------------------------------------------------------------------

## 5.3 特点

优点：

-   适合稠密图；
-   思路直观。

------------------------------------------------------------------------

# 6. Kruskal算法

Kruskal算法是一种基于边选择的最小生成树算法。

## 6.1 基本思想

按照边权值从小到大排序：

1.  选择最小边；
2.  判断是否产生环；
3.  不产生环则加入；
4.  继续选择下一条边。

------------------------------------------------------------------------

## 6.2 算法过程

``` text
所有边排序

↓

选择最小边

↓

判断是否形成环

↓

加入生成树

↓

直到选择 n-1 条边
```

------------------------------------------------------------------------

## 6.3 特点

优点：

-   适合稀疏图；
-   实现简单。

------------------------------------------------------------------------

# 7. Prim与Kruskal比较

  对比项       Prim算法     Kruskal算法
  ------------ ------------ -------------
  基本思想     顶点扩展     边选择
  操作对象     节点         边
  是否排序边   不需要       需要
  适合场景     稠密图       稀疏图
  核心判断     最小连接边   是否形成环

------------------------------------------------------------------------

# 8. 典型应用

## 8.1 网络建设

例如：

多个城市建设通信线路。

目标：

-   所有城市连通；
-   总建设成本最低。

------------------------------------------------------------------------

## 8.2 计算机网络设计

例如：

规划：

-   局域网连接；
-   网络拓扑结构。

------------------------------------------------------------------------

## 8.3 工程成本优化

用于：

-   管道铺设；
-   电力线路规划；
-   交通线路设计。

------------------------------------------------------------------------

重点掌握：

1.  最小生成树定义；
2.  n个节点需要n-1条边；
3.  最小生成树不能有环；
4.  Prim算法思想；
5.  Kruskal算法思想；
6.  两种算法适用场景。

------------------------------------------------------------------------

# 10. 易错点

  易错知识                    正确理解
  --------------------------- ----------------------------------------
  最小生成树要求路径最短      最小生成树要求总边权最小
  最小生成树可以有环          生成树不能有环
  节点数量等于边数量          n个节点对应n-1条边
  Prim和Kruskal结果一定不同   对同一图可能得到不同形式但相同最小权值

------------------------------------------------------------------------

# 12. 本节小结

最小生成树用于解决：

> 如何以最低成本连接所有节点。

考试重点：

-   理解最小生成树定义；
-   掌握 Prim 算法；
-   掌握 Kruskal 算法；
-   能够根据题目要求选择合适方法。
