# 1. 决策树概述

决策树（Decision Tree）是一种用于辅助决策分析的图形化方法。

它通过树形结构表示：

-   决策方案；
-   可能状态；
-   状态概率；
-   最终收益。

主要用于：

> 在多个方案和不确定环境下，选择最优决策方案。

应用：

-   项目投资；
-   工程方案选择；
-   企业经营决策。

------------------------------------------------------------------------

# 2. 决策树定义

决策树是：

> 用树形结构描述决策过程，并通过分析不同路径结果选择最佳方案的方法。

特点：

-   结构直观；
-   能表示多阶段决策；
-   可以结合概率计算期望收益。

------------------------------------------------------------------------

# 3. 决策树基本组成

决策树主要包括：

``` text
决策节点

↓

状态节点

↓

结果节点
```

------------------------------------------------------------------------

# 4. 决策节点

决策节点表示：

> 需要进行方案选择的位置。

通常表示为：

``` text
□
```

例如：

选择：

-   方案A；
-   方案B。

决策者需要在此选择行动。

------------------------------------------------------------------------

# 5. 状态节点

状态节点表示：

> 决策之后可能出现的环境状态。

通常表示为：

``` text
○
```

例如：

市场可能：

-   高需求；
-   正常需求；
-   低需求。

每种状态通常具有概率。

------------------------------------------------------------------------

# 6. 结果节点

结果节点表示：

> 某种方案和状态组合产生的最终结果。

例如：

-   收益；
-   成本；
-   损失。

------------------------------------------------------------------------

# 7. 决策树表示方法

基本结构：

``` text
       决策点

          □

       /     \

   方案A     方案B

     |         |

     ○         ○

   状态1     状态2

     |         |

   收益值    收益值
```

------------------------------------------------------------------------

# 8. 期望收益计算

风险型决策中：

通常使用期望收益。

公式：

``` text
期望收益 = Σ(收益 × 概率)
```

例如：

某方案：

状态1：

收益100，概率0.6

状态2：

收益50，概率0.4

则：

``` text
期望收益

=100×0.6+50×0.4
```

# 9. 决策树分析步骤

## 第一步：确定决策方案

列出：

-   可选择方案。

------------------------------------------------------------------------

## 第二步：确定可能状态

分析：

-   未来可能发生情况。

------------------------------------------------------------------------

## 第三步：建立决策树

绘制：

-   决策节点；
-   状态节点；
-   结果节点。

------------------------------------------------------------------------

## 第四步：计算期望值

根据：

-   收益；
-   概率。

计算期望结果。

------------------------------------------------------------------------

## 第五步：选择最佳方案

比较：

不同方案期望收益。

选择：

最大收益方案。

# 13. 易错点

  易错知识               正确理解
  ---------------------- ----------------------
  决策节点表示随机事件   决策节点表示主动选择
  状态节点表示选择方案   状态节点表示随机状态
  所有决策只看最大收益   风险决策需要考虑概率
  决策树只能用于投资     可用于多种决策分析
