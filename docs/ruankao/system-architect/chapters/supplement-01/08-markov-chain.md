# 1. 状态转移矩阵概述

状态转移矩阵是一种描述系统状态变化规律的数学工具。

主要研究：

> 系统从当前状态转变到下一状态的概率关系。

应用场景：

-   市场占有率变化；
-   用户行为分析；
-   系统状态预测；
-   风险分析。

------------------------------------------------------------------------

# 2. 马尔可夫链定义

马尔可夫链（Markov Chain）是一类随机过程。

其核心思想：

> 系统未来状态只与当前状态有关，而与过去经历无关。

即：

当前状态决定未来变化。

------------------------------------------------------------------------

# 3. 马尔可夫性质

马尔可夫性质：

``` text
未来状态

只依赖

当前状态
```

不需要考虑：

-   更早的历史状态；
-   完整变化过程。

------------------------------------------------------------------------

# 4. 状态与状态转移概率

## 4.1 状态

状态表示：

> 系统在某一时刻所处的情况。

例如：

市场竞争：

``` text
A品牌

B品牌

C品牌
```

每个品牌代表一个状态。

------------------------------------------------------------------------

## 4.2 状态转移概率

表示：

从一个状态转移到另一个状态的概率。

例如：

``` text
P(A→B)=0.2
```

表示：

当前处于A状态时，下一周期进入B状态的概率为20%。

------------------------------------------------------------------------

# 5. 状态转移矩阵

状态转移矩阵表示：

所有状态之间的转移概率。

形式：

``` text
P =
[p11 p12 ... p1n]

[p21 p22 ... p2n]

...

[pn1 pn2 ... pnn]
```

其中：

pij 表示：

从状态 i 转移到状态 j 的概率。

------------------------------------------------------------------------

# 6. 转移矩阵特点

## 6.1 每个概率非负

满足：

``` text
pij ≥ 0
```

------------------------------------------------------------------------

## 6.2 每行概率和为1

对于每个状态：

``` text
Σpij = 1
```

表示：

当前状态一定会转移到某个下一状态。

------------------------------------------------------------------------

# 7. 多步状态转移

一次转移：

表示：

一个周期后的状态变化。

两次转移：

使用：

``` text
P²
```

一般：

n步转移：

``` text
Pⁿ
```

------------------------------------------------------------------------

状态计算：

``` text
下一状态分布

=

当前状态分布 × 转移矩阵
```

即：

``` text
S(n+1)=S(n)×P
```

------------------------------------------------------------------------

# 8. 稳态分析

长期运行后：

系统可能达到稳定状态。

特点：

``` text
稳定状态 × 转移矩阵

=

稳定状态
```

表示：

经过长期变化后，各状态比例保持稳定。

------------------------------------------------------------------------

# 12. 易错点

  易错知识                     正确理解
  ---------------------------- -------------------
  马尔可夫链需要完整历史信息   只依赖当前状态
  转移矩阵中的概率可以大于1    概率范围为0\~1
  每列概率和一定为1            通常每行概率和为1
  状态转移就是最优选择         它描述概率变化
