# 1. 动态规划概述

动态规划（Dynamic Programming，DP）是一种解决复杂优化问题的方法。

主要思想：

> 将一个复杂问题分解为多个阶段，通过保存中间计算结果，逐步得到整体最优解。

动态规划常用于：

-   资源分配；
-   投资规划；
-   路径优化；
-   多阶段决策。

------------------------------------------------------------------------

# 2. 动态规划定义

动态规划是：

> 将一个多阶段决策问题分解为若干相互联系的阶段，通过状态转移关系求得最优决策方案的方法。

核心：

-   阶段划分；
-   状态描述；
-   决策选择；
-   状态转移。

------------------------------------------------------------------------

# 3. 动态规划核心思想

动态规划的核心是：

## 分解问题

将复杂问题划分为：

``` text
多个阶段的小问题
```

------------------------------------------------------------------------

## 保存结果

避免重复计算：

``` text
保存已经计算的状态
```

------------------------------------------------------------------------

## 最优组合

通过局部最优选择：

得到整体最优结果。

------------------------------------------------------------------------

# 4. 多阶段决策过程

动态规划通常用于：

多阶段决策问题。

结构：

``` text
阶段1

↓

阶段2

↓

阶段3

↓

最终结果
```

每个阶段都有：

-   当前状态；
-   可选决策；
-   状态变化。

------------------------------------------------------------------------

# 5. 状态与状态转移

## 5.1 状态

状态表示：

> 某个阶段系统所处的情况。

例如：

-   当前资源数量；
-   当前位置；
-   当前时间。

------------------------------------------------------------------------

## 5.2 状态转移

状态转移表示：

从当前状态经过决策：

进入下一状态。

形式：

``` text
当前状态 + 决策

↓

下一状态
```

------------------------------------------------------------------------

# 6. 最优子结构

动态规划的重要特点：

## 最优子结构

表示：

> 一个问题的最优解包含其子问题的最优解。

例如：

整体最优方案：

由多个阶段最优决策组合形成。

------------------------------------------------------------------------

# 7. 动态规划求解步骤

## 第一步：划分阶段

确定问题：

-   分几个阶段；
-   每个阶段含义。

------------------------------------------------------------------------

## 第二步：确定状态

描述每个阶段：

-   当前情况；
-   状态变量。

------------------------------------------------------------------------

## 第三步：建立状态转移方程

描述：

状态之间如何变化。

例如：

``` text
F(n)=最优结果
```

------------------------------------------------------------------------

## 第四步：确定初始条件

设置：

-   起始状态；
-   初始值。

------------------------------------------------------------------------

## 第五步：逐步计算最优解

通过状态转移：

得到最终结果。

------------------------------------------------------------------------

# 8. 动态规划与线性规划区别

  对比       动态规划         线性规划
  ---------- ---------------- --------------
  核心       状态转移         线性优化
  问题特点   多阶段决策       资源优化
  模型       非固定阶段状态   线性数学模型
  方法       递推求解         单纯形等方法

------------------------------------------------------------------------

------------------------------------------------------------------------

## 9.2 投资规划

# 10. 动态规划特点

## 优点

-   能处理复杂多阶段问题；
-   避免重复计算；
-   可以得到全局最优解。

------------------------------------------------------------------------

## 缺点

-   状态设计困难；
-   状态数量过多时计算复杂。

# 12. 易错点

  易错知识                   正确理解
  -------------------------- --------------------------
  动态规划就是分治算法       动态规划需要保存中间状态
  每一步最优就是最终最优     需要满足最优子结构
  动态规划只能解决路径问题   可用于多种优化问题
  动态规划和线性规划相同     两者模型和方法不同

# 14. 本节小结

动态规划用于解决具有阶段结构的复杂优化问题。

考试重点：

-   理解动态规划思想；
-   掌握阶段、状态、决策、状态转移概念；
