# 1. 博弈论概述

博弈论（Game Theory）是研究多个参与者在相互影响环境下进行决策的方法。

与传统优化问题不同：

单个决策者的问题：

``` text
选择方案

↓

获得结果
```

而博弈问题：

``` text
参与者A决策

↓

影响参与者B

↓

B再次决策

↓

形成最终结果
```

------------------------------------------------------------------------

# 2. 博弈论定义

博弈论研究：

> 多个理性参与者在相互影响的情况下，如何选择策略并获得收益。

核心特点：

-   存在多个参与者；
-   参与者之间相互影响；
-   每个参与者根据利益选择策略。

------------------------------------------------------------------------

# 3. 博弈基本要素

一个完整博弈通常包含：

-   参与者（Players）；
-   策略（Strategies）；
-   收益（Payoffs）。

表示：

``` text
参与者

↓

选择策略

↓

产生收益
```

------------------------------------------------------------------------

# 4. 参与者

参与者是：

> 在博弈过程中进行决策的主体。

例如：

-   企业；
-   国家；
-   个人；
-   系统。

特点：

每个参与者都有自己的目标。

------------------------------------------------------------------------

# 5. 策略

策略表示：

> 参与者可以选择的行动方案。

例如：

企业竞争：

``` text
高价格策略

低价格策略
```

不同策略组合会产生不同结果。

------------------------------------------------------------------------

# 6. 收益函数

收益表示：

> 某种策略组合下参与者获得的结果。

收益可以表示：

-   利润；
-   成本；
-   效益；
-   得分。

目标：

参与者通常希望最大化自身收益。

------------------------------------------------------------------------

# 7. 博弈类型

## 7.1 合作博弈

参与者之间：

-   可以合作；
-   共同制定方案。

目标：

实现整体利益最大化。

------------------------------------------------------------------------

## 7.2 非合作博弈

参与者：

-   独立决策；
-   追求自身利益。

------------------------------------------------------------------------

## 7.3 零和博弈

特点：

一方收益增加：

另一方收益减少。

总收益：

``` text
保持不变
```

------------------------------------------------------------------------

## 7.4 非零和博弈

特点：

参与者收益之和：

可以增加或减少。

可能存在：

-   合作；
-   共赢。

------------------------------------------------------------------------

# 8. 纳什均衡

纳什均衡（Nash Equilibrium）是博弈论的重要概念。

定义：

> 在其他参与者策略保持不变时，任何参与者都没有动力单独改变自己的策略。

简单理解：

达到一种稳定状态。

------------------------------------------------------------------------

# 9. 博弈分析过程

基本步骤：

## 第一步：确定参与者

明确：

-   谁参与决策。

------------------------------------------------------------------------

## 第二步：确定策略集合

列出：

-   每个参与者可选择方案。

------------------------------------------------------------------------

## 第三步：建立收益矩阵

表示：

不同策略组合对应收益。

------------------------------------------------------------------------

## 第四步：分析均衡结果

寻找：

-   稳定策略；
-   最优选择。

------------------------------------------------------------------------

# 10. 典型应用

## 10.1 企业竞争

例如：

两个企业决定：

-   产品价格；
-   市场策略。

------------------------------------------------------------------------

## 10.2 网络安全

分析：

攻击者和防御者之间的策略选择。

------------------------------------------------------------------------

## 10.3 资源分配

分析：

多个主体竞争有限资源。

------------------------------------------------------------------------

## 10.4 经济管理

用于：

-   市场竞争分析；
-   投资决策。

------------------------------------------------------------------------

# 11. 博弈论与优化方法区别

  对比       博弈论     传统优化
  ---------- ---------- ------------
  决策者     多个       一个
  相互影响   有         通常无
  目标       策略竞争   寻找最优解
  方法       均衡分析   数学优化

# 13. 易错点

  易错知识                 正确理解
  ------------------------ ------------------------------
  博弈只有竞争没有合作     可以存在合作博弈
  博弈只研究经济问题       可用于安全、资源、管理等领域
  纳什均衡一定是全局最优   是稳定策略组合
  博弈只有两个参与者       可以有多个参与者

# 15. 本节小结

博弈论用于分析多个参与者相互影响条件下的决策问题。

考试重点：

-   理解博弈基本要素；
-   掌握博弈类型；
-   理解纳什均衡；
-   能结合经济管理场景进行分析。
