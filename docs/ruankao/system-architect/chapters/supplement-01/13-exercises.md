# 1. 最小生成树练习

## 练习1

一个包含 n 个顶点的连通无向图，其最小生成树包含多少条边？

A. n\
B. n-1\
C. n+1\
D. 2n

答案：

B

解析：

树结构满足：

``` text
边数 = 顶点数 - 1
```

# 2. 最短路径练习

## 练习1

Dijkstra算法适用于：

A. 任意带权图\
B. 含负权边图\
C. 非负权边图\
D. 无权图

答案：

C

解析：

Dijkstra算法要求边权值非负。


# 高频易错点总结

  知识点       易错点
  ------------ ----------------------
  最小生成树   与最短路径混淆
  Dijkstra     不能处理负权边
  最大流       关注流量不是距离
  线性规划     必须满足线性条件
  动态规划     需要状态转移
  伏格尔法     用于运输问题
  马尔可夫链   只依赖当前状态
  排队论       λ是到达率，μ是服务率
  决策论       区分风险型和不确定型
  决策树       区分节点类型
