# 三、图论与网络分析

## 1. 最小生成树

目标：

在保证所有节点连通的情况下，使边的总权值最小。

主要算法：

-   Prim算法；
-   Kruskal算法。

应用：

-   网络建设；
-   通信线路规划；
-   成本优化。

------------------------------------------------------------------------

## 2. 最短路径

目标：

寻找两个节点之间距离最短的路径。

典型算法：

-   Dijkstra算法。

应用：

-   网络路由；
-   路径规划。

------------------------------------------------------------------------

## 3. 最大流量

研究：

网络中从源点到汇点的最大可传输流量。

应用：

-   网络带宽规划；
-   资源调度。

------------------------------------------------------------------------

# 四、优化方法

## 1. 线性规划

在线性约束条件下：

求目标函数最大值或最小值。

典型问题：

-   生产计划；
-   资源分配；
-   成本优化。

------------------------------------------------------------------------

## 2. 动态规划

将复杂问题拆分为多个阶段的小问题。

核心思想：

``` text
阶段分解

↓

状态转移

↓

最优结果
```

------------------------------------------------------------------------

## 3. 伏格尔法

主要用于运输问题。

目标：

求运输成本最低方案。

------------------------------------------------------------------------
