# 1. 最短路径概述

最短路径（Shortest Path）是图论中的经典问题。

主要解决：

> 在一个带权图中，寻找两个节点之间总代价最小的路径。

路径中的权值可以表示：

-   距离；
-   时间；
-   成本；
-   网络传输代价。

------------------------------------------------------------------------

# 2. 图与路径基本概念

图通常表示为：

``` text
G = (V, E)
```

其中：

-   V：顶点集合；
-   E：边集合。

如果边具有权值，则称为：

加权图。

例如：

``` text
A ----5---- B

表示：

A到B的距离或成本为5
```

------------------------------------------------------------------------

# 3. 最短路径定义

最短路径是指：

> 从一个起始节点到目标节点之间，使路径权值总和最小的一条路径。

例如：

从节点 A 到节点 F：

可能存在多条路线：

``` text
A → B → F

A → C → D → F

A → E → F
```

选择：

总权值最小的路径。

------------------------------------------------------------------------

# 4. Dijkstra算法

Dijkstra算法是求解单源最短路径的经典算法。

适用条件：

-   带权图；
-   边权值非负。

主要思想：

> 从起始节点开始，不断选择当前距离最小的节点，并更新其他节点距离。

------------------------------------------------------------------------

# 5. Dijkstra算法步骤

## 第一步：初始化

设置：

-   起点距离为0；
-   其他节点距离为无穷大。

例如：

``` text
起点A = 0

其他节点 = ∞
```

------------------------------------------------------------------------

## 第二步：选择最近节点

从未确定节点中：

选择当前距离最小的节点。

------------------------------------------------------------------------

## 第三步：更新距离

通过该节点：

计算到其他节点的新距离。

如果：

新距离更小：

则更新。

------------------------------------------------------------------------

## 第四步：重复过程

不断执行：

``` text
选择最近节点

↓

更新距离

↓

确定最短路径
```

直到所有节点确定。

------------------------------------------------------------------------

# 6. Dijkstra算法流程

``` text
选择起点

↓

初始化距离

↓

选择距离最小节点

↓

更新相邻节点距离

↓

确定节点最短路径

↓

重复直到完成
```

------------------------------------------------------------------------

# 7. Dijkstra算法特点

## 优点

-   算法思想简单；
-   应用广泛；
-   适合网络路径计算。

------------------------------------------------------------------------

## 缺点

-   不适合存在负权边的图；
-   大规模图计算复杂度较高。

------------------------------------------------------------------------

# 9. 最短路径与最小生成树区别

  对比               最短路径           最小生成树
  ------------------ ------------------ ----------------------
  目标               两点之间距离最小   所有节点连接成本最低
  关注               一条路径           整个网络
  是否覆盖全部节点   不一定             必须
  典型算法           Dijkstra           Prim/Kruskal

# 11. 易错点

  易错知识                     正确理解
  ---------------------------- ----------------------
  最短路径就是最小生成树       两者目标不同
  Dijkstra可以处理负权边       Dijkstra要求非负权边
  最短路径一定经过最少节点     最短指权值最小
  只需要选择距离最近节点一次   需要不断更新距离
