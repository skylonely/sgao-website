# 1. 线性规划概述

线性规划（Linear Programming，LP）是运筹学中的重要优化方法。

主要用于解决：

> 在有限资源条件下，如何合理分配资源，使目标达到最大或最小。

典型问题：

-   最大利润；
-   最低成本；
-   最优资源配置。

------------------------------------------------------------------------

# 2. 线性规划定义

线性规划是：

> 在线性约束条件下，求线性目标函数最大值或最小值的一种数学优化方法。

特点：

-   目标函数是线性的；
-   约束条件是线性的；
-   决策变量通常为非负。

------------------------------------------------------------------------

# 3. 线性规划数学模型

一般形式：

``` text
目标函数：

max / min Z = c1x1 + c2x2 + ... + cnxn


约束条件：

a11x1+a12x2+...+a1nxn ≤ b1

...

am1x1+am2x2+...+amnxn ≤ bm


x1,x2,...,xn ≥ 0
```

------------------------------------------------------------------------

# 4. 决策变量

决策变量表示：

> 需要确定数量的未知变量。

例如：

生产两种产品：

``` text
x1 = 产品A生产数量

x2 = 产品B生产数量
```

决策变量决定最终方案。

------------------------------------------------------------------------

# 5. 目标函数

目标函数表示：

> 希望达到的优化目标。

主要包括：

## 最大化问题

例如：

-   最大利润；
-   最大产量。

表示：

``` text
max Z
```

------------------------------------------------------------------------

## 最小化问题

例如：

-   最小成本；
-   最短时间。

表示：

``` text
min Z
```

------------------------------------------------------------------------

# 6. 约束条件

约束条件表示：

> 实际问题中的限制因素。

例如：

资源限制：

``` text
原材料 ≤ 可用数量

生产时间 ≤ 总时间
```

形式：

``` text
ax ≤ b
```

------------------------------------------------------------------------

# 7. 线性规划标准形式

标准模型包括：

## 目标函数

``` text
max Z=CX
```

------------------------------------------------------------------------

## 约束条件

``` text
AX≤B
```

------------------------------------------------------------------------

## 非负约束

``` text
X≥0
```

------------------------------------------------------------------------

# 8. 求解方法

## 8.1 图解法

适用于：

-   两个决策变量。

步骤：

1.  建立坐标系；
2.  绘制约束区域；
3.  找可行解；
4.  确定最优点。

------------------------------------------------------------------------

## 8.2 单纯形法

单纯形法是线性规划的重要求解方法。

基本思想：

``` text
从一个可行解开始

↓

不断寻找更优解

↓

直到达到最优
```

------------------------------------------------------------------------

# 9. 典型应用

## 9.1 生产计划

问题：

如何安排产品生产数量，使利润最大。

------------------------------------------------------------------------

## 9.2 资源分配

问题：

如何分配有限资源，提高利用效率。

------------------------------------------------------------------------

## 9.3 成本控制

问题：

如何降低成本。

------------------------------------------------------------------------

## 9.4 运输规划

问题：

如何安排运输方案，使费用最低。

------------------------------------------------------------------------

# 10. 线性规划与动态规划区别

  对比   线性规划       动态规划
  ------ -------------- --------------
  方法   数学优化模型   阶段决策优化
  特点   线性关系       状态转移
  适用   资源分配       多阶段问题

# 12. 易错点

  易错知识                   正确理解
  -------------------------- ----------------------------------
  线性规划只能求最大值       可以求最大值和最小值
  变量没有限制               通常要求变量非负
  所有优化问题都是线性规划   只有线性目标和约束才属于线性规划
  动态规划等于线性规划       两者模型不同

# 14. 本节小结

线性规划用于解决：

> 在资源有限的情况下，通过数学模型寻找最优方案。

考试重点：

-   理解线性规划模型组成；
-   掌握目标函数和约束条件；
-   理解单纯形法思想；
-   能够分析实际优化问题。
