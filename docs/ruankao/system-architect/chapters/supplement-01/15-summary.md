# 2. 图论知识总结

## 最小生成树

目标：

最低成本连接所有节点。

重点：

``` text
边数 = n - 1
```

算法：

-   Prim
-   Kruskal

------------------------------------------------------------------------

## 最短路径

目标：

寻找两个节点之间成本最小路径。

重点算法：

Dijkstra。

注意：

-   单源最短路径；
-   不支持负权边。

------------------------------------------------------------------------

## 最大流

目标：

在容量限制下，使源点到汇点流量最大。

重点：

-   源点；
-   汇点；
-   容量；
-   增广路径。

------------------------------------------------------------------------

# 3. 优化方法总结

## 线性规划

三要素：

1.  决策变量；
2.  目标函数；
3.  约束条件。

------------------------------------------------------------------------

## 动态规划

核心：

> 通过状态转移求整体最优解。

重点：

-   阶段；
-   状态；
-   决策；
-   最优子结构。

------------------------------------------------------------------------

## 伏格尔法

应用：

运输问题。

公式：

``` text
罚数 = 第二小成本 - 最小成本
```

------------------------------------------------------------------------

# 4. 概率模型总结

## 马尔可夫链

核心：

> 未来状态只依赖当前状态。

重点：

-   状态；
-   转移概率；
-   转移矩阵。

------------------------------------------------------------------------

## 排队论

核心参数：

  参数   含义
  ------ --------
  λ      到达率
  μ      服务率
  ρ      利用率

公式：

``` text
ρ = λ / μ
```

------------------------------------------------------------------------

# 5. 决策分析总结

## 博弈论

基本要素：

-   参与者；
-   策略；
-   收益。

核心：

纳什均衡。

------------------------------------------------------------------------

## 决策论

三类决策：

  类型       特点
  ---------- ----------
  确定型     状态确定
  风险型     概率已知
  不确定型   概率未知

期望值：

``` text
E = Σ(收益 × 概率)
```

------------------------------------------------------------------------

## 决策树

组成：

-   决策节点；
-   状态节点；
-   结果节点。

------------------------------------------------------------------------

★★★★★

# 9. 易错点

  知识点       易错
  ------------ ------------------
  最短路径     与最小生成树混淆
  Dijkstra     可以处理负权边
  最大流       等同最长路径
  动态规划     等同分治
  马尔可夫链   依赖全部历史
  排队论       混淆λ和μ
  决策树       混淆节点类型
