# 1. 图论类真题

## 1.1 最小生成树

### 题目

在一个具有 n 个顶点的连通无向图中，其生成树包含的边数为：

A. n\
B. n-1\
C. n+1\
D. 2n

答案：

B

解析：

树结构特点：

``` text
边数 = 顶点数 - 1
```

------------------------------------------------------------------------

## 1.2 最短路径

### 题目

Dijkstra算法主要用于解决：

A. 最小生成树问题

B. 单源最短路径问题

C. 最大流问题

D. 排序问题

答案：

B

解析：

Dijkstra用于求单个源点到其他节点的最短路径。

------------------------------------------------------------------------

# 2. 优化方法类真题

## 2.1 线性规划

### 题目

线性规划模型通常包含：

A. 决策变量

B. 目标函数

C. 约束条件

D. 以上全部

答案：

D

解析：

线性规划三要素：

-   决策变量；
-   目标函数；
-   约束条件。

------------------------------------------------------------------------

## 2.2 动态规划

### 题目

动态规划求解问题的核心是：

A. 枚举所有可能方案

B. 状态转移

C. 随机搜索

D. 删除状态

答案：

B

解析：

动态规划通过状态转移关系求解最优方案。

------------------------------------------------------------------------

## 2.3 运输问题

### 题目

伏格尔法主要用于：

A. 最短路径

B. 运输问题

C. 最大流

D. 排队模型

答案：

B

解析：

伏格尔法是一种运输问题初始解求解方法。

------------------------------------------------------------------------

# 3. 概率模型类真题

## 3.1 马尔可夫链

### 题目

马尔可夫过程的特点是：

A. 依赖全部历史状态

B. 只依赖当前状态

C. 不存在随机性

D. 状态不能变化

答案：

B

解析：

马尔可夫性质：

未来状态只与当前状态有关。

------------------------------------------------------------------------

## 3.2 排队论

### 题目

排队系统中：

λ表示：

A. 服务率

B. 到达率

C. 利用率

D. 队列长度

答案：

B

解析：

λ表示单位时间平均到达数量。

μ表示服务率。

------------------------------------------------------------------------

# 4. 决策分析类真题

## 4.1 决策论

### 题目

风险型决策的特点是：

A. 状态概率已知

B. 状态概率未知

C. 状态唯一确定

D. 无收益分析

答案：

A

解析：

风险型决策已知各种状态发生概率。

------------------------------------------------------------------------

## 4.2 期望值法

### 题目

期望收益计算公式为：

答案：

``` text
期望收益 = Σ(收益 × 概率)
```

------------------------------------------------------------------------

## 4.3 决策树

### 题目

决策树中，方形节点表示：

A. 随机事件

B. 决策选择

C. 收益结果

D. 状态概率

答案：

B

解析：

方形：

决策节点。

圆形：

状态节点。

------------------------------------------------------------------------

# 5. 最大流类真题

## 题目

最大流问题中的两个特殊节点是：

A. 最大点和最小点

B. 源点和汇点

C. 输入点和输出点

D. 起点和终点

答案：

B

解析：

最大流模型包含：

-   源点 Source；
-   汇点 Sink。

------------------------------------------------------------------------

# 6. 数学建模类真题

## 题目

数学建模的一般流程正确的是：

A. 求解→建模→验证

B. 分析→假设→建模→求解→验证

C. 编程→计算→输出

D. 收集数据即可

答案：

B

解析：

标准流程：

``` text
问题分析

↓

模型假设

↓

建立模型

↓

模型求解

↓

模型验证
```

# 9. 易错知识总结

  知识点       常见错误
  ------------ ------------------------
  最短路径     与最小生成树混淆
  Dijkstra     认为可以处理负权边
  最大流       误认为寻找最长路径
  动态规划     等同于分治算法
  马尔可夫链   需要全部历史信息
  排队论       混淆λ和μ
  决策树       混淆决策节点和状态节点

# 本节小结

第十七章考试重点不是复杂计算，而是理解各种数学方法的应用场景。

复习重点：

-   区分不同模型解决的问题；
-   掌握核心公式和概念；
-   熟悉典型算法思想；
-   能根据场景选择正确方法。
