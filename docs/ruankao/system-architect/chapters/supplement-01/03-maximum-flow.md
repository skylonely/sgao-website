# 1. 网络流概述

网络流（Network Flow）是图论中的一种优化模型。

主要研究：

> 如何在网络中合理分配资源流动，使从起点到终点的传输量达到最大。

网络中的流可以表示：

-   数据传输；
-   物流运输；
-   资源分配；
-   通信容量。

------------------------------------------------------------------------

# 2. 最大流问题定义

最大流问题（Maximum Flow Problem）是指：

> 在满足网络容量限制条件下，从源点到汇点能够传输的最大流量。

目标：

使：

``` text
源点 → 汇点

传输量最大
```

------------------------------------------------------------------------

# 3. 网络流模型

一个网络流通常表示为：

``` text
G = (V, E)
```

其中：

-   V：节点集合；
-   E：边集合。

每条边具有容量：

``` text
c(u,v)
```

表示：

节点 u 到节点 v 最大允许通过的流量。

------------------------------------------------------------------------

# 4. 源点与汇点

网络流包含两个特殊节点：

## 4.1 源点（Source）

表示：

流量产生的位置。

记为：

``` text
S
```

------------------------------------------------------------------------

## 4.2 汇点（Sink）

表示：

流量最终到达的位置。

记为：

``` text
T
```

------------------------------------------------------------------------

网络流目标：

``` text
S

↓

中间节点

↓

T
```

使从 S 到 T 的流量最大。

------------------------------------------------------------------------

# 5. 容量限制

网络中每条边都有最大承载能力。

例如：

``` text
A ----10---- B
```

表示：

A到B最多传输10个单位流量。

约束：

实际流量不能超过边容量。

即：

``` text
流量 ≤ 容量
```

------------------------------------------------------------------------

# 6. 增广路径

增广路径是：

> 从源点到汇点的一条可以继续增加流量的路径。

最大流求解过程中：

不断寻找：

-   可增加流量的路径；
-   增加网络总流量。

------------------------------------------------------------------------

# 7. 最大流求解思想

经典方法：

## Ford-Fulkerson思想

基本过程：

``` text
初始化流量

↓

寻找增广路径

↓

增加路径流量

↓

更新剩余容量

↓

重复直到不存在增广路径
```

------------------------------------------------------------------------

# 8. 最大流特点

## 8.1 受容量限制

最大流不能超过网络总容量限制。

------------------------------------------------------------------------

## 8.2 寻找全局最优

目标：

不是寻找单条最佳路径，而是：

> 使整个网络传输能力最大。

------------------------------------------------------------------------

## 8.3 与割集有关

最大流等于最小割。

即：

``` text
最大流 = 最小割容量
```

------------------------------------------------------------------------

# 9. 最大流应用

## 9.1 网络通信

应用：

-   网络带宽规划；
-   数据传输优化。

------------------------------------------------------------------------

## 9.2 交通运输

应用：

-   道路容量分析；
-   运输能力规划。

------------------------------------------------------------------------

## 9.3 生产资源调度

应用：

-   资源分配；
-   生产能力分析。

------------------------------------------------------------------------

## 9.4 项目管理

应用：

-   任务资源分配；
-   流程优化。

------------------------------------------------------------------------

# 10. 最大流与最短路径区别

  对比       最大流           最短路径
  ---------- ---------------- ----------
  目标       流量最大         距离最小
  关注       网络传输能力     路径成本
  研究对象   多条路径组合     单条路径
  典型算法   Ford-Fulkerson   Dijkstra

# 12. 易错点

  易错知识                   正确理解
  -------------------------- ------------------------
  最大流就是最长路径         最大流关注传输总量
  最大流只考虑一条路线       最大流可以包含多条路径
  流量可以超过容量           流量不能超过边容量
  最大流和最短路径目标相同   两者优化目标不同

# 14. 本节小结

> 如何在容量限制条件下，使网络传输量达到最大。

-   理解网络流模型；
-   掌握源点、汇点、容量概念；
