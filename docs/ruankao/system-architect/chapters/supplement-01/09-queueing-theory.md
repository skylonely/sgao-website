# 1. 排队论概述

排队论（Queueing Theory）是研究服务系统中：

-   请求到达；
-   等待服务；
-   接受服务；
-   离开系统；

这一过程的数学理论。

主要研究：

> 如何合理配置服务能力，使等待时间和服务成本达到平衡。

应用：

-   计算机系统；
-   网络通信；
-   服务器资源规划；
-   服务窗口设计。

------------------------------------------------------------------------

# 2. 排队系统基本组成

一个完整排队系统通常包括：

``` text
输入过程

↓

排队过程

↓

服务过程

↓

离开系统
```

主要组成：

-   输入源；
-   等待队列；
-   服务机构。

------------------------------------------------------------------------

# 3. 输入过程

输入过程描述：

> 顾客或任务到达系统的规律。

例如：

-   用户访问服务器；
-   数据包进入网络；
-   客户到达服务窗口。

主要参数：

到达率：

``` text
λ
```

表示：

单位时间内平均到达数量。

------------------------------------------------------------------------

# 4. 服务过程

服务过程描述：

> 系统处理任务的能力。

主要参数：

服务率：

``` text
μ
```

表示：

单位时间内平均完成服务数量。

例如：

服务器：

-   每秒处理请求数量。

------------------------------------------------------------------------

# 5. 排队规则

排队规则表示：

任务接受服务的顺序。

常见规则：

## 先进先出 FIFO

先到先服务：

``` text
First In First Out
```

------------------------------------------------------------------------

## 后进先出 LIFO

后到先服务。

------------------------------------------------------------------------

## 优先级服务

根据任务重要程度决定顺序。

------------------------------------------------------------------------

# 6. 到达率 λ

到达率表示：

单位时间内进入系统的平均数量。

例如：

每分钟：

100个请求到达。

则：

``` text
λ = 100
```

------------------------------------------------------------------------

# 7. 服务率 μ

服务率表示：

单位时间内系统完成服务的平均数量。

例如：

服务器每秒处理：

1000个请求。

则：

``` text
μ = 1000
```

------------------------------------------------------------------------

# 8. 排队模型表示方法

常用 Kendall 标记法：

``` text
A/B/C
```

其中：

## 第一项 A

表示到达分布。

例如：

M：

Markov随机到达。

------------------------------------------------------------------------

## 第二项 B

表示服务时间分布。

例如：

M：

指数分布。

------------------------------------------------------------------------

## 第三项 C

表示服务台数量。

例如：

1：

一个服务台。

------------------------------------------------------------------------

# 9. M/M/1排队模型

M/M/1 是经典排队模型。

含义：

``` text
M

↓

M

↓

1
```

表示：

-   到达过程服从指数分布；
-   服务时间服从指数分布；
-   一个服务台。

------------------------------------------------------------------------

# 10. 排队性能指标

常见指标：

## 10.1 队列长度

表示：

等待服务的任务数量。

------------------------------------------------------------------------

## 10.2 等待时间

表示：

任务进入系统后等待服务的时间。

------------------------------------------------------------------------

## 10.3 系统利用率

表示：

服务资源繁忙程度。

通常：

``` text
ρ = λ / μ
```

当：

``` text
ρ < 1
```

系统可以稳定运行。

------------------------------------------------------------------------

# 14. 易错点

  易错知识               正确理解
  ---------------------- ------------------------
  λ表示服务能力          λ表示到达率
  μ表示任务到达速度      μ表示服务速度
  ρ越大系统越空闲        ρ越大表示越繁忙
  排队论只用于人工服务   可用于计算机和网络系统
