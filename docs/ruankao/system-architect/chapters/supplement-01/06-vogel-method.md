# 1. 运输问题概述

运输问题（Transportation Problem）是线性规划中的典型问题。

主要研究：

> 如何安排多个供应点向多个需求点运输资源，使运输成本最低。

典型场景：

-   商品运输；
-   生产配送；
-   仓储调度；
-   资源分配。

------------------------------------------------------------------------

# 2. 伏格尔法定义

伏格尔法（Vogel Approximation
Method，VAM）是一种求解运输问题初始可行解的方法。

核心目标：

> 通过考虑运输成本差异，选择更合理的运输路线，降低初始运输成本。

------------------------------------------------------------------------

# 3. 运输问题数学模型

运输问题包含：

## 供应点

表示资源提供方。

例如：

-   工厂；
-   仓库。

------------------------------------------------------------------------

## 需求点

表示资源需求方。

例如：

-   商店；
-   客户。

------------------------------------------------------------------------

## 运输成本

表示：

从供应点到需求点的单位运输费用。

------------------------------------------------------------------------

目标：

``` text
总运输成本最小
```

数学形式：

``` text
min Z = ΣΣ cij*xij
```

其中：

-   cij：单位运输成本；
-   xij：运输数量。

------------------------------------------------------------------------

# 4. 伏格尔法核心思想

伏格尔法认为：

如果某一行或列中：

最低成本和次低成本差距较大，

说明选择错误路线的损失较大。

因此：

优先处理：

> 运输成本差异最大的行或列。

------------------------------------------------------------------------

# 5. 罚数计算

罚数（Penalty）：

表示选择其他路线的机会成本。

计算方法：

``` text
罚数 = 第二小成本 - 最小成本
```

分别计算：

-   每一行罚数；
-   每一列罚数。

------------------------------------------------------------------------

# 6. 伏格尔法求解步骤

## 第一步：计算罚数

计算所有：

-   行罚数；
-   列罚数。

------------------------------------------------------------------------

## 第二步：选择最大罚数

找到：

> 罚数最大的行或列。

------------------------------------------------------------------------

## 第三步：选择最低成本单元

在该行或列中：

选择运输成本最低的位置。

------------------------------------------------------------------------

## 第四步：分配运输量

分配：

``` text
min(供应量,需求量)
```

------------------------------------------------------------------------

## 第五步：更新运输表

调整：

-   剩余供应量；
-   剩余需求量。

------------------------------------------------------------------------

## 第六步：重复计算

直到：

所有供应和需求满足。

------------------------------------------------------------------------

# 7. 伏格尔法特点

## 优点

-   初始解质量较高；
-   通常接近最优解；
-   计算过程适合人工求解。

------------------------------------------------------------------------

## 缺点

-   不能保证一定得到最优解；
-   大规模问题计算较复杂。

------------------------------------------------------------------------

# 8. 典型应用

## 8.1 物流运输

例如：

多个仓库向多个地区配送。

目标：

降低运输成本。

------------------------------------------------------------------------

## 8.2 生产供应链

应用：

-   原材料配送；
-   产品调拨。

------------------------------------------------------------------------

## 8.3 资源调度

应用：

-   人力安排；
-   设备分配。

------------------------------------------------------------------------

# 9. 伏格尔法与其他方法比较

  方法         特点
  ------------ ------------------------------
  西北角法     简单，但考虑成本较少
  最小成本法   优先选择最低运输成本
  伏格尔法     考虑成本差异，初始解质量较高

------------------------------------------------------------------------

# 11. 易错点

  易错知识                   正确理解
  -------------------------- --------------------------
  伏格尔法直接求最终最优解   通常用于求初始可行解
  罚数越小越优先选择         应选择最大罚数
  只计算行罚数               行和列都需要计算
  运输量随意分配             分配应满足供应和需求限制

# 13. 本节小结

伏格尔法用于解决运输问题，是一种基于罚数思想的启发式方法。

考试重点：

-   理解运输问题模型；
-   掌握罚数计算方法；
-   理解最大罚数选择原则；
-   区分伏格尔法与其他运输方法。
