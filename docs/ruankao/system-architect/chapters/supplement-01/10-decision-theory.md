# 1. 决策论概述

决策论（Decision Theory）是研究：

> 在不同环境条件下，如何选择最优行动方案的方法。

决策过程通常包括：

-   发现问题；
-   制定方案；
-   分析结果；
-   选择方案。

应用：

-   项目管理；
-   投资分析；
-   工程规划；
-   企业经营。

------------------------------------------------------------------------

# 2. 决策问题基本要素

一个完整决策问题包括：

## 2.1 决策者

进行方案选择的主体。

------------------------------------------------------------------------

## 2.2 决策方案

可供选择的行动方案。

例如：

-   方案A；
-   方案B。

------------------------------------------------------------------------

## 2.3 状态

表示未来可能出现的环境情况。

例如：

-   市场增长；
-   市场下降。

------------------------------------------------------------------------

## 2.4 收益

不同方案在不同状态下产生的结果。

例如：

-   利润；
-   成本；
-   效益。

------------------------------------------------------------------------

# 3. 决策矩阵

决策矩阵用于表示：

不同方案在不同状态下的收益。

形式：

``` text
        状态1   状态2

方案1    a11    a12

方案2    a21    a22
```

其中：

-   行表示方案；
-   列表示状态；
-   元素表示收益。

------------------------------------------------------------------------

# 4. 确定型决策

确定型决策特点：

> 未来状态已知，并且结果确定。

特点：

-   环境明确；
-   无概率因素。

方法：

直接选择收益最大或成本最低方案。

------------------------------------------------------------------------

# 5. 风险型决策

风险型决策特点：

> 未来可能出现多个状态，并且每个状态具有已知概率。

例如：

市场状态：

-   高增长；
-   正常；
-   低增长。

每种状态具有概率。

------------------------------------------------------------------------

# 6. 期望值法

期望值法是风险型决策常用方法。

公式：

``` text
期望值 = Σ(收益 × 概率)
```

选择：

-   最大期望收益；
-   或最小期望成本。

------------------------------------------------------------------------

# 7. 不确定型决策

不确定型决策特点：

> 未来状态未知，并且无法确定概率。

常用方法：

-   乐观法；
-   悲观法；
-   折中法；
-   后悔值法。

------------------------------------------------------------------------

# 8. 乐观法（大中取大）

又称：

最大最大准则。

思想：

> 认为未来会出现最有利情况。

步骤：

1.  每个方案取最大收益；
2.  在这些最大收益中选择最大值。

表示：

``` text
max(max收益)
```

------------------------------------------------------------------------

# 9. 悲观法（小中取大）

又称：

最大最小准则。

思想：

> 按最坏情况考虑，选择最可靠方案。

步骤：

1.  每个方案取最小收益；
2.  选择其中最大的值。

表示：

``` text
max(min收益)
```

------------------------------------------------------------------------

# 10. 折中法（赫维斯准则）

折中法同时考虑：

-   最好情况；
-   最坏情况。

公式：

``` text
α×最大收益

+

(1-α)×最小收益
```

其中：

α：

乐观系数。

范围：

``` text
0≤α≤1
```

------------------------------------------------------------------------

# 11. 后悔值法

后悔值法也称：

最小最大后悔值法。

思想：

> 选择未来可能后悔程度最小的方案。

步骤：

1.  计算每种状态下最大收益；
2.  计算各方案差值；
3.  得到后悔值；
4.  选择最大后悔值最小方案。

------------------------------------------------------------------------

# 12. 决策方法比较

  方法         适用情况   思想
  ------------ ---------- --------------
  确定型决策   状态确定   直接选择
  风险型决策   概率已知   期望值
  乐观法       无概率     追求最好
  悲观法       无概率     防范最坏
  折中法       无概率     权衡最好最坏
  后悔值法     无概率     最小化后悔

------------------------------------------------------------------------

# 13. 典型应用

## 13.1 项目投资

选择：

-   不同投资方案；
-   不同市场环境。

------------------------------------------------------------------------

## 13.2 产品规划

分析：

-   市场需求；
-   生产方案。

------------------------------------------------------------------------

## 13.3 工程建设

选择：

-   技术方案；
-   实施策略。

------------------------------------------------------------------------

# 15. 易错点

  易错知识               正确理解
  ---------------------- ----------------------
  风险型决策没有概率     风险型决策概率已知
  不确定型决策概率已知   不确定型决策概率未知
  悲观法选择最大收益     悲观法先取最小收益
  乐观法考虑最坏情况     乐观法选择最好情况

# 17. 本节小结

决策论用于分析不同环境条件下的方案选择问题。

考试重点：

-   掌握三类决策区别；
-   理解各种决策准则；
-   熟悉期望值计算；
-   掌握乐观、悲观、折中、后悔值方法。
