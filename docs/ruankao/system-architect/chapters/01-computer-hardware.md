# 第一章｜计算机硬件

> **章节定位**
>
> 本章介绍计算机硬件系统基础，包括计算机组成、CPU、校验码、指令系统、存储系统、输入/输出技术及总线结构。
>
> 本文档为《系统架构设计师知识库》第一章门户页（Index），用于建立整体学习路线和章节导航。

------------------------------------------------------------------------

## 📖 一句话理解

**计算机硬件负责数据的输入、处理、存储和输出，而 CPU
是整个硬件系统的核心。**

------------------------------------------------------------------------

## 🎯 学习目标

完成本章后，你应该能够：

-   理解计算机五大组成部分
-   掌握 CPU 的组成与功能
-   掌握常见寄存器
-   理解奇偶校验与 CRC
-   理解指令执行过程
-   掌握 Cache 工作机制
-   理解 DMA、中断与总线
