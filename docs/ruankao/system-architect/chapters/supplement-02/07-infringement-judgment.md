# 1. 侵权判定概述

知识产权侵权是指：

> 未经权利人许可，实施法律禁止的使用行为，侵犯他人知识产权的行为。

侵权判断通常需要考虑：

-   权利是否有效；
-   是否未经授权使用；
-   是否属于法律允许范围。

------------------------------------------------------------------------

# 2. 知识产权侵权基本原则

判断侵权通常包括：

``` text
存在合法权利

↓

发生使用行为

↓

未经授权

↓

造成权利损害
```

------------------------------------------------------------------------

# 3. 著作权侵权判断（★★★★★）

著作权侵权主要表现：

-   未经许可发表作品；
-   未经许可复制作品；
-   修改他人作品；
-   冒用他人署名。

------------------------------------------------------------------------

## 3.1 著作权保护重点

著作权保护：

> 作品的表达形式。

不直接保护：

-   思想；
-   创意；
-   方法。

------------------------------------------------------------------------

# 4. 软件著作权侵权判断（★★★★★）

软件侵权常见情况：

## 4.1 未授权复制软件

例如：

-   非法复制软件程序；
-   使用盗版软件。

------------------------------------------------------------------------

## 4.2 未授权传播软件

例如：

-   未经许可发布软件；
-   非法提供下载。

------------------------------------------------------------------------

## 4.3 修改他人软件

例如：

-   删除版权信息；
-   修改程序后冒充自己的软件。

------------------------------------------------------------------------

# 5. 专利侵权判断

专利侵权主要判断：

是否未经许可实施专利技术。

包括：

-   制造专利产品；
-   使用专利方法；
-   销售专利产品。

------------------------------------------------------------------------

# 6. 商标侵权判断

商标侵权常见行为：

-   未经许可使用注册商标；
-   使用近似商标造成混淆；
-   销售侵犯商标权商品；
-   伪造商标标识。

------------------------------------------------------------------------

# 7. 常见侵权行为

  类型         常见行为
  ------------ ------------------------
  著作权       复制、发表、修改
  软件著作权   复制软件、盗版传播
  专利权       未授权制造、使用
  商标权       使用近似标识、假冒品牌

------------------------------------------------------------------------

# 8. 合理使用情形（★★★★★）

在法律允许范围内：

以下通常不构成侵权：

-   个人学习研究；
-   教学科研使用；
-   适当引用；
-   非营利性的合理使用。

判断关键：

是否超过合理使用范围。

------------------------------------------------------------------------

# 9. 软件开发中的侵权风险

软件项目中需要注意：

## 第三方组件

关注：

-   开源许可证；
-   商业授权；
-   使用限制。

------------------------------------------------------------------------

## 软件复制使用

需要确认：

-   是否获得授权；
-   是否符合许可范围。

------------------------------------------------------------------------

## 外包开发

需要明确：

-   软件著作权归属；
-   源代码权限；
-   商业使用权。

------------------------------------------------------------------------

# 10. 侵权责任

知识产权侵权可能承担：

-   停止侵害；
-   消除影响；
-   赔偿损失。

严重情况下：

可能承担其他法律责任。

------------------------------------------------------------------------

# 11. 高频考点（★★★★★）

重点掌握：

1.  知识产权侵权基本判断流程；
2.  软件复制属于典型侵权；
3.  著作权保护表达形式；
4.  合理使用判断；
5.  商标、专利侵权特点。

------------------------------------------------------------------------

# 12. 易错点

  易错知识                 正确理解
  ------------------------ --------------------
  使用他人思想一定侵权     著作权主要保护表达
  软件购买后可以任意复制   需要遵守授权范围
  开源软件没有版权限制     仍受许可证约束
  修改软件一定拥有版权     需要考虑原作品权利

# 14. 本节小结

侵权判定是知识产权考试中的重点内容。

核心：

-   判断是否存在有效权利；
-   判断是否未经许可使用；
-   区分合理使用和侵权行为；
-   掌握软件、专利、商标不同侵权特点。

软件开发过程中，应重点关注：

-   软件授权；
-   开源协议；
-   第三方组件合规。
