# 1. 软件著作权概述

软件著作权是著作权的重要组成部分。

软件作为一种智力成果，受到法律保护。

软件著作权保护的主要对象：

-   软件程序；
-   软件文档。

------------------------------------------------------------------------

# 2. 软件著作权定义

软件著作权是指：

> 软件开发者或者其他权利人依法享有的软件相关权利。

软件著作权属于：

``` text
著作权范畴
```

而不是传统意义上的专利保护。

------------------------------------------------------------------------

# 3. 软件著作权保护对象（★★★★★）

软件著作权主要保护：

## 3.1 软件程序

包括：

-   源程序；
-   目标程序。

------------------------------------------------------------------------

## 3.2 软件文档

包括：

-   设计说明书；
-   用户手册；
-   使用说明等。

------------------------------------------------------------------------

# 4. 软件著作权保护范围

软件著作权保护：

> 软件的表达形式。

例如：

-   程序代码；
-   软件文档。

不直接保护：

-   软件思想；
-   算法本身；
-   功能概念。

------------------------------------------------------------------------

# 5. 软件著作权取得方式

软件著作权采用：

``` text
自动取得原则
```

即：

软件完成创作后，符合条件即可产生著作权。

登记：

-   可以作为权利证明；
-   有利于权利保护。

------------------------------------------------------------------------

# 6. 软件著作权人确定（★★★★★）

软件著作权人通常根据：

-   开发主体；
-   开发方式；
-   合同约定；

确定。

------------------------------------------------------------------------

## 6.1 自主开发软件

通常：

``` text
开发者享有软件著作权
```

------------------------------------------------------------------------

## 6.2 职务开发软件

如果软件：

-   属于工作任务；
-   由单位安排开发；
-   利用单位条件完成；

需要按照职务作品规则确定。

------------------------------------------------------------------------

## 6.3 委托开发软件

原则：

``` text
合同约定优先
```

没有约定：

按照法律规定确定。

------------------------------------------------------------------------

# 7. 软件职务作品

软件开发中常见情况：

## 属于单位任务

例如：

-   程序员根据岗位职责开发系统；
-   公司安排开发业务软件。

通常：

``` text
单位享有相关权利
```

------------------------------------------------------------------------

## 个人业余开发

如果：

-   非工作任务；
-   未使用单位资源；

通常：

``` text
个人享有权利
```

------------------------------------------------------------------------

# 8. 软件委托开发作品

委托开发软件：

由委托方和开发方共同约定权利归属。

重点：

合同应明确：

-   著作权归属；
-   源代码交付；
-   使用权限；
-   后续维护。

------------------------------------------------------------------------

# 9. 软件著作权登记

软件著作权登记作用：

-   证明权利归属；
-   方便维权；
-   便于交易。

注意：

登记不是取得软件著作权的必要条件。

------------------------------------------------------------------------

# 10. 软件著作权保护期限

软件著作权保护期限：

## 自然人软件

``` text
作者终生 + 死亡后50年
```

------------------------------------------------------------------------

## 法人或者其他组织软件

``` text
首次发表后50年
```

------------------------------------------------------------------------

# 11. 软件著作权与专利权区别

  对比           软件著作权     专利权
  -------------- -------------- ----------
  保护对象       软件表达形式   技术方案
  获取方式       自动产生       申请授权
  是否需要审查   通常不需要     需要审查
  保护重点       代码、文档     创新技术

------------------------------------------------------------------------

# 12. 软件开发中的知识产权管理

项目开发过程中需要明确：

## 合同管理

明确：

-   权利归属；
-   授权范围；
-   使用限制。

------------------------------------------------------------------------

## 开源软件管理

关注：

-   开源协议；
-   商业使用限制；
-   修改发布要求。

------------------------------------------------------------------------

## 第三方组件管理

确认：

-   使用许可；
-   版权要求；
-   合规风险。

------------------------------------------------------------------------

# 13. 高频考点（★★★★★）

重点掌握：

1.  软件属于著作权保护范围；
2.  软件著作权保护对象；
3.  软件著作权自动取得；
4.  软件登记不是取得条件；
5.  软件职务作品归属判断；
6.  委托开发合同优先；
7.  软件著作权保护期限。

------------------------------------------------------------------------

# 14. 易错点

  易错知识                 正确理解
  ------------------------ ------------------------
  软件只能申请专利保护     软件主要通过著作权保护
  登记后才产生著作权       完成创作即可产生
  软件著作权保护算法思想   保护代码等表达形式
  委托开发一定归委托方     首先看合同约定

# 16. 本节小结

软件著作权是系统架构设计师考试中知识产权部分的重要内容。

重点：

-   理解软件著作权保护范围；
