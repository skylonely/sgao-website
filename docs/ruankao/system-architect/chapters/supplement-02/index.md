# 1. 学习目标

掌握：

-   知识产权基本概念；
-   知识产权特点；
-   软件著作权；

-   知识产权归属判断；
-   软件侵权判定；
-   标准分类和编号规则。

------------------------------------------------------------------------

# 2. 知识产权概述

知识产权是对创造性智力成果和工商业标记依法享有的权利。

主要包括：

-   著作权；
-   专利权；
-   商标权。

特点：

-   无形性；
-   专有性；
-   地域性；
-   时间性。

------------------------------------------------------------------------

# 3. 保护期限

  类型           期限
  -------------- ----------------------
  软件著作权     作者终生及死亡后50年
  发明专利       20年
  实用新型专利   10年
  外观设计专利   15年
  商标权         10年，可续展

------------------------------------------------------------------------

# 4. 知识产权归属

重点：

## 职务作品

需要判断：

-   是否属于工作职责；
-   是否利用单位条件；
-   是否由单位安排。

## 委托作品

原则：

合同约定优先。

------------------------------------------------------------------------

# 5. 侵权判定

不构成侵权：

-   个人学习研究；
-   教学科研使用；
-   合理引用。

构成侵权：

-   未经许可发表；
-   非法复制；
-   销售盗版。

------------------------------------------------------------------------

# 6. 标准化

标准化包括：

-   标准制定；
-   标准发布；
-   标准实施；
-   标准监督。

标准分类：

-   国际标准；
-   国家标准；
-   行业标准；
-   地方标准；
-   企业标准。
