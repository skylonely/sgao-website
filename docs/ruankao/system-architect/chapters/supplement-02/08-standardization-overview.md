# 1. 标准化概述

标准化是现代信息技术和工程管理的重要基础。

通过制定、发布和实施标准：

-   统一技术要求；
-   提高产品兼容性；
-   促进技术交流；
-   提升系统质量。

------------------------------------------------------------------------

# 2. 标准定义

标准是：

> 为了在一定范围内获得最佳秩序，经协商一致制定并由公认机构批准，共同使用的规范性文件。

标准通常具有：

-   规范性；
-   统一性；
-   指导性。

------------------------------------------------------------------------

# 3. 标准化定义

标准化是：

> 为了在一定范围内获得最佳秩序，对实际问题或潜在问题制定共同使用和重复使用的条款的活动。

标准化过程包括：

``` text
制定标准

↓

发布标准

↓

实施标准

↓

监督改进
```

------------------------------------------------------------------------

# 4. 标准化目的

标准化主要目的：

## 4.1 统一规范

解决：

-   技术差异；
-   产品不兼容。

------------------------------------------------------------------------

## 4.2 提高质量

通过标准：

-   降低错误；
-   提升可靠性。

------------------------------------------------------------------------

## 4.3 促进交流

实现：

-   系统互操作；
-   技术共享。

------------------------------------------------------------------------

# 5. 标准化作用

主要作用：

## 技术作用

促进：

-   技术发展；
-   产品兼容。

------------------------------------------------------------------------

## 经济作用

实现：

-   降低成本；
-   提高效率。

------------------------------------------------------------------------

## 管理作用

提供：

-   管理依据；
-   评价依据。

------------------------------------------------------------------------

# 6. 标准化基本原则

标准化通常遵循：

## 科学性

标准制定应符合技术规律。

------------------------------------------------------------------------

## 协调性

不同标准之间应保持一致。

------------------------------------------------------------------------

## 先进性

标准应适应技术发展。

------------------------------------------------------------------------

## 实用性

标准应具有可操作性。

------------------------------------------------------------------------

# 7. 标准化过程

基本流程：

``` text
需求分析

↓

标准制定

↓

标准审批

↓

标准发布

↓

标准实施

↓

标准维护
```

------------------------------------------------------------------------

# 8. 信息技术标准化

信息技术领域标准化主要解决：

-   系统互操作；
-   数据交换；
-   网络通信；
-   软件兼容。

常见领域：

-   网络协议；
-   数据格式；
-   软件接口；
-   安全规范。

------------------------------------------------------------------------

# 9. 国际标准化组织

## ISO

国际标准化组织。

主要负责：

-   国际标准制定。

------------------------------------------------------------------------

## IEC

国际电工委员会。

主要涉及：

-   电工技术；
-   电子技术。

------------------------------------------------------------------------

## ITU

国际电信联盟。

主要涉及：

-   通信标准。

------------------------------------------------------------------------
