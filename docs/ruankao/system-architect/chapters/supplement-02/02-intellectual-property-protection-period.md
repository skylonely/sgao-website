# 1. 知识产权保护期限概述

知识产权具有：

> 时间性。

即：

知识产权并不是永久有效，而是在法律规定期限内受到保护。

超过保护期限后：

-   权利终止；
-   相关成果可能进入公共领域。

------------------------------------------------------------------------

# 2. 软件著作权保护期限（★★★★★）

软件属于著作权保护范围。

软件著作权保护期限：

## 自然人作品

保护期限：

``` text
作者终生 + 死亡后50年
```

计算：

从作者死亡后开始计算。

------------------------------------------------------------------------

## 法人或者其他组织作品

保护期限：

``` text
首次发表后50年
```

如果软件自开发完成后50年内未发表：

不再保护。

------------------------------------------------------------------------

# 3. 发明专利保护期限（★★★★★）

发明专利保护期限：

``` text
20年
```

计算：

自申请日起计算。

保护对象：

-   技术方案；
-   产品或者方法创新。

------------------------------------------------------------------------

# 4. 实用新型专利保护期限

实用新型专利保护期限：

``` text
10年
```

计算：

自申请日起计算。

主要保护：

-   产品结构改进；
-   实用技术方案。

------------------------------------------------------------------------

# 5. 外观设计专利保护期限

外观设计专利保护期限：

``` text
15年
```

计算：

自申请日起计算。

保护：

-   产品外观设计。

------------------------------------------------------------------------

# 6. 商标权保护期限（★★★★★）

商标权保护期限：

``` text
10年
```

计算：

自核准注册日起计算。

特点：

可以续展。

每次续展：

``` text
10年
```

因此商标权可以长期持续。

------------------------------------------------------------------------

# 7. 不同知识产权期限对比

  类型                   保护期限
  ---------------------- ---------------------
  软件著作权（自然人）   作者终生+死亡后50年
  软件著作权（法人）     首次发表后50年
  发明专利               20年
  实用新型专利           10年
  外观设计专利           15年
  商标权                 10年，可续展

------------------------------------------------------------------------

# 8. 期限相关注意事项

## 8.1 著作权与专利权区别

著作权：

-   保护作品表达；
-   软件通常采用著作权保护。

专利权：

-   保护技术方案；
-   需要申请授权。

------------------------------------------------------------------------

## 8.2 申请日与发表日区别

专利：

``` text
申请日起计算
```

软件法人著作权：

``` text
首次发表日起计算
```

考试中容易混淆。

------------------------------------------------------------------------

## 8.3 商标续展

商标权：

不是永久固定期限。

通过续展：

可以继续获得保护。

------------------------------------------------------------------------

# 9. 高频考点（★★★★★）

重点掌握：

1.  软件著作权保护期限；
2.  发明专利20年；
3.  实用新型10年；
4.  外观设计15年；
5.  商标10年并可续展；
6.  专利从申请日起计算；
7.  软件法人作品从首次发表计算。

------------------------------------------------------------------------

# 10. 易错点

  易错知识                 正确理解
  ------------------------ ------------------------
  软件保护都是专利20年     软件通常属于著作权保护
  著作权永久有效           著作权具有时间性
  商标注册后永久有效       商标需要续展
  专利期限从发表日起计算   专利通常从申请日起计算
  所有软件著作权期限一样   自然人与法人规定不同

# 12. 本节小结

知识产权保护期限是系统架构设计师考试中的高频记忆点。

重点：

-   软件著作权期限；
-   三类专利期限；
-   商标续展规则；
-   不同知识产权期限计算方式。

考试中通常通过案例判断权利是否仍在保护期内。
