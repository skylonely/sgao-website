# 1. 商标权概述

商标权是知识产权的重要组成部分。

商标权保护：

> 商标注册人对其注册商标依法享有的专有权。

商标主要用于：

-   区分商品来源；
-   区分服务来源；
-   建立品牌识别。

------------------------------------------------------------------------

# 2. 商标定义

商标是：

> 用于区别商品或者服务来源的标志。

常见形式：

-   文字；
-   图形；
-   字母；
-   数字；
-   三维标志；
-   颜色组合。

------------------------------------------------------------------------

# 3. 商标作用

商标主要作用：

## 3.1 区别作用

帮助消费者识别：

-   商品来源；
-   服务提供者。

------------------------------------------------------------------------

## 3.2 品牌作用

商标可以：

-   建立企业形象；
-   体现品牌价值。

------------------------------------------------------------------------

## 3.3 保护作用

注册商标后：

可以防止他人未经许可使用相同或近似标识。

------------------------------------------------------------------------

# 4. 商标类型

常见分类：

## 注册商标

经过国家商标主管机关核准注册。

------------------------------------------------------------------------

## 未注册商标

未经过注册程序。

保护程度通常低于注册商标。

------------------------------------------------------------------------

# 5. 注册商标

注册商标是：

> 经商标主管机关核准注册的商标。

特点：

-   具有专用权；
-   受到法律保护；
-   可以进行转让和许可。

------------------------------------------------------------------------

# 6. 商标权取得方式

商标权通常通过：

``` text
申请注册

↓

审查

↓

核准注册

↓

获得商标权
```

取得。

与著作权不同：

商标权需要经过注册。

------------------------------------------------------------------------

# 7. 商标权人的确定

商标权人通常为：

-   商标注册申请人；
-   依法取得商标权的主体。

包括：

-   企业；
-   组织；
-   个人。

------------------------------------------------------------------------

# 8. 商标权保护期限（★★★★★）

商标权保护期限：

``` text
10年
```

计算：

> 自核准注册之日起计算。

------------------------------------------------------------------------

# 9. 商标续展（★★★★★）

商标保护期满后：

可以申请续展。

每次续展：

``` text
10年
```

因此：

商标权可以通过不断续展持续保护。

------------------------------------------------------------------------

# 10. 商标侵权判断

常见侵权行为：

-   未经许可使用注册商标；
-   使用近似商标造成混淆；
-   销售侵犯注册商标权的商品；
-   伪造、擅自制造商标标识。

------------------------------------------------------------------------

# 11. 软件产品中的商标保护

软件产品涉及：

## 软件名称

例如：

-   产品名称；
-   软件品牌。

------------------------------------------------------------------------

## 软件标识

例如：

-   Logo；
-   图形标识。

------------------------------------------------------------------------

## 企业品牌

例如：

-   公司名称；
-   服务品牌。

这些通常通过商标保护。

------------------------------------------------------------------------

# 12. 商标权与其他知识产权区别

  对比       商标权     著作权     专利权
  ---------- ---------- ---------- ----------
  保护对象   标识       作品表达   技术方案
  获取方式   注册       自动产生   申请授权
  主要目的   区分来源   保护创作   保护创新

------------------------------------------------------------------------

# 13. 高频考点（★★★★★）

重点掌握：

1.  商标用于区别商品或服务来源；
2.  商标权需要注册取得；
3.  商标保护期限10年；
4.  商标可以续展；
5.  商标侵权判断。

------------------------------------------------------------------------

# 14. 易错点

  易错知识                   正确理解
  -------------------------- ----------------------
  商标自动产生权利           商标通常需要注册
  商标保护永久有效           需要定期续展
  商标保护技术方案           技术方案属于专利保护
  软件名称天然受到商标保护   需要注册商标

------------------------------------------------------------------------

# 16. 本节小结

商标权是知识产权体系中的重要组成部分。

考试重点：

-   理解商标作用；
-   掌握商标权取得方式；
-   牢记10年保护期限；
-   掌握续展规则；
-   区分商标权、著作权和专利权。
