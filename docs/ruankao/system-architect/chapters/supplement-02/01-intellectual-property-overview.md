# 1. 知识产权概述

知识产权（Intellectual Property）是指：

> 权利人对其智力劳动成果依法享有的专有权利。

知识产权保护的对象不是具体物品，而是人的创造性成果。

例如：

-   软件程序；
-   文学作品；
-   发明创造；
-   商标标识。

------------------------------------------------------------------------

# 2. 知识产权定义

知识产权主要保护：

-   创造性智力成果；
-   工商业标记；
-   技术创新成果。

其本质是：

``` text
智力创造

↓

法律保护

↓

专有权利
```

------------------------------------------------------------------------

# 3. 知识产权主要类型

知识产权主要包括：

``` text
知识产权

├── 著作权
│
├── 专利权
│
└── 商标权
```

------------------------------------------------------------------------

# 4. 著作权

## 4.1 著作权概念

著作权又称版权。

保护：

> 作者对其创作作品享有的权利。

------------------------------------------------------------------------

## 4.2 著作权保护对象

包括：

-   文字作品；
-   软件程序；
-   音乐作品；
-   图形作品等。

------------------------------------------------------------------------

## 4.3 软件著作权

软件属于著作权保护范围。

保护内容包括：

-   软件程序代码；
-   软件文档；
-   软件设计成果。

------------------------------------------------------------------------

# 5. 专利权

专利权是指：

> 国家依法授予发明创造者一定期限内的专有权。

主要包括：

## 发明专利

保护：

技术方案创新。

------------------------------------------------------------------------

## 实用新型专利

保护：

产品结构改进。

------------------------------------------------------------------------

## 外观设计专利

保护：

产品外观设计。

------------------------------------------------------------------------

# 6. 商标权

商标权保护：

> 用于区别商品或服务来源的标志。

例如：

-   企业名称；
-   商品标识；
-   品牌标志。

------------------------------------------------------------------------

# 7. 知识产权特点（★★★★★）

知识产权具有四个主要特点：

------------------------------------------------------------------------

## 7.1 无形性

知识产权对象：

不是实体物品。

例如：

软件代码属于智力成果。

------------------------------------------------------------------------

## 7.2 专有性

特点：

权利人享有专有权。

未经许可：

他人不得随意使用。

------------------------------------------------------------------------

## 7.3 地域性

特点：

知识产权保护范围通常受到国家或地区限制。

例如：

某国家授予的专利权，主要在该国家范围内有效。

------------------------------------------------------------------------

## 7.4 时间性

特点：

知识产权保护存在期限。

超过保护期限：

权利可能失效。

------------------------------------------------------------------------

# 8. 软件领域知识产权

软件开发过程中涉及：

## 软件著作权

保护：

-   软件代码；
-   软件文档。

------------------------------------------------------------------------

## 专利保护

保护：

-   软件相关技术方案；
-   创新技术方法。

------------------------------------------------------------------------

## 商业秘密

保护：

-   未公开技术信息；
-   企业内部资料。

------------------------------------------------------------------------

# 9. 信息系统建设中的知识产权

系统建设过程中需要关注：

## 软件开发

明确：

-   软件著作权归属；
-   开发合同约定。

------------------------------------------------------------------------

## 外包项目

需要明确：

-   源代码归属；
-   使用权限；
-   后续维护权。

------------------------------------------------------------------------

## 第三方组件

需要注意：

-   开源协议；
-   授权范围；
-   商业使用限制。

------------------------------------------------------------------------

# 11. 易错点

  易错知识               正确理解
  ---------------------- ------------------------
  知识产权保护具体物品   保护智力成果
  软件只有专利保护       软件主要属于著作权保护
  知识产权永久有效       具有时间限制
  知识产权全球自动有效   具有地域性
