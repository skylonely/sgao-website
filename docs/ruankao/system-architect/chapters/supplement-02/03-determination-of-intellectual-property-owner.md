> 本文依据《补充：知识产权与标准化.pdf》整理，用于系统架构设计师考试复习。主要介绍不同情况下知识产权权利人的确定规则，包括职务作品、委托作品、合作开发作品等。

# 1. 知识产权权利人概述

知识产权权利人是指：

> 依法享有知识产权相关权利的主体。

权利人的确定通常需要考虑：

-   创作主体；
-   创作目的；
-   是否属于工作任务；
-   是否存在合同约定。

------------------------------------------------------------------------

# 2. 非职务作品权利归属

非职务作品：

> 由个人独立完成，且不属于单位工作任务范围的作品。

一般原则：

``` text
作者享有著作权
```

特点：

-   由个人创作；
-   未利用单位条件完成；
-   与本职工作无直接关系。

------------------------------------------------------------------------

# 3. 职务作品权利归属（★★★★★）

职务作品是指：

> 公民为完成法人或者其他组织工作任务所创作的作品。

判断因素：

-   是否属于工作职责；
-   是否由单位安排完成；
-   是否利用单位资源。

------------------------------------------------------------------------

# 4. 特殊职务作品

对于特殊职务作品：

单位通常享有较大的权利。

典型情况：

-   主要利用单位物质技术条件完成；
-   由单位承担责任的作品。

------------------------------------------------------------------------

# 5. 软件职务作品（★★★★★）

软件开发中重点判断：

## 属于单位任务的软件

例如：

-   根据单位安排开发；
-   属于岗位职责范围；
-   使用单位资源完成。

通常：

``` text
单位享有软件著作权
```

------------------------------------------------------------------------

## 个人独立开发软件

如果：

-   非工作任务；
-   未使用单位资源；

通常：

``` text
个人享有相关权利
```

------------------------------------------------------------------------

# 6. 委托作品权利归属（★★★★★）

委托作品：

> 一方委托另一方完成创作的作品。

基本原则：

``` text
合同约定优先
```

如果合同中明确约定：

按照合同确定权利归属。

如果没有约定：

按照法律规定确定。

------------------------------------------------------------------------

# 7. 合作开发作品权利归属

合作开发作品：

> 多个主体共同完成的作品。

特点：

-   共同参与创作；
-   权利可能由共同创作者享有。

需要根据：

-   合作协议；
-   实际贡献；
-   法律规定；

确定权利归属。

------------------------------------------------------------------------

# 8. 合同约定原则

知识产权归属判断中：

合同具有重要作用。

重点：

``` text
有约定 → 按约定

无约定 → 按法律规定
```

因此软件开发合同中应明确：

-   著作权归属；
-   源代码权限；
-   使用范围；
-   后续维护权。

------------------------------------------------------------------------

# 9. 软件开发项目中的权利归属

项目开发过程中需要关注：

## 自主研发

通常：

开发方拥有相关权利。

------------------------------------------------------------------------

## 外包开发

需要明确：

-   软件著作权归谁；
-   是否交付源代码；
-   是否允许再次使用。

------------------------------------------------------------------------

## 联合开发

需要明确：

-   各方贡献；
-   权利比例；
-   使用权限。

------------------------------------------------------------------------

# 10. 高频考点（★★★★★）

重点掌握：

1.  非职务作品一般属于作者；
2.  职务作品需要判断工作任务；
3.  软件职务作品归属判断；
4.  委托作品合同优先；
5.  合同没有约定时按照法律规则处理。

------------------------------------------------------------------------

# 11. 易错点

  易错知识                   正确理解
  -------------------------- --------------------------
  所有软件都属于开发者个人   需要判断是否属于职务开发
  委托开发一定属于委托方     首先看合同约定
  使用单位资源一定归单位     需要结合具体规则判断
  合作开发只有一个权利人     可能存在共同权利

------------------------------------------------------------------------

# 13. 本节小结

知识产权人的确定是系统架构设计师考试中的高频考点。

核心判断原则：

1.  先判断是否属于职务作品；
2.  再判断是否存在合同约定；
3.  最后依据法律规则确定权利人。

软件开发项目中，应重点关注：

-   软件著作权归属；
-   源代码所有权；
-   使用授权范围。
