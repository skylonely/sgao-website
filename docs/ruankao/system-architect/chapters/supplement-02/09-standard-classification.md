# 1. 标准分类概述

标准按照不同分类方式，可以分为：

## 按制定组织和适用范围分类

``` text
标准

├── 国际标准
├── 国家标准
├── 行业标准
├── 地方标准
└── 企业标准
```

------------------------------------------------------------------------

## 按约束性质分类

``` text
标准

├── 强制性标准
└── 推荐性标准
```

------------------------------------------------------------------------

# 2. 国际标准（★★★★★）

国际标准是：

> 由国际标准化组织制定，在国际范围内使用的标准。

主要组织：

## ISO

国际标准化组织。

主要负责：

-   通用国际标准制定。

------------------------------------------------------------------------

## IEC

国际电工委员会。

主要负责：

-   电工；
-   电子技术相关标准。

------------------------------------------------------------------------

## ITU

国际电信联盟。

主要负责：

-   通信领域标准。

------------------------------------------------------------------------

# 3. 国家标准（★★★★★）

国家标准是在一个国家范围内统一使用的标准。

我国国家标准编号：

## 强制性国家标准

``` text
GB
```

例如：

``` text
GB xxxx
```

------------------------------------------------------------------------

## 推荐性国家标准

``` text
GB/T
```

其中：

T表示：

推荐性标准。

------------------------------------------------------------------------

## 指导性技术文件

``` text
GB/Z
```

其中：

Z表示：

指导性技术文件。

------------------------------------------------------------------------

# 4. 行业标准

行业标准：

> 在没有国家标准时，由相关行业主管部门制定，在行业范围内使用的标准。

特点：

-   适用于特定行业；
-   补充国家标准不足。

信息技术相关行业标准示例：

-   通信行业标准；
-   软件行业规范。

------------------------------------------------------------------------

# 5. 地方标准

地方标准：

> 由地方标准化组织制定，在一定行政区域内使用的标准。

适用范围：

-   某地区；
-   某地方特色需求。

------------------------------------------------------------------------

# 6. 企业标准

企业标准：

> 企业根据生产、经营和技术管理需要制定的标准。

应用：

-   企业内部管理；
-   产品开发；
-   技术规范。

企业标准通常要求：

不低于相关强制性标准。

------------------------------------------------------------------------

# 7. 强制性标准（★★★★★）

强制性标准：

> 必须执行的标准。

特点：

-   具有约束力；
-   不执行可能承担法律责任。

主要涉及：

-   安全；
-   健康；
-   环境保护；
-   基本技术要求。

------------------------------------------------------------------------

# 8. 推荐性标准

推荐性标准：

> 鼓励采用，但不是强制执行的标准。

特点：

-   提供技术参考；
-   促进技术统一。

国家推荐性标准：

``` text
GB/T
```

------------------------------------------------------------------------

# 9. 信息技术领域标准分类

信息技术标准主要包括：

## 网络标准

例如：

-   通信协议；
-   网络接口。

------------------------------------------------------------------------

## 数据标准

例如：

-   数据格式；
-   数据交换规范。

------------------------------------------------------------------------

## 软件标准

例如：

-   软件开发规范；
-   接口规范。

------------------------------------------------------------------------

## 安全标准

例如：

-   信息安全要求；
-   安全管理规范。

------------------------------------------------------------------------

# 10. 标准层级关系

一般关系：

``` text
国际标准

↓

国家标准

↓

行业标准

↓

地方标准

↓

企业标准
```

实际应用中：

不同层级标准共同作用。

------------------------------------------------------------------------

# 11. 高频考点（★★★★★）

重点掌握：

1.  标准分类方式；
2.  ISO、IEC、ITU职责；
3.  GB、GB/T、GB/Z区别；
4.  国家标准和行业标准关系；
5.  强制性标准与推荐性标准区别。

------------------------------------------------------------------------

# 12. 易错点

  易错知识                   正确理解
  -------------------------- --------------------
  GB/T中的T表示技术          T表示推荐性
  所有标准都强制执行         推荐性标准不是强制
  ISO负责通信标准            通信主要关注ITU
  企业标准可以低于强制标准   不得低于强制性要求

-   掌握五级标准分类；
