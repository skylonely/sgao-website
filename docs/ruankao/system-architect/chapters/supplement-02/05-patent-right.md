# 1. 专利权概述

专利权是知识产权的重要组成部分。

专利权保护：

> 发明创造者依法享有的一定期限内的专有权。

专利制度的目的：

-   保护创新成果；
-   鼓励技术创新；
-   促进技术公开。

------------------------------------------------------------------------

# 2. 专利权定义

专利权是：

> 国家依法授予发明创造者或者权利人的独占性权利。

获得专利权后：

未经许可：

-   他人不得制造；
-   不得使用；
-   不得销售相关专利产品。

------------------------------------------------------------------------

# 3. 专利类型（★★★★★）

我国专利主要包括：

``` text
专利权

├── 发明专利
├── 实用新型专利
└── 外观设计专利
```

------------------------------------------------------------------------

# 4. 发明专利

## 4.1 定义

发明专利保护：

> 对产品、方法或者其改进提出的新的技术方案。

特点：

-   技术创新程度高；
-   保护范围较广。

------------------------------------------------------------------------

## 4.2 示例

例如：

-   新型算法实现方法；
-   新技术方案；
-   新产品制造方法。

------------------------------------------------------------------------

# 5. 实用新型专利

## 5.1 定义

实用新型专利保护：

> 产品形状、构造或者其结合提出的适于实用的新技术方案。

特点：

-   主要针对产品结构改进；
-   技术要求相对较低。

------------------------------------------------------------------------

## 5.2 示例

例如：

-   设备结构优化；
-   产品内部结构改进。

------------------------------------------------------------------------

# 6. 外观设计专利

## 6.1 定义

外观设计专利保护：

> 产品整体或者局部的形状、图案以及色彩组合。

特点：

保护重点：

-   外观；
-   视觉效果。

------------------------------------------------------------------------

# 7. 专利权取得

专利权通常需要：

``` text
提出申请

↓

审查

↓

授权

↓

获得专利权
```

与著作权不同：

专利权不是自动产生。

------------------------------------------------------------------------

# 8. 专利权保护期限（★★★★★）

  类型           保护期限
  -------------- ----------
  发明专利       20年
  实用新型专利   10年
  外观设计专利   15年

计算：

> 自申请日起计算。

------------------------------------------------------------------------

# 9. 专利权人的确定

专利权人通常包括：

-   发明人；
-   申请人；
-   依法取得权利的主体。

------------------------------------------------------------------------

## 9.1 职务发明

如果发明：

-   执行单位任务完成；
-   利用单位条件完成；

通常：

按照职务发明规则确定权利归属。

------------------------------------------------------------------------

## 9.2 非职务发明

个人独立完成：

通常：

``` text
发明人享有相关权利
```

------------------------------------------------------------------------

# 10. 软件相关专利

软件相关成果可能涉及：

## 软件著作权

保护：

-   程序代码；
-   软件文档。

------------------------------------------------------------------------

## 软件相关专利

保护：

-   技术方案；
-   技术创新。

例如：

-   软件结合硬件实现的技术方案；
-   创新的技术处理方法。

------------------------------------------------------------------------

# 11. 专利权与软件著作权区别

  对比       专利权       软件著作权
  ---------- ------------ ------------------
  保护对象   技术方案     软件表达形式
  获得方式   申请授权     自动产生
  是否审查   需要审查     通常无需审查
  期限       有固定期限   具有不同期限规则

------------------------------------------------------------------------

# 13. 易错点

  易错知识               正确理解
  ---------------------- ------------------------
  专利自动产生           专利需要申请
  软件只能申请专利       软件主要通过著作权保护
  三种专利期限相同       三者期限不同
  外观设计保护技术方案   外观设计保护视觉设计
