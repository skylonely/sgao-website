# 2. 知识产权总结（★★★★★）

## 2.1 知识产权特点

四大特点：

  特点     含义
  -------- ------------------
  无形性   保护智力成果
  专有性   权利人独占使用
  地域性   在特定范围内有效
  时间性   存在保护期限

------------------------------------------------------------------------

# 3. 知识产权类型对比

  类型     保护对象         获取方式
  -------- ---------------- ----------
  著作权   作品表达形式     自动产生
  专利权   技术方案         申请授权
  商标权   商品或服务标识   注册取得

------------------------------------------------------------------------

# 4. 软件著作权总结（★★★★★）

## 保护对象

主要包括：

-   程序代码；
-   软件文档。

不直接保护：

-   软件思想；
-   算法本身。

------------------------------------------------------------------------

## 获取方式

核心：

``` text
完成创作 → 自动产生
```

登记作用：

-   证明权利归属；
-   便于维权。

------------------------------------------------------------------------

## 权利归属

判断：

``` text
是否职务开发？

↓

是否存在合同约定？

↓

确定权利人
```

重点：

-   职务开发；
-   委托开发；
-   合作开发。

------------------------------------------------------------------------

## 保护期限

  类型         期限
  ------------ ---------------------
  自然人软件   作者终生+死亡后50年
  法人软件     首次发表后50年

------------------------------------------------------------------------

# 5. 专利权总结（★★★★★）

## 三种专利

  类型       保护内容   期限
  ---------- ---------- ------
  发明专利   技术方案   20年
  实用新型   产品结构   10年
  外观设计   产品外观   15年

------------------------------------------------------------------------

## 专利特点

-   需要申请；
-   需要审查；
-   授权后获得权利。

------------------------------------------------------------------------

# 6. 商标权总结（★★★★★）

## 商标作用

用于：

-   区别商品来源；
-   区别服务来源；
-   建立品牌。

------------------------------------------------------------------------

## 商标期限

``` text
10年
```

特点：

-   可以续展；
-   每次续展10年。

------------------------------------------------------------------------

# 7. 侵权判定总结

## 著作权侵权

常见：

-   未授权复制；
-   未授权发表；
-   修改冒用。

------------------------------------------------------------------------

## 软件侵权

常见：

-   非法复制软件；
-   非法传播软件；
-   删除版权信息。

------------------------------------------------------------------------

## 专利侵权

常见：

-   未授权制造；
-   使用专利技术；
-   销售专利产品。

------------------------------------------------------------------------

## 商标侵权

常见：

-   未授权使用注册商标；
-   使用近似标识；
-   销售假冒商品。

------------------------------------------------------------------------

# 8. 合理使用

通常包括：

-   个人学习研究；
-   教学科研使用；
-   合理引用。

判断重点：

是否超过合理范围。

------------------------------------------------------------------------

# 9. 标准化总结（★★★★★）

## 标准分类

``` text
标准

├── 国际标准
├── 国家标准
├── 行业标准
├── 地方标准
└── 企业标准
```

------------------------------------------------------------------------

## 国家标准编号

### GB

强制性国家标准。

------------------------------------------------------------------------

### GB/T

推荐性国家标准。

其中：

``` text
T = 推荐性
```

------------------------------------------------------------------------

### GB/Z

国家标准化指导性技术文件。

------------------------------------------------------------------------

# 11. 高频考点总结（★★★★★）

## 必背内容

1.  知识产权四大特点；
2.  软件属于著作权保护；
3.  软件著作权保护代码和文档；
4.  软件登记不是取得条件；
5.  发明专利20年；
6.  实用新型10年；
7.  外观设计15年；
8.  商标10年可续展；
9.  GB/T表示推荐性；
10. GB/Z表示指导性技术文件。

# 12. 易错点总结

  易错点               正确理解
  -------------------- --------------------

  软件登记产生著作权   著作权通常自动产生

  商标永久有效         商标需要续展
  GB/T中的T代表技术    T代表推荐性

# 本章小结

第十八章《知识产权与标准化》属于系统架构设计师考试中的基础记忆章节。

复习重点：

-   掌握知识产权分类；
-   牢记软件著作权保护范围；
-   熟悉权利归属判断；
-   记忆专利和商标期限；
-   掌握侵权判断方法；
-   理解标准分类和编号规则。

本章核心思想：

> 保护创新成果，规范技术应用，促进信息系统建设标准化。
