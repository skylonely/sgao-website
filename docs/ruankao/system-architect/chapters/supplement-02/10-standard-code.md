# 1. 标准编号概述

标准编号是识别标准文件的重要标识。

通过标准编号可以了解：

-   标准所属类别；
-   标准性质；
-   标准发布顺序；
-   发布年份。

------------------------------------------------------------------------

# 2. 标准编号组成

国家标准编号通常由：

``` text
标准代号 + 标准顺序号 + 发布年份
```

组成。

基本形式：

``` text
GB ××××× - ××××
```

例如：

``` text
GB/T 12345-2024
```

------------------------------------------------------------------------

# 3. 国家标准编号规则（★★★★★）

我国国家标准主要使用：

``` text
GB
```

作为标准代号。

国家标准编号包括：

1.  标准代号；
2.  标准顺序号；
3.  年份。

------------------------------------------------------------------------

# 4. GB标准代号

GB表示：

> 国家标准。

主要用于：

强制性国家标准。

特点：

-   必须执行；
-   具有约束力。

格式：

``` text
GB xxxx-xxxx
```

------------------------------------------------------------------------

# 5. GB/T标准代号（★★★★★）

GB/T表示：

> 推荐性国家标准。

其中：

T表示：

推荐性（推荐标准）。

特点：

-   推荐采用；
-   不属于强制执行。

格式：

``` text
GB/T xxxx-xxxx
```

------------------------------------------------------------------------

# 6. GB/Z标准代号

GB/Z表示：

> 国家标准化指导性技术文件。

特点：

-   提供技术指导；
-   不属于正式强制标准。

格式：

``` text
GB/Z xxxx-xxxx
```

------------------------------------------------------------------------

# 7. 标准顺序号

标准顺序号表示：

> 该标准在标准体系中的编号。

例如：

``` text
GB/T 12345
```

其中：

12345表示标准顺序号。

------------------------------------------------------------------------

# 8. 标准发布年份

年份表示：

> 标准发布或者修订年份。

例如：

``` text
GB/T 12345-2024
```

其中：

2024表示发布年份。

------------------------------------------------------------------------

# 9. 标准编号示例解析

示例：

``` text
GB/T 320101-2012
```

解析：

  部分     含义
  -------- ------------
  GB       国家标准
  T        推荐性
  320101   标准顺序号
  2012     发布年份

------------------------------------------------------------------------

# 10. 信息技术标准编号

信息技术领域常见标准：

-   国家标准；
-   行业标准；
-   国际标准。

例如：

## ISO标准

国际标准编号：

``` text
ISO xxxx
```

------------------------------------------------------------------------

## IEEE标准

常见于：

-   网络技术；
-   软件工程；
-   通信协议。

------------------------------------------------------------------------

# 11. 高频考点（★★★★★）

重点掌握：

1.  GB表示国家标准；
2.  GB/T表示推荐性国家标准；
3.  GB/Z表示指导性技术文件；
4.  标准编号由代号、顺序号、年份组成；
5.  T不是技术（Technology），而是推荐性。

------------------------------------------------------------------------

# 12. 易错点

  易错知识               正确理解
  ---------------------- --------------------
  GB/T中的T表示技术      T表示推荐性
  GB一定代表推荐标准     GB通常表示国家标准
  年份表示标准编号       年份表示发布时间
  所有标准编号格式一样   不同组织规则不同
