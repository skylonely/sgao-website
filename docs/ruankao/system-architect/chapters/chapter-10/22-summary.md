# 三、易混知识对比

| 对比 | 区别 |
|------|------|
| 瀑布模型 vs V 模型 | V 模型增加测试对应关系 |
| 原型模型 vs 增量模型 | 验证需求；逐步交付 |
| 黑盒测试 vs 白盒测试 | 功能测试；结构测试 |
| 耦合 vs 内聚 | 模块间关系；模块内关系 |
| 测试 vs 调试 | 发现缺陷；修复缺陷 |
| BPR vs BPM | 流程重组；流程持续管理 |
