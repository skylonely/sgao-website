# 第七节 存储管理（Memory Management）

> **说明**
> 本文依据《2.操作系统知识》资料整理，围绕存储管理体系、分页、分段、段页式等知识展开。

## 一句话理解

**存储管理负责对主存空间进行分配、回收和保护，提高内存利用率并支持程序高效运行。**

## 学习目标

-   理解存储管理目标
-   掌握连续与离散分配
-   理解分页、分段、段页式
-   为页面置换算法学习打基础

## 1. 存储管理目标

-   提高内存利用率
-   支持多道程序运行
-   实现地址保护
-   提供逻辑地址到物理地址转换。

## 2. 连续存储分配

连续分配要求程序装入一块连续的物理内存。

常见方式：

-   单一连续分配
-   固定分区
-   动态分区

优点是实现简单，缺点是容易产生内外部碎片。

## 3. 分页存储

分页将：

-   逻辑空间划分为**页（Page）**
-   物理内存划分为**页框（Frame）**

页与页框大小相同，通过页表完成地址映射。

```mermaid
flowchart LR
A[逻辑地址] --> B[页号]
B --> C[页表]
C --> D[页框]
D --> E[物理地址]
```

## 4. 分段存储

程序按照逻辑意义划分：

-   代码段
-   数据段
-   堆栈段

每段长度可以不同，更符合程序设计习惯。

## 5. 段页式存储

段页式结合：

-   分段的逻辑组织
-   分页的内存管理

先查段表，再查页表，最后得到物理地址。

## 6. 地址转换

```text
逻辑地址
   ↓
段表（可选）
   ↓
页表
   ↓
物理地址
```

资料中配有页式地址计算及地址转换相关例题。

## 高频考点

-   固定分区与动态分区
-   分页与分段区别
-   段页式特点
-   地址转换

## 易错点

> **注意：** 分页大小固定；分段长度可变。

> **注意：** 分页主要解决内存管理问题；分段强调程序逻辑结构。

## 开发者视角

现代 Linux、Windows
均采用虚拟内存机制，分页管理是实现虚拟地址空间和内存保护的重要基础。

## 架构师思考

理解虚拟内存、分页和地址转换，有助于分析大规模系统中的内存占用、性能瓶颈和缓存命中率。
