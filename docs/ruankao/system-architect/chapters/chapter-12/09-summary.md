# 2. CPM 关键路径法

关键路径特点：

-   是项目网络图中最长的一条路径
-   决定项目最短完成时间
-   路径上的活动总浮动时间为 0

时间参数：

  参数   含义
  ------ --------------
  ES     最早开始时间
  EF     最早结束时间
  LS     最晚开始时间
  LF     最晚结束时间

计算公式：

``` text
EF = ES + 工期

LS = LF - 工期

总浮动时间：

TF = LS - ES
   = LF - EF
```

  易混知识               区别
  ---------------------- ----------------------------
