# 1. 关键路径法概述

关键路径法（Critical Path
Method，CPM）是一种用于项目进度计划分析的方法。

通过分析项目活动之间的依赖关系，计算各活动时间参数，确定影响项目完成时间的关键活动。

关键路径决定项目的最短完成时间。

------------------------------------------------------------------------

# 2. 项目网络图

项目网络图用于表示：

-   项目活动之间的关系
-   活动执行顺序
-   活动持续时间

通过网络图可以分析：

-   项目完成时间
-   关键路径
-   活动浮动时间

------------------------------------------------------------------------

# 3. 时间参数

## 3.1 ES（Earliest Start）

最早开始时间：

> 活动最早可以开始的时间。

------------------------------------------------------------------------

## 3.2 EF（Earliest Finish）

最早结束时间：

公式：

``` text
EF = ES + 活动持续时间
```

------------------------------------------------------------------------

## 3.3 LS（Latest Start）

最晚开始时间：

> 在不影响项目完成时间情况下，活动最迟开始时间。

------------------------------------------------------------------------

## 3.4 LF（Latest Finish）

最晚结束时间：

公式：

``` text
LS = LF - 活动持续时间
```

------------------------------------------------------------------------

# 4. 最早时间计算

计算方向：

``` text
从项目开始节点
        ↓
向项目结束节点计算
```

规则：

-   起始活动 ES 通常为 0
-   根据前置活动 EF 推算后续活动 ES

------------------------------------------------------------------------

# 5. 最晚时间计算

计算方向：

``` text
从项目结束节点
        ↓
向项目开始节点计算
```

规则：

-   终点活动 LF 等于项目总工期
-   根据后续活动 LS 推算当前活动 LF

------------------------------------------------------------------------

# 6. 浮动时间

## 6.1 总浮动时间（Total Float）

表示活动可以延迟的最大时间。

公式：

``` text
TF = LS - ES

或

TF = LF - EF
```

------------------------------------------------------------------------

## 6.2 自由浮动时间（Free Float）

表示活动延迟但不影响后续活动最早开始时间的时间。

------------------------------------------------------------------------

# 7. 关键路径确定

关键路径具有以下特点：

-   是项目网络图中最长的一条路径
-   决定项目最短完成时间
-   路径上的活动总浮动时间为 0

关键路径上的活动属于关键活动。

------------------------------------------------------------------------

# 8. CPM 计算步骤

## 第一步：绘制项目网络图

确定：

-   活动
-   活动关系
-   活动持续时间

------------------------------------------------------------------------

## 第二步：正向计算

计算：

-   ES
-   EF

得到项目最早完成时间。

------------------------------------------------------------------------

## 第三步：反向计算

计算：

-   LS
-   LF

------------------------------------------------------------------------

## 第四步：计算浮动时间

计算：

-   总浮动时间
-   自由浮动时间

------------------------------------------------------------------------

## 第五步：确定关键路径

找到：

-   浮动时间为 0 的活动
-   从开始到结束的最长路径

------------------------------------------------------------------------

# 10. 易错点

  易混知识               区别
  ---------------------- ------------------------------------
  ES vs LS               最早开始；最晚开始
  EF vs LF               最早结束；最晚结束
  关键路径 vs 最短路径   项目最长时间路径；不是距离最短
  总浮动 vs 自由浮动     是否影响项目整体；是否影响后续活动
