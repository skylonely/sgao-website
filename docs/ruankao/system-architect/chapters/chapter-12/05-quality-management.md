# 1. 软件质量管理概述

质量管理是项目管理的重要组成部分，主要目标是保证项目交付成果满足规定的质量要求。

软件质量管理主要包括三个过程：

-   质量规划
-   质量保证
-   质量控制


------------------------------------------------------------------------

# 2. 质量规划

质量规划用于确定项目质量目标、质量标准以及实现质量要求的方法。

主要内容包括：

-   确定质量要求
-   制定质量标准
-   规划质量活动
-   确定质量评价方法

质量规划主要关注：

> 项目应该达到什么质量要求。

------------------------------------------------------------------------

# 3. 质量保证

质量保证（Quality Assurance）主要关注项目过程是否符合质量要求。

特点：

-   面向过程
-   预防问题发生
-   保证开发过程规范

主要活动：

-   过程检查
-   软件评审
-   质量审核

质量保证关注：

> 是否按照正确的方法开发软件。

------------------------------------------------------------------------

# 4. 质量控制

质量控制（Quality Control）主要关注项目成果是否满足质量标准。

特点：

-   面向产品
-   发现问题
-   验证结果

主要活动：

-   产品检查
-   测试
-   缺陷分析

质量控制关注：

> 最终产品是否达到要求。

------------------------------------------------------------------------

# 5. 三者关系对比

  内容       关注点     主要问题
  ---------- ---------- ------------------
  质量规划   制定标准   要达到什么质量
  质量保证   过程管理   是否按照规范执行
  质量控制   产品检查   结果是否满足要求

------------------------------------------------------------------------

# 6. 质量管理流程

``` text
质量规划

↓

质量保证

↓

质量控制
```

三者共同保证项目最终交付质量。

# 8. 易错点

  易混知识               区别
  ---------------------- ----------------------------
  质量保证 vs 质量控制   保证过程质量；检查产品质量
  质量规划 vs 质量保证   制定要求；执行监督
  过程检查 vs 产品检查   开发过程；最终结果

# 10. 本节小结

质量管理主要围绕质量规划、质量保证和质量控制三个过程展开。

考试重点：

-   区分三个过程的作用

-   掌握质量管理流程
