# 1. 软件风险管理概述

风险管理是项目管理的重要组成部分，主要用于识别、分析和处理项目过程中可能影响项目目标实现的不确定因素。

风险管理的目标：

-   降低风险发生概率
-   减少风险造成的影响
-   保证项目顺利实施


------------------------------------------------------------------------

# 2. 风险管理计划编制

风险管理计划编制用于确定项目风险管理的方法和流程。

主要内容包括：

-   风险管理策略
-   风险管理流程
-   风险责任分配
-   风险监控方式

------------------------------------------------------------------------

# 3. 风险识别

风险识别用于发现项目中可能存在的风险。

主要关注：

-   风险来源
-   风险类型
-   风险影响因素

风险识别是风险管理的基础。

------------------------------------------------------------------------

# 4. 风险定性分析

风险定性分析用于评估风险发生的可能性和影响程度。

主要关注：

-   风险优先级
-   风险等级
-   风险重要程度

------------------------------------------------------------------------

# 5. 风险定量分析

风险定量分析用于进一步分析风险对项目目标的影响。

主要关注：

-   风险概率
-   风险影响
-   风险量化结果

------------------------------------------------------------------------

# 6. 风险应对计划

风险应对计划用于制定处理风险的方法。

常见处理思路：

-   降低风险影响
-   减少风险发生概率
-   制定应急措施

------------------------------------------------------------------------

# 7. 风险监控

风险监控用于跟踪风险变化情况。

主要内容：

-   监控已有风险
-   发现新风险
-   检查风险应对措施效果

------------------------------------------------------------------------

# 8. 风险分类

课程资料重点介绍三类风险：

## 8.1 项目风险

来源：

-   成本
-   进度
-   人员
-   资源
-   用户需求

------------------------------------------------------------------------

## 8.2 技术风险

来源：

-   软件设计
-   软件实现
-   接口
-   测试
-   新技术应用

------------------------------------------------------------------------

## 8.3 商业风险

包括：

-   市场风险
-   策略风险
-   销售风险
-   管理风险
-   预算风险

# 10. 易错点

  易混知识               区别
  ---------------------- --------------------
  风险识别 vs 风险分析   发现风险；评估风险
  定性分析 vs 定量分析   等级评估；数值分析
  风险监控 vs 风险应对   跟踪变化；处理风险

# 12. 本节小结

风险管理主要围绕风险计划编制、风险识别、风险分析、风险应对和风险监控展开。

考试重点：

-   掌握风险管理流程
-   理解风险分类
-   区分定性分析与定量分析
