# 三、典型真题

## 题目 1：关键路径

某项目网络计划中，关键路径上的活动具有：

A. 最大浮动时间

B. 最小资源消耗

C. 总浮动时间为 0

D. 不需要控制

答案：

``` text
C
```

解析：

关键路径上的活动总浮动时间为 0，任何延迟都会影响项目完成时间。

------------------------------------------------------------------------

## 题目 2：进度管理

项目进度管理包括：

A. 活动定义

B. 活动排序

C. 活动资源估算

D. 以上全部

答案：

``` text
D
```

解析：

项目进度管理包括活动定义、活动排序、资源估算、历时估算、制定进度计划和进度控制。

------------------------------------------------------------------------

## 题目 3：配置管理

软件配置管理的主要目标是：

A. 提高软件运行速度

B. 控制软件产品变化

C. 降低硬件成本

D. 增加用户数量

答案：

``` text
B
```

解析：

配置管理主要用于控制软件产品及相关配置项的变化。

------------------------------------------------------------------------

## 题目 4：质量管理

质量保证主要关注：

A. 最终产品检查

B. 开发过程是否规范

C. 软件销售情况

D. 用户反馈

答案：

``` text
B
```

解析：

质量保证关注过程，质量控制关注产品结果。

------------------------------------------------------------------------

# 四、真题解析重点

## 1. CPM 计算题

解题步骤：

``` text
绘制网络图

↓

正向计算 ES、EF

↓

反向计算 LS、LF

↓

计算浮动时间

↓

确定关键路径
```

------------------------------------------------------------------------

## 2. 配置管理题

重点理解：

-   配置项
-   配置标识
-   配置控制
-   配置状态报告
-   配置审计

------------------------------------------------------------------------

## 3. 质量管理题

重点区分：

  内容       关注
  ---------- --------------
  质量规划   制定质量要求
  质量保证   保证过程规范
  质量控制   检查产品结果

------------------------------------------------------------------------

## 4. 风险管理题

风险管理流程：

``` text
风险管理计划编制

↓

风险识别

↓

风险定性分析

↓

风险定量分析

↓

风险应对计划

↓

风险监控
```


------------------------------------------------------------------------

# 五、易错题分析

  易错点                 正确理解
  ---------------------- --------------------------------
  关键路径是最短路径     错，关键路径是最长工期路径
  质量保证检查产品       错，质量保证关注过程
  风险分析等于风险识别   错，识别发现风险，分析评估风险
  配置管理只管理代码     错，还包括文档、数据等配置项
