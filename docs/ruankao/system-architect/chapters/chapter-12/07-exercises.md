# 三、计算练习：关键路径法

某项目活动关系如下：

```text
A → B → D

A → C → D
```

活动持续时间：

| 活动 | 时间 |
|---|---:|
| A | 3 |
| B | 4 |
| C | 6 |
| D | 2 |

要求：

1. 计算两条路径时间。
2. 确定关键路径。
3. 计算项目最短完成时间。

答案：

路径：

- A-B-D = 3+4+2=9
- A-C-D = 3+6+2=11

因此：

关键路径：

```text
A-C-D
```

项目最短完成时间：

```text
11
```
