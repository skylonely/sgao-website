# 1. Web Service 概述

Web Service（Web 服务）是一种基于网络的软件服务技术。

它通过标准协议实现不同系统之间的信息交互，使不同平台、不同语言开发的软件能够进行通信。

Web Service 主要特点：

-   跨平台
-   跨语言
-   基于标准协议
-   服务可复用

------------------------------------------------------------------------

# 2. Web Service 基本思想

Web Service 将应用功能封装成服务，并通过网络接口向外提供。

核心思想：

``` text
服务提供

↓

标准描述

↓

网络调用

↓

服务使用
```

系统之间不需要了解内部实现，只需要按照服务接口进行调用。

------------------------------------------------------------------------

# 3. Web Service 体系结构

Web Service 通常包含三个核心角色：

## 3.1 服务提供者

负责：

-   创建 Web Service
-   发布服务描述
-   提供服务实现

------------------------------------------------------------------------

## 3.2 服务请求者

负责：

-   查找服务
-   调用服务
-   获取服务结果

------------------------------------------------------------------------

## 3.3 服务注册中心

负责：

-   保存服务信息
-   支持服务查询
-   提供服务发现

------------------------------------------------------------------------

# 4. SOAP

SOAP（Simple Object Access Protocol）是一种用于 Web Service 通信的协议。

特点：

-   基于 XML
-   描述消息格式
-   支持跨平台通信

SOAP 消息通常包含：

``` text
SOAP Envelope

↓

Header

↓

Body
```

作用：

实现服务之间的数据交换。

------------------------------------------------------------------------

# 5. WSDL

WSDL（Web Services Description Language）用于描述 Web Service。

主要描述：

-   服务接口
-   服务操作
-   输入输出参数
-   服务访问地址

作用：

让服务调用者了解如何调用服务。

------------------------------------------------------------------------

# 6. UDDI

UDDI（Universal Description, Discovery and Integration）用于 Web Service
的注册和发现。

主要功能：

-   发布服务
-   查询服务
-   获取服务信息

------------------------------------------------------------------------

# 7. Web Service 调用流程

典型流程：

``` text
服务提供者

↓

发布服务描述

↓

注册中心

↓

服务请求者查询

↓

调用 Web Service

↓

返回结果
```

------------------------------------------------------------------------

# 8. Web Service 与 SOA 关系

SOA 是一种架构思想。

Web Service 是实现 SOA 的一种技术方式。

关系：

``` text
SOA

↓

服务思想

↓

Web Service

↓

SOAP / WSDL / UDDI
```

SOA 关注：

-   服务划分
-   服务组合
-   系统集成

Web Service 关注：

-   服务实现
-   通信协议
-   技术标准

# 10. 易错点

  易混知识                   区别
  -------------------------- --------------------
  SOAP vs WSDL               通信协议；服务描述
  WSDL vs UDDI               描述服务；注册发现
  SOA vs Web Service         架构思想；实现技术
  服务提供者 vs 服务请求者   提供服务；调用服务
