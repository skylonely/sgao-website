# 1. 软件架构评估概述

软件架构评估是通过分析软件架构方案，判断其是否满足系统需求和质量属性要求的过程。

软件架构评估关注：

-   架构设计是否合理
-   是否满足质量需求
-   是否存在潜在风险

架构评估通常在系统开发早期进行，以降低后期修改成本。

------------------------------------------------------------------------

# 2. 软件质量属性

软件架构评估主要围绕质量属性展开。

常见质量属性包括：

## 2.1 性能

关注：

-   响应时间
-   吞吐量
-   资源利用率

------------------------------------------------------------------------

## 2.2 可用性

关注：

-   系统持续运行能力
-   故障恢复能力

------------------------------------------------------------------------

## 2.3 可修改性

关注：

-   系统适应变化能力
-   修改成本

------------------------------------------------------------------------

## 2.4 安全性

关注：

-   数据保护
-   访问控制
-   系统防护能力

------------------------------------------------------------------------

## 2.5 可测试性

关注：

-   是否容易进行测试
-   是否容易发现问题

------------------------------------------------------------------------

# 3. 架构评估目的

软件架构评估主要目的：

-   发现架构问题
-   分析质量属性满足情况
-   比较不同架构方案
-   支持架构决策

通过评估，可以提前发现：

-   性能瓶颈
-   扩展困难
-   安全风险

------------------------------------------------------------------------

# 5. 架构评估方法

常见软件架构评估方法：

## 5.1 SAAM

SAAM（Scenario-based Architecture Analysis Method）

即：

基于场景的软件架构分析方法。

特点：

-   以场景为基础
-   分析架构对变化的支持能力

重点关注：

-   可修改性

------------------------------------------------------------------------

## 5.2 ATAM

ATAM（Architecture Tradeoff Analysis Method）

即：

架构权衡分析方法。

特点：

-   分析多个质量属性之间的权衡
-   识别架构风险

重点关注：

-   性能
-   安全性
-   可修改性等质量属性之间的关系

------------------------------------------------------------------------

## 5.3 CBAM

CBAM（Cost Benefit Analysis Method）

即：

成本收益分析方法。

关注：

-   架构决策成本
-   架构收益分析

------------------------------------------------------------------------

# 6. 场景驱动分析

架构评估通常采用场景描述系统变化。

场景可以描述：

-   用户需求变化
-   功能扩展
-   性能变化
-   环境变化

通过分析架构对场景的响应能力，评价架构质量。

------------------------------------------------------------------------

# 7. 架构权衡思想

软件架构设计中，不同质量属性之间可能存在冲突。

例如：

  提升         可能影响
  ------------ ----------------
  性能提高     可修改性降低
  安全增强     系统复杂度增加
  灵活性提高   实现成本增加

架构评估需要寻找合理平衡。

# 9. 易错点

  易混知识               区别
  ---------------------- ------------------------
  SAAM vs ATAM           场景分析；质量属性权衡
  ATAM vs CBAM           架构权衡；成本收益分析
  性能 vs 可修改性       运行效率；变化能力
  架构设计 vs 架构评估   创建方案；分析方案
