系统架构设计是系统架构设计师考试中的核心章节，主要研究软件系统的整体结构、组成元素以及架构设计方法。

软件架构通过描述系统的结构、行为和属性，为软件设计和开发提供指导。

本章重点包括：

-   软件架构概念
-   软件架构风格
-   层次架构
-   SOA 面向服务架构
-   DSSA 特定领域软件架构
-   ABSD 基于架构的软件开发
-   软件架构评估
-   中间件技术

# 三、重点知识说明

## 1. 软件架构概述

软件架构描述软件系统的结构和组织方式。

主要关注：

-   系统组成元素
-   元素之间关系
-   系统设计约束

------------------------------------------------------------------------

## 2. 软件架构风格

软件架构风格定义系统组织结构的模式。

主要类型：

  风格            特点
  --------------- --------------------------
  数据流风格      数据经过多个处理步骤转换
  调用/返回风格   主程序调用子程序
  独立构件风格    基于事件通信
  虚拟机风格      通过解释执行实现
  仓库风格        数据集中管理

------------------------------------------------------------------------

## 3. 层次架构

重点掌握：

-   C/S
-   B/S
-   三层架构
-   MVC
-   MVP
-   MVVM

其中 MVC、MVP、MVVM 是考试常见知识点。

------------------------------------------------------------------------

## 4. SOA 面向服务架构

SOA 通过服务实现系统功能组织。

相关技术：

-   SOAP：服务通信协议
-   WSDL：服务描述
-   UDDI：服务注册
-   ESB：企业服务总线

------------------------------------------------------------------------

## 5. DSSA

DSSA（Domain Specific Software Architecture）：

特定领域软件架构。

主要过程：

``` text
领域分析

↓

领域设计

↓

领域实现
```

------------------------------------------------------------------------

## 6. ABSD

ABSD（Architecture-Based Software Development）：

基于架构的软件开发。

核心思想：

以软件架构为核心开展开发活动。

------------------------------------------------------------------------

## 7. 软件架构评估

重点方法：

  方法   说明
  ------ ------------------------
  SAAM   基于场景的架构分析方法
  ATAM   架构权衡分析方法
  CBAM   成本收益分析方法

------------------------------------------------------------------------

## 8. 中间件技术

主要内容：

-   CORBA
-   J2EE
-   .NET

用于解决分布式系统中的通信、集成和资源管理问题。
