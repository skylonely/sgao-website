# 1. 中间件概述

中间件（Middleware）是一种位于操作系统和应用程序之间的软件层。

中间件为分布式应用提供：

-   通信支持
-   服务调用
-   数据交换
-   资源管理

中间件屏蔽底层技术差异，使应用程序更加容易进行开发和集成。

------------------------------------------------------------------------

# 2. 中间件作用

中间件主要作用：

## 2.1 提供通信机制

解决不同系统之间的信息交换问题。

例如：

-   消息传递
-   远程调用

------------------------------------------------------------------------

## 2.2 提供公共服务

为应用提供通用功能：

-   安全服务
-   事务管理
-   连接管理

------------------------------------------------------------------------

## 2.3 支持系统集成

帮助不同平台、不同语言开发的软件进行协作。

------------------------------------------------------------------------

# 3. 中间件分类

常见中间件类型：

  类型                 作用
  -------------------- ----------------
  远程过程调用中间件   支持远程调用
  消息中间件           支持异步通信
  对象中间件           支持分布式对象
  事务中间件           支持事务管理

------------------------------------------------------------------------

# 4. CORBA

CORBA（Common Object Request Broker Architecture）：

公共对象请求代理体系结构。

由 OMG（Object Management Group）提出。

核心：

> 通过对象请求代理实现分布式对象之间的通信。

------------------------------------------------------------------------

## CORBA 主要组成

包括：

-   ORB（对象请求代理）
-   IDL（接口定义语言）

其中：

ORB 负责：

-   接收请求
-   定位对象
-   完成通信

IDL 用于：

-   描述对象接口
-   实现跨语言调用

------------------------------------------------------------------------

# 5. COM/DCOM

COM（Component Object Model）：

组件对象模型。

DCOM（Distributed Component Object Model）：

分布式组件对象模型。

主要用于 Windows 平台组件开发。

特点：

-   支持组件复用
-   支持对象通信
-   DCOM 支持分布式调用

------------------------------------------------------------------------

# 6. EJB

EJB（Enterprise JavaBeans）：

企业级 JavaBeans。

EJB 是 Java 企业级应用中的组件技术。

主要提供：

-   事务管理
-   安全管理
-   生命周期管理

EJB 类型包括：

-   Session Bean
-   Entity Bean
-   Message-Driven Bean

------------------------------------------------------------------------

# 7. J2EE

J2EE（Java 2 Platform, Enterprise Edition）：

Java 企业级应用平台。

核心目标：

支持企业级分布式应用开发。

主要技术：

-   Servlet
-   JSP
-   EJB

特点：

-   跨平台
-   面向组件
-   支持企业应用

------------------------------------------------------------------------

# 8. .NET

.NET 是微软提出的软件开发平台。

核心：

-   CLR（公共语言运行时）
-   多语言支持

特点：

-   支持多种开发语言
-   提供统一运行环境
-   支持组件开发

------------------------------------------------------------------------

# 9. 中间件技术对比

  技术       特点
  ---------- --------------------------
  CORBA      跨语言、跨平台分布式对象
  COM/DCOM   Windows组件技术
  EJB        Java企业组件技术
  J2EE       Java企业级应用平台
  .NET       微软企业开发平台
