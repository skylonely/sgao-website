# 二、软件架构核心概念

软件架构描述软件系统的高层结构。

主要包括：

-   架构元素
-   元素之间关系
-   架构约束

架构设计重点关注：

-   功能需求
-   非功能需求
-   质量属性
-   技术约束

------------------------------------------------------------------------

# 三、软件架构风格总结

  架构风格        核心思想
  --------------- ------------------
  数据流风格      数据逐步转换处理
  调用/返回风格   模块之间调用
  独立构件风格    事件或消息通信
  虚拟机风格      提供抽象运行环境
  仓库风格        共享数据存储

------------------------------------------------------------------------

# 四、层次架构总结

## C/S 架构

特点：

-   客户端承担部分处理
-   服务器提供核心服务

优点：

-   响应速度快

缺点：

-   部署维护复杂

## B/S 架构

特点：

-   浏览器作为客户端
-   服务集中管理

优点：

-   易部署
-   易维护

# 十一、易错知识总结

  易错点                 正确理解
  ---------------------- -----------------------------------
  SOA 是一种具体技术     SOA 是架构思想
  Web Service 等于 SOA   Web Service 是实现 SOA 的技术之一
  WSDL 用于注册服务      WSDL 用于描述服务
  UDDI 用于描述服务      UDDI 用于注册和发现服务
  ATAM 只分析性能        ATAM 分析多质量属性权衡
  DSSA 面向单系统        DSSA 面向领域复用
