# 13 Exercises（章节练习）

> 本文依据《13.系统架构设计.pdf》中系统架构设计相关内容整理，用于系统架构设计师考试复习，保持章节知识体系。

------------------------------------------------------------------------

# 一、单项选择题

## 1. 软件架构主要描述的是：

A. 软件代码实现细节\
B. 软件系统的整体结构和组成关系\
C. 数据库表结构\
D. 用户操作流程

**答案：B**

解析：

软件架构关注系统的高层结构、组成元素以及元素之间的关系。

------------------------------------------------------------------------

## 2. 以下属于软件架构风格的是：

A. 数据流风格\
B. 数据库设计风格\
C. 编码规范\
D. 测试方法

**答案：A**

解析：

常见软件架构风格包括数据流风格、调用/返回风格、独立构件风格、虚拟机风格和仓库风格。

------------------------------------------------------------------------

## 3. MVC 模式中负责业务数据和业务逻辑的是：

A. View\
B. Controller\
C. Model\
D. Interface

**答案：C**

解析：

Model 负责数据管理和业务逻辑。

------------------------------------------------------------------------

## 4. MVVM 架构中的核心组件是：

A. Controller\
B. ViewModel\
C. Presenter\
D. Service Bus

**答案：B**

解析：

ViewModel 负责连接 View 和 Model，实现数据状态管理。

------------------------------------------------------------------------

## 5. SOA 中负责服务注册和查询的是：

A. SOAP\
B. WSDL\
C. UDDI\
D. ESB

**答案：C**

解析：

UDDI 用于服务注册和发现。

------------------------------------------------------------------------

## 6. Web Service 中描述服务接口的是：

A. SOAP\
B. WSDL\
C. UDDI\
D. XML

**答案：B**

解析：

WSDL 用于描述 Web Service 的接口和调用方式。

------------------------------------------------------------------------

## 7. DSSA 的核心目标是：

A. 单个系统快速开发\
B. 面向领域的软件复用\
C. 提高代码执行速度\
D. 替代数据库系统

**答案：B**

解析：

DSSA 面向特定领域，通过领域分析和设计形成可复用架构。

------------------------------------------------------------------------

## 8. ABSD 的核心思想是：

A. 数据驱动开发\
B. 架构驱动开发\
C. 测试驱动开发\
D. 文档驱动开发

**答案：B**

------------------------------------------------------------------------

## 9. ATAM 主要关注：

A. 成本计算\
B. 架构权衡和质量属性分析\
C. 数据存储\
D. 编码规范

**答案：B**

------------------------------------------------------------------------

## 10. CORBA 中负责对象请求代理的是：

A. CLR\
B. ORB\
C. JVM\
D. ESB

**答案：B**

------------------------------------------------------------------------

# 二、判断题

1.  软件架构只关注软件代码实现。（×）

2.  构件具有接口，可以进行复用。（√）

3.  MVC 中 View 负责业务逻辑处理。（×）

4.  SOA 强调服务之间的松耦合。（√）

5.  WSDL 用于服务注册发现。（×）

6.  DSSA 面向某个特定领域的软件系统。（√）

7.  ATAM 用于分析架构质量属性之间的权衡。（√）

8.  中间件位于操作系统和应用程序之间。（√）

------------------------------------------------------------------------

# 三、简答题

## 1. 简述软件架构的主要组成。

参考答案：

软件架构主要包括：

-   架构元素
-   元素之间关系
-   架构约束

用于描述系统整体结构。

------------------------------------------------------------------------

## 2. 简述 MVC 三个组成部分。

参考答案：

  部分         作用
  ------------ ----------------
  Model        数据和业务逻辑
  View         用户界面展示
  Controller   请求控制和协调

------------------------------------------------------------------------

## 3. 简述 SOA 三个核心角色。

参考答案：

``` text
服务提供者

↓

服务注册中心

↓

服务消费者
```

-   服务提供者发布服务；
-   注册中心保存服务信息；
-   消费者查询并调用服务。

------------------------------------------------------------------------

## 4. 简述 DSSA 三个阶段。

参考答案：

``` text
领域分析

↓

领域设计

↓

领域实现
```

# 四、综合练习

## 1. 某系统要求：

-   支持快速扩展
-   多系统集成
-   服务复用

应采用哪种架构思想？

答案：

SOA。

原因：

SOA 通过服务封装实现系统集成和服务复用。

------------------------------------------------------------------------

## 2. 某系统需要根据用户变化需求不断调整架构。

应重点关注：

答案：

软件架构评估和架构演化。
