# 1. 软件架构风格概述

软件架构风格（Architectural Style）描述了软件系统中：

-   构件组织方式
-   构件之间交互方式
-   系统结构模式

架构风格为软件系统设计提供了一类可复用的结构方案。

常见软件架构风格包括：

-   数据流风格
-   调用/返回风格
-   独立构件风格
-   虚拟机风格
-   仓库风格

------------------------------------------------------------------------

# 2. 数据流风格

数据流风格以数据处理过程为核心。

特点：

-   数据按照固定流程进行传递
-   每个处理步骤完成特定转换
-   一个处理过程的输出成为下一个处理过程的输入

典型形式：

``` text
输入

↓

处理1

↓

处理2

↓

输出
```

常见应用：

-   编译器
-   数据处理系统
-   信号处理系统

------------------------------------------------------------------------

# 3. 调用/返回风格

调用/返回风格通过模块之间的调用关系组织系统。

特点：

-   一个模块调用另一个模块
-   控制权在模块之间传递
-   结构清晰

常见形式：

## 主程序-子程序

``` text
Main

↓

Sub Program
```

## 面向对象调用

对象之间通过方法调用完成协作。

优点：

-   易理解
-   易设计
-   易维护

------------------------------------------------------------------------

# 4. 独立构件风格

独立构件风格强调构件之间松散耦合。

特点：

-   构件相互独立
-   通过事件或消息通信
-   降低系统耦合度

典型形式：

``` text
事件产生

↓

事件处理构件
```

常见应用：

-   事件驱动系统
-   消息系统

优势：

-   易扩展
-   易替换
-   支持并发处理

------------------------------------------------------------------------

# 5. 虚拟机风格

虚拟机风格通过建立虚拟执行环境实现系统运行。

特点：

-   提供抽象执行环境
-   屏蔽底层平台差异
-   支持解释执行

典型应用：

-   Java 虚拟机（JVM）
-   解释器
-   规则引擎

结构：

``` text
应用程序

↓

虚拟机

↓

操作系统/硬件
```

------------------------------------------------------------------------

# 6. 仓库风格

仓库风格以共享数据存储为核心。

特点：

-   中央数据存储
-   多个构件访问共享数据
-   数据与处理逻辑分离

结构：

``` text
处理构件

   ↓

共享仓库

   ↑

处理构件
```

常见应用：

-   数据库系统
-   信息管理系统

优点：

-   数据共享方便
-   易于管理

缺点：

-   仓库可能成为性能瓶颈

------------------------------------------------------------------------

# 7. 架构风格对比

  架构风格    核心思想       典型应用
  ----------- -------------- ------------------
  数据流      数据逐步转换   编译器、数据处理
  调用/返回   模块调用关系   传统程序
  独立构件    事件通信       消息系统
  虚拟机      抽象执行环境   JVM
  仓库        共享数据中心   数据库系统

# 8. 高频考点（★★★★★）

重点掌握：

-   五种架构风格特点
-   数据流风格特点
-   调用/返回结构
-   事件驱动架构特点
-   虚拟机作用
-   仓库风格优缺点

------------------------------------------------------------------------

# 9. 易错点

  易混知识                区别
  ----------------------- ----------------------------
  数据流 vs 仓库          数据逐步转换；共享数据存储
  调用/返回 vs 独立构件   直接调用；事件通信
  虚拟机 vs 操作系统      提供运行环境；管理硬件资源

# 11. 本节小结

本节重点：

-   理解五种基本架构风格
