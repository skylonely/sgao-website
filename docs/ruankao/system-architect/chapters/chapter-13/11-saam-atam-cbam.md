# 1. SAAM 方法

SAAM（Scenario-based Architecture Analysis Method）

中文：

> 基于场景的软件架构分析方法。

SAAM
是一种早期的软件架构评估方法，主要通过场景分析架构对变化的支持能力。

主要关注：

-   架构可修改性
-   架构适应变化能力

------------------------------------------------------------------------

# 2. SAAM 评估过程

SAAM 基本过程：

``` text
确定评估场景

↓

分析场景影响

↓

评价架构响应

↓

比较架构方案
```

------------------------------------------------------------------------

## SAAM 特点

-   基于场景
-   关注变化影响
-   适合分析架构修改能力

------------------------------------------------------------------------

# 3. ATAM 方法

ATAM（Architecture Tradeoff Analysis Method）

中文：

> 架构权衡分析方法。

ATAM 是一种用于分析软件架构质量属性之间权衡关系的方法。

主要关注：

-   多种质量属性之间的影响
-   架构决策风险

------------------------------------------------------------------------

# 4. ATAM 评估过程

ATAM 主要过程：

``` text
确定质量属性

↓

建立质量属性场景

↓

分析架构决策

↓

发现权衡点

↓

识别风险
```

------------------------------------------------------------------------

## ATAM 关注内容

主要分析：

-   性能
-   可修改性
-   安全性
-   可用性

等质量属性之间的关系。

例如：

提高性能可能导致：

-   系统复杂度增加
-   可修改性下降

------------------------------------------------------------------------

# 5. CBAM 方法

CBAM（Cost Benefit Analysis Method）

中文：

> 成本收益分析方法。

CBAM 在架构决策过程中考虑：

-   成本
-   收益
-   风险

通过经济分析帮助选择架构方案。

------------------------------------------------------------------------

## CBAM 关注点

主要分析：

-   架构决策成本
-   架构收益
-   投资回报

------------------------------------------------------------------------

# 6. 三种方法对比

  方法   中文名称                     重点
  ------ ---------------------------- ----------------
  SAAM   基于场景的软件架构分析方法   场景和修改能力
  ATAM   架构权衡分析方法             质量属性权衡
  CBAM   成本收益分析方法             成本收益分析

------------------------------------------------------------------------

# 7. 架构评估中的质量属性场景

架构评估通常通过场景描述质量需求。

常见场景：

## 性能场景

例如：

用户请求增加时，系统响应时间是否满足要求。

------------------------------------------------------------------------

## 可修改性场景

例如：

增加新功能时，需要修改多少模块。

------------------------------------------------------------------------

## 可用性场景

例如：

系统发生故障后恢复时间。

------------------------------------------------------------------------

## 安全性场景

例如：

非法访问发生时系统如何处理。

------------------------------------------------------------------------

# 8. 高频考点（★★★★★）

重点掌握：

-   SAAM 关注可修改性
-   ATAM 关注质量属性权衡
-   CBAM 关注成本收益
-   三种评估方法区别
-   架构评估中的场景分析

------------------------------------------------------------------------

# 9. 易错点

  易混知识               区别
  ---------------------- ----------------------------
  SAAM vs ATAM           场景分析；质量属性权衡
  ATAM vs CBAM           技术权衡；经济分析
  架构评估 vs 架构设计   分析已有方案；创建架构方案
  质量属性 vs 功能需求   系统质量要求；业务功能

------------------------------------------------------------------------
