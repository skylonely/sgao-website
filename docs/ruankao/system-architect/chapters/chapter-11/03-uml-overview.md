# 1. UML 概述

UML（Unified Modeling Language，统一建模语言）是一种用于面向对象系统分析、设计和建模的标准化图形语言。课程资料将 UML 作为面向对象开发的重要建模工具进行介绍。

---

# 2. UML 的作用

- 描述系统结构
- 描述系统行为
- 支持分析与设计
- 提高沟通效率
- 为系统实现提供模型基础

# 4. UML 的特点

- 图形化表示
- 面向对象
- 标准化建模
- 支持系统全生命周期
- 易于交流与维护

---

# 5. UML 的应用

UML 可应用于：

- 面向对象分析（OOA）
- 面向对象设计（OOD）
- 软件架构设计
- 系统建模
- 文档编制

# 7. 易错点

| 易混知识 | 区别 |
|----------|------|
| UML vs OOA | UML 是建模语言；OOA 是分析方法 |
| UML vs OOD | UML 是建模工具；OOD 是设计过程 |
