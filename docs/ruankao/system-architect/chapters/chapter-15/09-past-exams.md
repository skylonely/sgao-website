# 09 Past Exams（历年真题）

> 本文用于系统架构设计师考试复习，整理第十五章《软件架构的演化和维护》的重点考查内容。

------------------------------------------------------------------------

# 一、软件架构演化基础

## 1. 软件架构演化的主要目的？

A. 删除旧系统\
B. 适应环境变化和新的业务需求\
C. 停止系统维护\
D. 替换全部技术

答案：

``` text
B
```

------------------------------------------------------------------------

# 二、面向对象架构演化

## 2. AO 表示：

``` text
Add Object（增加对象）
```

## 3. DO 表示：

``` text
Delete Object（删除对象）
```

## 4. 消息演化包括：

-   AM（Add Message）
-   DM（Delete Message）
-   SMO（Swap Message Order）
-   OM（Overturn Message）
-   CMM（Change Message Module）

------------------------------------------------------------------------

# 三、架构演化方式

## 5. 架构演化按照实现方式分类：

-   基于过程和函数的演化
-   面向对象演化
-   基于组件演化
-   基于架构演化

------------------------------------------------------------------------

## 6. 静态演化与动态演化

静态演化：

-   通常发生在运行前；
-   修改后重新部署。

动态演化：

-   发生在运行过程中；
-   可以不中断服务。

------------------------------------------------------------------------

# 四、架构演化原则

重点：

-   成本可控；
-   风险可控；
-   平滑演化；
-   模块独立演化；
-   影响可控；
-   复杂性可控。

------------------------------------------------------------------------

# 五、大型网站架构演化

典型过程：

``` text
单体架构

↓

垂直架构

↓

缓存/CDN

↓

反向代理

↓

负载均衡

↓

分布式服务
```

## CDN作用

``` text
提高静态资源访问速度，降低源站压力
```

------------------------------------------------------------------------

# 六、软件架构维护

主要包括：

-   架构知识管理；
-   架构修改管理；
-   架构版本管理。

版本管理作用：

-   保存历史版本；
-   支持架构比较；
-   保证演化过程可追踪。

------------------------------------------------------------------------

# 七、综合案例分析

某大型网站从单体架构逐步演化为分布式服务架构。

原因：

-   用户规模增长；
-   数据量增加；
-   业务复杂度提高；
-   单体架构扩展能力不足。

演化目标：

-   提升性能；
-   提高可扩展性；
-   降低维护成本；
-   提高系统稳定性。

# 九、易错点

  错误理解                 正确理解
  ------------------------ ----------------------------------
  架构演化只是修改代码     架构演化关注整体结构
  动态演化发生在设计阶段   动态演化发生在运行阶段
  CDN解决数据库问题        CDN主要优化静态资源访问
  架构维护只管理代码       架构维护包含知识、修改和版本管理
