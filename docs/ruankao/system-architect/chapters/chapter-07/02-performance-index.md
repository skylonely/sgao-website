# 第一节 性能指标

## 计算机
- 时钟频率
- 运算速度
- 运算精度
- 内存容量
- 存储容量
- PDR
- 响应时间
- RASIS（可靠性、可用性、可维护性、完整性、安全性）

## 网络设备
### 路由器
设备吞吐量、端口吞吐量、转发能力、QoS、VPN 等。

### 交换机
交换容量、背板带宽、MAC 地址表、VLAN、QoS 等。

### 网络
设备级、网络级、应用级、用户级性能指标。

### 操作系统
可靠性、吞吐率、响应时间、资源利用率、可移植性。

### 数据库
容量、记录数、索引数、并发能力、连接数。

### Web服务器
最大并发连接数、响应延迟、吞吐量。
