# 第四节 阿姆达尔定律

阿姆达尔（Amdahl）定律用于计算：只改进系统中的一部分后，整个系统最多能获得多少加速。它的关键结论是：没有被优化的部分会限制总加速比。

## 1. 公式

设：

- `a`：可优化部分占原总执行时间的比例。
- `k`：可优化部分加速的倍数。
- `1-a`：不可优化部分占原总执行时间的比例。

则总加速比为：

```text
Speedup = 原执行时间 / 新执行时间
        = 1 / ((1 - a) + a / k)
```

也可以从时间拆分理解：原总时间设为 1，优化后不可优化部分仍为 `1-a`，可优化部分变为 `a/k`。

## 2. 解题流程

```mermaid
flowchart TD
  A[读题：确定可优化比例 a] --> B[确定优化倍数 k]
  B --> C[不可优化部分 = 1-a]
  C --> D[优化后可优化部分 = a/k]
  D --> E[新总时间 = 1-a+a/k]
  E --> F[总加速比 = 1/新总时间]
  F --> G[检查：结果不超过 1/(1-a)]
```

## 3. 课件经典例题

某功能的处理时间占整个系统运行时间的 60%，将该功能的处理速度提高到原来的 5 倍。根据阿姆达尔定律：

```text
a = 0.60
k = 5
新总时间 = (1 - 0.60) + 0.60 / 5
          = 0.40 + 0.12
          = 0.52
Speedup = 1 / 0.52 ≈ 1.923
```

答案：整个系统速度提高约 **1.923 倍**。

## 4. 最大加速比

当可优化部分被无限加速，即 `k → ∞` 时：

```text
最大 Speedup = 1 / (1-a)
```

上例中 `a=0.6`，最大加速比为 `1/0.4=2.5`。因此即使把这 60% 的功能做到无限快，系统整体也不可能超过 2.5 倍。

## 5. 常见错误

1. 把 `a` 当成不可优化比例；正确的是 `a` 表示可优化比例。
2. 直接计算 `a×k`；这是局部部分的直觉乘法，不是整体加速比。
3. 忘记保留 `1-a`；未优化部分仍然占用时间。
4. 把“提高 5 倍”误读成“提高了 5 倍”，通常题目中的“提高到原来的 5 倍”对应 `k=5`。
5. 结果超过 `1/(1-a)`，说明公式或比例代入有误。

## 快速模板

```text
原时间 = 1
不可优化 = 1-a
优化后可优化 = a/k
新时间 = 1-a+a/k
总加速比 = 1/(1-a+a/k)
```
