# 1. Kubernetes Node概述

Node：

> Kubernetes集群中运行Pod和Container的工作节点。

结构：

``` text
Kubernetes Cluster

↓

Worker Node

↓

Pod

↓

Container
```

------------------------------------------------------------------------

# 2. Node节点组成

Worker Node主要包含：

## kubelet

负责：

-   Pod生命周期管理；
-   Container启动；
-   状态汇报。

------------------------------------------------------------------------

## Container Runtime

负责：

-   创建容器；
-   管理镜像。

常见：

-   containerd；
-   CRI-O。

------------------------------------------------------------------------

## kube-proxy

负责：

-   Service网络转发；
-   网络规则维护。

结构：

``` text
Node

├── kubelet
├── kube-proxy
└── Container Runtime
```

------------------------------------------------------------------------

# 10. cordon节点隔离

作用：

> 禁止新的Pod调度到指定Node。

命令：

``` bash
kubectl cordon node-name
```

效果：

``` text
已有Pod继续运行

新Pod禁止进入
```

------------------------------------------------------------------------

# 11. drain节点驱逐

作用：

> 安全迁移节点上的Pod。

命令：

``` bash
kubectl drain node-name
```

流程：

``` text
Node

↓

驱逐Pod

↓

迁移到其他Node
```

------------------------------------------------------------------------

# 12. uncordon恢复节点

命令：

``` bash
kubectl uncordon node-name
```

作用：

恢复节点调度能力。

# 17. 系统架构设计师考点

## Node作用？

答：

> Node是Kubernetes运行工作负载的节点，负责运行Pod和Container。

------------------------------------------------------------------------

## kubelet作用？

答：

> kubelet负责管理节点上的Pod生命周期，并向API Server汇报状态。

------------------------------------------------------------------------

## cordon和drain区别？

答：

> cordon禁止新Pod调度，drain会驱逐已有Pod并迁移。

------------------------------------------------------------------------

## Node如何加入集群？

答：

> kubelet启动后向API Server注册Node信息，完成节点加入。

# 19. 本节小结

1.  Node负责运行Pod和Container；
