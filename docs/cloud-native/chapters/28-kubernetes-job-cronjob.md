# 1. Job概述

Job：

> Kubernetes中用于执行一次性任务的控制器。

特点：

-   创建Pod；
-   执行任务；
-   任务完成后结束。

结构：

``` text
Job

↓

Pod

↓

Container
```

------------------------------------------------------------------------

# 2. 为什么需要Job

Deployment：

``` text
运行

↓

持续提供服务
```

适合：

-   Web服务；
-   API服务。

Job：

``` text
启动

↓

执行

↓

完成

↓

退出
```

适合：

-   批处理；
-   数据计算；
-   文件处理。

------------------------------------------------------------------------

# 3. Job与Deployment区别

  Deployment        Job
  ----------------- ----------------
  长期运行服务      一次性执行任务
  保证Pod持续运行   保证任务完成
  Web/API服务       批处理任务
  持续提供服务      执行完成退出

结构：

``` text
Job

├── Metadata

└── Status
```

Spec主要包含：

-   completions；
-   parallelism；

------------------------------------------------------------------------

# 5. Job YAML结构

示例：

``` yaml
apiVersion: batch/v1

kind: Job

metadata:
  name: data-job

spec:
  template:
    spec:
      containers:
      - name: worker
        image: batch-image

      restartPolicy: Never
```

# 7. Job任务完成机制

通过：

``` yaml
completions
```

控制任务完成数量。

例如：

``` yaml
completions: 5
```

表示需要成功完成5次任务。

------------------------------------------------------------------------

# 8. Job并行任务

parallelism：

控制：

> 同时运行多少个Pod。

例如：

``` yaml
parallelism: 3
```

表示：

``` text
Pod1

Pod2

Pod3
```

同时执行。

------------------------------------------------------------------------

# 9. Job失败处理机制

参数：

## backoffLimit

控制失败重试次数。

例如：

``` yaml
backoffLimit: 3
```

表示最多失败重试3次。

# 10. CronJob概述

CronJob：

> Kubernetes中的定时任务控制器。

关系：

``` text
CronJob

↓

Job

↓

Pod

↓

Container
```

类似 Linux：

``` bash
crontab
```

------------------------------------------------------------------------

# 11. CronJob资源模型

结构：

``` text
CronJob

├── Schedule
├── Job Template
└── Status
```

------------------------------------------------------------------------

# 12. CronJob YAML结构

示例：

``` yaml
apiVersion: batch/v1

kind: CronJob

metadata:
  name: backup

spec:
  schedule: "0 2 * * *"

  jobTemplate:
    spec:
      template:
        spec:
          containers:
          - name: backup
            image: backup-image
```

------------------------------------------------------------------------

# 13. Cron表达式

格式：

``` text
分 时 日 月 周
```

例如：

每天凌晨2点：

``` text
0 2 * * *
```

常见：

每分钟：

``` text
* * * * *
```

每天：

``` text
0 0 * * *
```

每周：

``` text
0 0 * * 0
```

# 17. 系统架构设计师考点

## Job作用？

答：

> Job用于执行一次性任务，保证任务成功完成。

------------------------------------------------------------------------

## CronJob作用？

答：

> CronJob用于按照时间计划周期性创建Job，实现定时任务调度。

------------------------------------------------------------------------

## Job和Deployment区别？

答：

> Deployment用于长期运行服务，Job用于执行完成后结束的任务。

------------------------------------------------------------------------

## CronJob类似什么？

答：

> CronJob类似Linux中的crontab定时任务。

# 19. 本节小结

Job与CronJob核心：

1.  Job负责一次性任务执行；
2.  Job保证任务最终完成；
3.  parallelism控制并行数量；
4.  backoffLimit控制失败重试；
5.  CronJob基于时间规则创建Job；
6.  适用于备份、同步、批处理等场景。
