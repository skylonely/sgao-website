# 1. Docker概述

Docker是一种基于容器技术的应用运行平台。

它通过操作系统级虚拟化技术，将应用程序及其依赖环境封装成标准化容器，实现：

-   快速部署
-   环境一致性
-   资源隔离
-   应用迁移

核心思想：

> Build Once，Run Anywhere（一次构建，到处运行）

# 2. 容器技术发展历史

``` text
物理机时代

↓

虚拟机时代

↓

容器时代

↓

云原生时代
```

## 虚拟机

特点：

-   完整操作系统
-   隔离性强
-   资源消耗较高

## 容器

特点：

-   共享宿主机内核
-   启动速度快
-   资源利用率高

------------------------------------------------------------------------

# 3. 虚拟机与容器对比

  比较项     虚拟机       容器
  ---------- ------------ ----------------
  虚拟化层   硬件虚拟化   操作系统虚拟化
  运行环境   完整OS       共享Kernel
  启动速度   较慢         快速
  资源占用   较高         较低

# 4. Docker核心概念

Docker核心组成：

``` text
Docker Image

↓

Docker Container

↓

Docker Engine
```

## Image

镜像是创建容器的只读模板。

特点：

-   分层存储
-   可版本管理
-   可共享

## Container

容器是镜像运行后的实例。

生命周期：

``` text
创建

↓

启动

↓

运行

↓

停止

↓

删除
```

## Docker Engine

负责：

-   镜像管理
-   容器管理
-   网络管理
-   存储管理
