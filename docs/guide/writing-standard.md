# 文档写作规范

为了让知识库长期保持统一、清晰和易于维护，新文档建议采用下面的结构。

## 文件与标题

- 文件名使用简短、清晰的英文小写名称，多个单词使用连字符连接。
- 每篇文档只保留一个一级标题。
- 文档放入对应分类目录，图片等资源尽量与文章放在同一分类下。
- 图片统一使用 `https://img.sgao.cc/...` 地址，并填写能够说明内容的替代文本。
- 不创建只有标题、“后续补充”或文档计划的占位页面。

## 发布标准

文档进入导航和侧边栏前，至少应包含：

- 明确的适用范围
- 能够执行的步骤或可复用的信息
- 必要的验证方法
- 常见问题或注意事项
- 相关文档入口

暂未完成的主题记录在项目计划中，等内容达到可阅读状态后再创建 Markdown 文件。

## 标准模板

```markdown
# 标题

## 一、简介

## 二、准备工作

## 三、操作步骤

## 四、最终效果

## 五、注意事项

## 六、常见问题

## 七、经验总结

## 八、相关文章
```

## 使用说明

不需要的章节可以省略，但同一类型的文档应尽量保持相同顺序。操作类内容应写清前置条件、关键命令、验证方法和可能遇到的问题。
